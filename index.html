Reference
Hardware requirements

Companion computers, flight controllers, cameras and modems. Check this before you buy parts.

  • Raspberry Pi, NVIDIA Jetson, Orange Pi
  • Any arm64 or amd64 Linux computer
  • Any MAVLink flight controller (ArduPilot, PX4)
  • USB and HiLink LTE modems

Activate your license

Activate a key on a device, move it to new hardware and see how device slots work.
