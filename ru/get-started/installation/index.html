Установка UAVcast-Pro

Установка одной командой
$curl -fsSL https://install.uavmatrix.com | sudo bash

Выполните её на бортовом компьютере (64-битная Raspberry Pi OS, Debian или Ubuntu с доступом в интернет). Шаги ниже объясняют, что она делает и как подготовить устройство.

Для активации дрона нужна лицензия UAVcast-Pro. Купите её в магазине UAVmatrix.

Купить UAVcast-ProТарифы и цены

UAVcast-Pro устанавливается одной командой в любой 64-битной Linux-системе на основе Debian: Raspberry Pi OS, Debian или Ubuntu, на arm64 или amd64. Установщик загружает последнюю версию, устанавливает её зависимости и службы и по завершении выводит адрес веб-интерфейса. Установка занимает около 10 минут или около 30 минут на Raspberry Pi Zero 2 W, 2 или 3.

Перед началом работы​

  • 64-битная ОС на бортовом компаньоне. Проверьте командой uname -m: она должна вывести aarch64 или x86_64.
  • Не менее 500 МБ свободного места на корневом диске (df -h /).
  • Доступ в интернет на устройстве во время установки.
  • SSH или клавиатура и монитор для устройства, а также пользователь с правами sudo.

Шаг 1: Установка операционной системы​

  • Raspberry Pi
  • Другие платы arm64
  • ПК x86-64
  1. Откройте Raspberry Pi Imager и выберите модель вашего Pi.
  2. Выберите Raspberry Pi OS (64-bit). Версии Lite достаточно, и она оставляет больше ресурсов процессора для видео.
  3. Откройте настройки кастомизации ОС. Задайте имя хоста, имя пользователя и пароль, вашу сеть Wi-Fi и страну, а также включите SSH.
  4. Запишите образ на карту, вставьте её в Pi и включите питание.

Ubuntu Server 64-bit для Raspberry Pi также подходит.

Запишите 64-битный образ Ubuntu или Debian от производителя (например, Ubuntu из JetPack для NVIDIA Jetson), выполните первоначальную настройку при первом запуске и включите SSH.

Платы arm64, отличные от Raspberry Pi, требуют UAVcast-Pro 6.5.3 или новее; старые установщики останавливаются с сообщением Device is not a Raspberry Pi.

Установите 64-битную версию Debian или Ubuntu (Server или Desktop). Установщик не проверяет версию выпуска, поэтому используйте актуальную поддерживаемую версию, например Ubuntu 22.04 LTS или новее.

Затем войдите по SSH и обновите систему:

Terminal
sudo apt update && sudo apt full-upgrade -y

Шаг 2: Запуск установщика​

На дроне:

$curl -fsSL https://install.uavmatrix.com | sudo bash

Установщик:

  1. Определяет архитектуру и загружает подходящую версию в /opt/uavcast-pro.
  2. Устанавливает нужные системные пакеты: NetworkManager, ModemManager, GStreamer, v4l-utils, Redis, Python и другие.
  3. На Raspberry Pi освобождает UART на GPIO для полётного контроллера (удаляет консоль последовательного порта из cmdline.txt, переносит Bluetooth с UART) и увеличивает пул памяти камеры для конфигураций с двумя камерами. Исходные config.txt и cmdline.txt предварительно сохраняются в резервную копию.
  4. Устанавливает ZeroTier, Tailscale, mavlink-router и MediaMTX.
  5. Устанавливает и запускает службы UAVcast-Pro.
  6. Проверяет наличие основных инструментов и выводит адрес веб-интерфейса.

По завершении вы увидите:

Text
✅ Installation completed successfully!

Please reboot your device to complete the installation.

To access the UAVcast-Pro web interface, open your browser and navigate to:
http://192.168.1.50

Перезагрузите устройство, чтобы изменения UART и камеры вступили в силу:

Terminal
sudo reboot
Дайте медленным платам завершить установку

На Pi Zero 2 W индикатор прогресса может несколько минут оставаться неподвижным, пока apt выполняет работу. Не запускайте вторую установку: установщик не запускается дважды, а вторая копия только замедлит первую. Полный журнал находится в /opt/uavcast-pro/installer.log.

Установка определённой версии​

Выведите список версий, доступных для вашей архитектуры:

Terminal
curl -fsSL https://install.uavmatrix.com | bash -s -- -l

Установите одну из них с помощью -b:

Terminal
curl -fsSL https://install.uavmatrix.com | sudo bash -s -- -b 6.5.2

Позже версию также можно сменить в веб-интерфейсе. См. Обновление UAVcast-Pro.

Шаг 3: Откройте веб-интерфейс​

На компьютере в той же сети откройте браузер и перейдите по адресу, который вывел установщик, например http://192.168.1.50. Веб-интерфейс работает на порту 80.

Если вы не знаете адрес:

  • Попробуйте имя хоста, которое вы задали в Raspberry Pi Imager, например http://raspberrypi.local. Для этого нужен mDNS, который работает в большинстве домашних сетей, а также в macOS, Linux и Windows 10 или новее.
  • Найдите устройство в списке подключённых клиентов вашего роутера.
  • Выполните на устройстве команду hostname -I.

Первая страница, которую вы увидите, — Приложение, так как у UAVcast-Pro пока нет лицензии. Боковая панель остаётся неактивной (Feature requires license), пока устройство не будет лицензировано.

Шаг 4: Активируйте лицензию​

В разделе Приложение → Менеджер лицензий вставьте ключ в поле Введите лицензионный ключ и выберите Проверить. Для этого устройству нужен доступ в интернет. Полный процесс, слоты устройств и перенос лицензии описаны в разделе Лицензирование и активация.

Шаг 5: Создайте пользователя-администратора​

В новой установке нет пользователей и входа: любой, у кого есть доступ к веб-интерфейсу, получает полные права администратора. Создайте учётную запись администратора до того, как дрон будет подключён к общей сети или интернету.

  1. Перейдите в Users на боковой панели (в разделе Управление).
  2. Выберите Add User.
  3. Введите Username (не менее 3 символов) и Password (не менее 6 символов). Первый пользователь всегда получает роль Admin.
  4. Выберите Create User.

С этого момента веб-интерфейс запрашивает вход. Сеансы действуют 7 дней. Учётные записи только для чтения см. в разделе Пользователи и доступ.

Что устанавливается​

КомпонентРасположение
Приложение, исполняемые файлы, база данных (uavcast.db), журналы/opt/uavcast-pro
Журнал установщика/opt/uavcast-pro/installer.log
Службы systemduavcast-web, uavcast-factory, mavlink-manager, uavcast-camera, uavcast-ntrip, uavcast-dns, mediamtx, internet-check
Конфигурация маршрутизатора MAVLink/etc/mavlink-router/main.conf (создаётся UAVcast-Pro, не редактируйте)

Проверьте, что веб-служба запущена:

Terminal
sudo systemctl status uavcast-web

Удаление​

У исполняемого файла установщика есть режим удаления. Он останавливает и удаляет все службы UAVcast-Pro, базу настроек и файлы программы в /opt/uavcast-pro, а также удаляет ZeroTier, Tailscale и Redis, если их установил UAVcast-Pro. Общие пакеты, такие как NetworkManager, ModemManager и GStreamer, остаются.

Terminal
sudo /opt/uavcast-pro/factory/ApplicationInstaller --uninstall

Начиная с UAVcast-Pro 6.5.3 записи полётов в /opt/uavcast-pro/recordings сохраняются. Добавьте --delete-recordings, чтобы удалить и их, или --purge-deps, чтобы удалить также ZeroTier, Tailscale и Redis, установленные до UAVcast-Pro. В более ранних версиях удаление стирает всю папку /opt/uavcast-pro вместе с записями, поэтому сначала скопируйте записи, которые хотите сохранить.

Сначала снимите устройство с регистрации

Удаление не освобождает слот лицензии. Снимите устройство с регистрации в разделе Приложение → Менеджер лицензий до очистки, иначе освободить слот можно будет только с помощью другого устройства. См. Лицензирование и активация.

Обновление с UAVcast-Pro 4.x или 5.x​

Версия 6 полностью переписана и не может импортировать настройки из версий 4.x или 5.x. Запишите настройки наземной станции, камеры и модема, установите свежую 64-битную ОС и затем установите версию 6.

Если установщик сообщает An older version of UAVcast-Pro has been detected at /opt/UAVcast-Pro, сначала удалите старую версию. Это удалит старые настройки:

Terminal
sudo rm -rf /opt/UAVcast-Pro

Если установка не удалась​

Сообщение или симптомРешение
No installation candidate for … found!ОС 32-битная или архитектура не поддерживается. Проверьте uname -m и перезапишите образ 64-битной версией.
Not enough free space. … need 500MBОсвободите место или используйте карту большего объёма.
Another process is currently using the system package managerВыполняется автоматическое обновление. Подождите несколько минут и запустите установщик снова.
Another installer is already runningДождитесь завершения первого установщика.
Installation completed with errors с красным ✗Запустите установщик снова. Если ошибка повторяется, отправьте /opt/uavcast-pro/installer.log на support@uavmatrix.com.
Веб-страница не открываетсяПроверьте sudo systemctl status uavcast-web, попробуйте IP-адрес вместо имени хоста и убедитесь, что порт 80 не занят другой программой.

Другие способы решения: Установка не удалась и Веб-интерфейс не открывается.
