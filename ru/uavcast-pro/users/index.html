Пользователи и доступ

В новой установке UAVcast-Pro нет ни пользователей, ни входа: любой, кто может открыть веб-интерфейс, получает полные права администратора. Добавьте пользователя-администратора, чтобы включить вход. После этого можно добавить пользователей с правами Read Only для наблюдателей, заказчиков или операторов полезной нагрузки, которые должны видеть всё, но ничего не менять. Откройте Управление → Users.

Включение входа​

  1. Перейдите в Users и выберите Add User.
  2. Введите Username (не менее 3 символов), Password (не менее 6 символов) и Confirm Password.
  3. Выберите Create User. Первый пользователь всегда получает роль Admin (First user must be an admin).

С этого момента каждый посетитель видит страницу входа. Сеанс входа сохраняется в этом браузере 7 дней или до тех пор, пока вы не выберете Выйти в меню пользователя внизу боковой панели.

Веб-интерфейс использует обычный HTTP

Логины и настройки передаются без шифрования. Это допустимо в вашей локальной сети или внутри VPN, но никогда не пробрасывайте порт веб-интерфейса в интернет.

Нельзя создать пользователя Read Only, пока не существует администратора (Create an admin user first before adding read-only users).

Пользователи веб-интерфейса с правами только для чтения отличаются от переключателя Read Only у пункта назначения наземной станции, который блокирует команды от программы наземной станции. См. Наземные станции.

Смена пароля​

Выберите Change Password, введите Current Password, затем дважды введите New Password, после чего выберите Update Password. Пароли хранятся в виде хешей bcrypt.

Удаление пользователя​

Выберите Delete в строке пользователя и подтвердите действие.

  • Нельзя удалить собственную учётную запись, пока существуют другие пользователи.
  • Удаление последнего пользователя снова отключает вход: After deletion, the application will be open without authentication until a new user is created.

Забыли пароль администратора​

Ссылки для сброса нет: у дрона нет электронной почты, а восстановление пароля не выполняется самостоятельно.

  • Если другой администратор может войти, он может удалить вашу учётную запись в разделе Users и создать её заново.
  • Если ни один пользователь с ролью администратора не может войти, свяжитесь с поддержкой по адресу support@uavmatrix.com. Укажите ваш лицензионный ключ (или адрес электронной почты, с которым вы его покупали), имя хоста или название устройства, как оно отображается в разделе Приложение → Менеджер лицензий → Активированные устройства, версию UAVcast-Pro и доступно ли устройство по SSH.
