# Инжекторы

> Используйте инжекторы UAVcast-Pro, чтобы передавать показания датчиков из скриптов, Arduino или LTE-модема в поток MAVLink по HTTP, UDP или последовательному порту, чтобы QGC и Mission Planner их видели.

Инжектор передаёт данные извне UAVcast-Pro, например из Python-скрипта, Arduino или датчика в сети, в поток MAVLink в виде сообщений `NAMED_VALUE_FLOAT` (или `NAMED_VALUE_INT`). Каждая подключённая наземная станция получает значения как обычную телеметрию: Mission Planner показывает их на вкладке **Status**, а QGroundControl — в MAVLink Inspector. Они также автоматически появляются на панелях [Потоков данных](https://docs.uavmatrix.com/ru/uavcast-pro/data-streams/). Откройте **Полётный контроллер → Инжекторы**.

Типичные сценарии: датчики радиации, газа или погоды на бортовом компаньоне, значения сигнала LTE (RSRP, SINR) для контроля связи или значения, которые вычисляют ваши собственные скрипты.

## Выбор транспорта

| Тип | Как поступают данные | Лучше всего подходит для |
| --- | --- | --- |
| **HTTP** | Отправка JSON методом POST на уникальный URL с секретным токеном | Проще всего. Подойдёт всё, что умеет отправлять HTTP-запросы. |
| **UDP** | Пакеты на порт дрона в виде строк `NAME=VALUE` или JSON | Минимальные накладные расходы, доверенные локальные сети. Без аутентификации. |
| **Serial** | Строки, считываемые с устройства `/dev/tty*` | Проводные датчики, например Arduino по USB. |

Тип нельзя изменить после создания инжектора.

## Создание инжектора

1. Перейдите в **Полётный контроллер → Инжекторы** и нажмите **Добавить инжектор**.
2. Введите **Имя** (отображается только в интерфейсе) и выберите **Тип ввода**.
3. Оставьте **sysid MAVLink** равным `1`, чтобы значения относились к тому же аппарату, что и полётный контроллер, и **compid MAVLink** равным `194` (полезная нагрузка пользователя), если не требуется иное.
4. По желанию задайте **Префикс имени**, например `BAL_`, чтобы `RAD1` отправлялся как `BAL_RAD1`.
5. Для UDP или Serial заполните настройки слушателя. Затем нажмите **Создать**.
6. Нажмите **Отправить тестовый сигнал** на карточке инжектора, чтобы отправить значение и проверить его в наземной станции.

## Отправка данных

**HTTP**

После создания HTTP-инжектора на его карточке отображается **HTTP-эндпойнт**. URL имеет вид `http://<drone-ip>/api/inject/<token>` и проходит через обычный порт веб-интерфейса. Кнопка **Скопировать URL** копирует его.

```bash
curl -X POST http://192.168.1.50/api/inject/<token> \
  -H "Content-Type: application/json" \
  -d '{"name":"RAD1","value":0.077}'
```

```bash
curl -X POST http://192.168.1.50/api/inject/<token> \
  -H "Content-Type: application/json" \
  -d '{"samples":[{"name":"TEMP","value":21.4},{"name":"HUM","value":48}]}'
```

В ответе приводятся счётчики: `{"accepted":2,"rateLimited":0,"rejected":0}`. Единственная защита — токен. Если он утёк, нажмите **Сменить токен** и обновите клиент.

**UDP**

По умолчанию инжектор слушает **Порт** `14600` и **Адрес прослушивания** `0.0.0.0` (все интерфейсы). Используйте `127.0.0.1`, если отправитель работает на самом дроне.

```bash
echo "RAD1=0.077" | nc -u -w1 192.168.1.50 14600
```

```python
import json, socket
s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.sendto(json.dumps({"name": "RAD1", "value": 0.077}).encode(), ("192.168.1.50", 14600))
```

**Serial**

Инжектор считывает строки, завершающиеся переводом строки, с **Путь к устройству** (по умолчанию `/dev/ttyUSB0`) на скорости **Скорость (бод)** (по умолчанию `115200`). Каждая строка — один отсчёт: `NAME=VALUE` для протокола Key=Value или объект JSON. Если устройство отключили, инжектор переподключается к нему автоматически.

```cpp
void setup() { Serial.begin(115200); }
void loop() {
  Serial.print("LIGHT=");
  Serial.println(analogRead(A0));
  delay(200);
}
```

> **Имена MAVLink ограничены 10 символами**
>
> Имена `NAMED_VALUE_FLOAT` ограничены 10 символами, включая префикс. Делайте префикс коротким (до 8 символов), а имена — компактными.

## Справочник настроек

| Параметр | По умолчанию | Значения | Примечания |
| --- | --- | --- | --- |
| **Имя** | пусто | текст | Подпись только в интерфейсе. |
| **Тип ввода** | **HTTP** | **HTTP**, **UDP**, **Serial** | Нельзя изменить после создания. |
| **Включено** | Вкл. | Вкл., выкл. | Выкл. сохраняет настройки, но останавливает слушатель. |
| **sysid MAVLink** | `1` | 1–255 | Значения группируются с этим аппаратом так же, как у полётного контроллера. |
| **compid MAVLink** | `194` | 0–255 | 194 часто используется для датчиков полезной нагрузки пользователя. |
| **Префикс имени** | пусто | до 8 ASCII-символов | Добавляется перед каждым именем сигнала. |
| **Лимит частоты (Гц на сигнал)** | `10` | отсчётов в секунду | Лишние отсчёты отбрасываются и учитываются как **Ограничено**. Защищает связь от неконтролируемого отправителя. |
| **Протокол** (UDP, Serial) | **Key=Value (line-delimited)** | **Key=Value (line-delimited)**, **JSON** (`{name, value}`) |  |
| **Порт** (UDP) | `14600` | 1–65535 |  |
| **Адрес прослушивания** (UDP) | `0.0.0.0` | IP-адрес | `127.0.0.1` принимает только локальных отправителей. |
| **Путь к устройству** (Serial) | `/dev/ttyUSB0` | путь к устройству | Чтобы его найти, выполните `ls /dev/tty*`. |
| **Скорость (бод)** (Serial) | `115200` |  | Должна совпадать с отправителем. |

Каждая карточка показывает счётчики **Принято**, **Ограничено** и **Отклонено**, поэтому видно, поступают ли данные и корректны ли они.

Инжекторы работают внутри служб UAVcast-Pro и запускаются при загрузке, поэтому значения продолжают поступать, даже когда веб-интерфейс закрыт.
