# Вкладка Радио

> Смотрите значения PWM RC-каналов и RSSI с полётного контроллера на вкладке Радио UAVcast-Pro, чтобы проверить переключатели передатчика и переключение камер по RC-каналу.

Вкладка Радио показывает RC-сигнал, который полётный контроллер получает от вашего передатчика: значение PWM каждого канала и RSSI (уровень сигнала). Используйте её, чтобы проверить назначение переключателей, например канал для [переключения камер по RC](https://docs.uavmatrix.com/ru/uavcast-pro/camera/multi-camera/), без подключения наземной станции. Откройте **Карта Полёта → Радио**.

![Вкладка Радио: значок RSSI, четыре основных канала и вспомогательные каналы, все со значением 0](https://docs.uavmatrix.com/ru/img/screenshots/uavcast-pro/flight-map--radio.webp)

*Карта Полёта → Радио на стендовом устройстве без RC-приёмника, поэтому все каналы показывают 0.*

## Что вы увидите

- **RSSI**: уровень сигнала приёмника по данным полётного контроллера; оценка может быть **No Signal**, **Weak**, **Fair**, **Good** или **Excellent**. Для работы нужна настройка RSSI на полётном контроллере (`RSSI_TYPE` в ArduPilot).
- **Основное Управление**: **Канал 1 - Крен**, **Канал 2 - Тангаж**, **Канал 3 - Газ** и **Канал 4 - Рыскание** в раскладке Mission Planner.
- **Вспомогательные Каналы**: остальные каналы.

Значения PWM обычно находятся в диапазоне от 1000 (минимум) до 2000 (максимум). Если канал не меняется, значит, он не назначен на передатчике или приёмник его не передаёт.

Значения поступают из сообщения `RC_CHANNELS` полётного контроллера, поэтому обновляются только при статусе **Подключено** для связи с полётным контроллером.
