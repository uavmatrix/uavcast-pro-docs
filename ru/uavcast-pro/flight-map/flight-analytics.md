# Аналитика полёта

> Постройте графики живой телеметрии MAVLink или записанного файла .tlog в UAVcast-Pro Flight Analytics. Выберите до 10 параметров, сравните их во времени и разберите полёт на дроне.

Аналитика полёта строит графики значений MAVLink во времени — либо живых с полётного контроллера, либо по записанному файлу `.tlog`. Используйте её, чтобы проверить вибрацию, просадку батареи, удержание высоты или значения сигнала, без копирования журналов на ПК. Откройте **Карта Полёта → Аналитика полёта**.

## Построение графика живой телеметрии

1. Выберите **Прямой Эфир**. Список параметров заполняется по мере поступления сообщений. Если появляется *Ожидание Данных MAVLink*, сначала подключите полётный контроллер.
2. В поле **Поиск параметров...** найдите нужные значения и отметьте их для построения. Можно построить до **10** значений одновременно.
3. Включите **Накапливать Данные**, чтобы сохранять все точки (*Storing all data points*). Если опция выключена, график хранит скользящее окно (*Last … points*).

## Анализ записанного журнала

1. Нажмите **Открыть Файл Журнала**.
2. В окне **Выбрать Файл Журнала** выберите записанный `.tlog`. Журналы телеметрии берутся из [Записей](https://docs.uavmatrix.com/ru/uavcast-pro/camera/recordings/) (по умолчанию по одному на каждый взведённый полёт).
3. Отметьте параметры для построения. Вверху отображаются **Длительность** и количество **Параметров** в файле.

**Очистить Все** удаляет все построенные параметры.

## Откуда берутся журналы

Телеметрия записывается на дроне в соответствии с настройкой **Записывать телеметрию** в разделе **Камера → Записи → Настройки**: **Когда взведён** (по умолчанию), **Всегда при подключении** или **Выкл.** Те же файлы `.tlog` открываются в Mission Planner, MAVExplorer и UAV Log Viewer.

На боковой вкладке **Записи** в Карте Полёта те же журналы телеметрии перечислены с **Сообщения**, **Макс. высота** и **Расстояние**. Журнал можно **Скачать .tlog**, **Удалить** или **Воспроизвести**. Воспроизведение передаёт записанную телеметрию на карту так, как будто дрон летит.
