Порты и протоколы

Используйте эту страницу, чтобы настроить брандмауэры на наземной станции, в сети дрона и в корпоративных сетях. Показаны значения по умолчанию; там, где порт можно изменить, указана соответствующая настройка.

Наземная станция: входящий трафик​

UAVcast-Pro отправляет телеметрию и видео на каждую наземную станцию. Наземной станции нужно только принимать входящий UDP; на дроне для этого ничего слушать не нужно.

Порт (по умолчанию)ПротоколНазначениеНастройка
14550UDPТелеметрия MAVLink, в обе стороны, как только GCS отвечаетНаземные станции → Порт телеметрии
5600UDPВидео: H.264 в RTP, тип полезной нагрузки 96Порт видео
Порт видео + 1 (5601)UDPВидео камеры 2, когда включено Два потокаПорт видео (Камера 2) (пусто = Порт видео + 1)
Порт видео + 2 (5602)UDPАудио: Opus в RTP, тип полезной нагрузки 97, когда включено Передавать звук на наземные станцииСледует за Порт видео
Порт TCP 5760 закрыт

Начиная с v6.5.0 маршрутизатор телеметрии не слушает TCP 5760. Наземные станции подключаются по UDP к пунктам назначения, которые вы добавили.

С привязками потоков Fleet Manager первый дрон, привязанный к наземной станции, использует 5600/14550, а каждый следующий дрон получает собственный блок портов: порт видео с местом для камеры 2 и аудио после него, а также порт телеметрии. Смотрите порты в каждой привязке.

Дрон: службы, к которым вы подключаетесь​

ПортПротоколНазначениеПримечания
80TCP (HTTP)Веб-интерфейсМеняется в Приложение → Настройки → Порт сервера (80 или выше).
8889TCP (HTTP)Предварительный просмотр в браузере (WebRTC)Используется в Камера → Предварительный просмотр и в окнах видео на карте полёта.
8189UDPМедиа WebRTC для предварительного просмотраЗначение медиасервера по умолчанию.
9996TCP (HTTP)Воспроизведение записейИспользуется библиотекой записей и плеером разбора полёта.
8554TCP (RTSP)Копия потока камеры по RTSP (/camera, /camera2)Доступна, пока включены предварительный просмотр или запись.
8888TCP (HTTP)Копия потока камеры по HLSВеб-интерфейсом не используется.
HTTP-инжекторTCP (HTTP)http://<drone>/api/inject/<token>Обслуживается на порту веб-интерфейса. См. Инжекторы.
UDP-инжекторUDPНа ваш выбор (14600 — безопасное значение по умолчанию)Задаётся для каждого инжектора в Полётный контроллер → Инжекторы.

Через VPN эти порты должны быть доступны по VPN-адресу дрона. На стороне сотовой связи проброс портов не требуется.

Дрон: исходящий трафик​

Дрон сам открывает эти соединения. Сети, которые пропускают только веб-трафик, будут блокировать некоторые из них.

НазначениеПортПротоколЧто передаётся
Наземные станции14550, 5600 (+1, +2)UDPТелеметрия, видео, аудио
uavmatrix.com443HTTPSАктивация лицензии и периодические проверки
install.uavmatrix.com443HTTPSУстановщик и обновления
fleet-manager.uavmatrix.com443HTTPSСопряжение с Fleet Manager
Брокер Fleet Manager8883MQTT через TLS (клиентские сертификаты)Статус, телеметрия и команды Fleet Manager
vpn-connect.uavmatrix.com443HTTPSСервер входа в VPN Fleet Manager
Ваш кастер NTRIP2101 (или как задано)TCP, опционально TLSПоправки RTCM
ZeroTier / TailscaleZeroTier 9993, Tailscale 41641 (и 443 как запасной)UDPТуннели VPN
Ваш провайдер DNS443HTTPSОбновления динамического DNS

Внутри дрона (только локально)​

Эти порты используются между собственными службами UAVcast-Pro и не требуют правил брандмауэра:

ПортНазначение
6379Redis, внутренняя шина сообщений
12550, 12551Маршрутизатор телеметрии к приложению UAVcast-Pro и к клиенту NTRIP
8090HTTP-слушатель инжектора (доступен через /api/inject/… на порту 80)
9997API медиасервера
5000API фоновой службы UAVcast-Pro, используется веб-интерфейсом

Правила брандмауэра для наземной станции​

  • Windows
  • Linux (UFW)
PowerShell (Administrator)PowerShell
New-NetFirewallRule -DisplayName "MAVLink Telemetry" -Direction Inbound -Protocol UDP -LocalPort 14550 -Action Allow
New-NetFirewallRule -DisplayName "UAV Video" -Direction Inbound -Protocol UDP -LocalPort 5600-5602 -Action Allow
Terminal
sudo ufw allow 14550/udp comment 'MAVLink Telemetry'
sudo ufw allow 5600:5602/udp comment 'UAV Video and audio'

Добавьте другие порты, если вы используете другие порты телеметрии или видео либо несколько дронов через привязки потоков Fleet Manager.
