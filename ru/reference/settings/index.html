Справочник настроек

Каждая настройка веб-интерфейса UAVcast-Pro, сгруппированная по страницам, с подписью точно такой, как в приложении, и значением по умолчанию на новой установке. Страницы, которые меняют настройки сразу, применяют их без задержки, если не указано иное. Страницы функций подробно объясняют каждую область; эта страница нужна для быстрого поиска.

Полётный контроллер → Подключение​

НастройкаПо умолчаниюЗначения и примечания
Link enabledВкл.Включает или выключает связь с полётным контроллером.
Link typeUSBUSB (собственный USB-порт полётного контроллера) или UART / Serial (порт TELEM на контактах GPIO или через USB-serial кабель).
PortАвтоматическиАвтоматически находит полётный контроллер и следует за ним, если номер устройства меняется. Пользовательский путь… принимает устройство, например /dev/ttyAMA0.
Baud rateАвтоматическиДолжна совпадать с SERIALx_BAUD на полётном контроллере. Автоматический режим перебирает 57600, 115200, 921600, 1500000, 460800, 230400 и 500000. Для USB не используется.

Кнопки: Автоопределение (проверить все порты и скорости и сохранить результат), Подключить, Перезапустить связь, Остановить. Изменения применяются сразу, без перезапуска.

НастройкаПо умолчаниюЗначения и примечания

Порт2101Некоторые кастеры с TLS используют 2102 или 443.
Точка монтированияпустоВыберите через Просмотреть точки монтирования.

Имя пользователя / Парольпустоrtk2go.com: адрес электронной почты в качестве имени пользователя, пароль не нужен.
Отправлять GGA вверх по потокуВкл.Нужно кастерам VRS и кастерам с ближайшей точкой монтирования.
Интервал отправки (секунды)10
Источник позицииТекущая позиция от полётного контроллераИли Фиксированная позиция вручную (Широта, Долгота, Высота (м)), которая также используется как запасной вариант до первого фикса GPS.

Полётный контроллер → Инжекторы​

НастройкаПо умолчаниюЗначения и примечания
Тип вводаHTTP, UDP или Serial. После создания изменить нельзя.
sysid MAVLink1Как у полётного контроллера.
compid MAVLink194Пользовательская нагрузка.
Префикс именипустоДо 8 ASCII-символов, добавляется в начало каждого имени сигнала.
Лимит частоты (Гц на сигнал)Максимальное количество отсчётов в секунду на каждое имя сигнала.
Протокол (UDP, Serial)Key=Value (построчно) или JSON ({name, value}).
Порт / Адрес прослушивания (UDP)Выберите свободный порт, например 14600. 0.0.0.0 = все интерфейсы, 127.0.0.1 = только локально.
Путь к устройству / Скорость (бод) (Serial)Например /dev/ttyUSB0; скорость (бод) должна совпадать с отправителем.

Наземные станции​

Одна карточка на каждый пункт назначения.

НастройкаЗначение по умолчанию для нового пункта назначенияЗначения и примечания
НазваниепустоДо 50 символов.
IP-адрес или хост назначенияпустоIPv4-адрес. Обязателен, прежде чем можно включить видео или телеметрию.
Порт телеметрии145501–65535.
Порт видео56001–65535.
Порт видео (Камера 2)пусто (= Порт видео + 1)Показывается, только когда включено Два потока.
Включить конечную точкуВкл.Выключение останавливает всё для этого пункта назначения: телеметрию, видео и аудио.
Включить видеоВыкл.
Включить телеметриюВыкл.
Read OnlyВыкл.Наземная станция получает телеметрию, но не может ничего изменить на аппарате. Это действует начиная с UAVcast-Pro 6.5.3; в более ранних версиях Read Only не блокирует запись параметров.

Битрейт (звук)64 kbps
Передавать звук на наземные станцииВыкл.RTP/Opus на каждый видеопункт назначения на Порт видео + 2.
