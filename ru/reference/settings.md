# Справочник настроек

> Все настройки UAVcast-Pro на одной странице с точной подписью, значением по умолчанию и диапазоном: полётный контроллер, NTRIP, наземные станции, камера, запись, модем, VPN.

Каждая настройка веб-интерфейса UAVcast-Pro, сгруппированная по страницам, с подписью точно такой, как в приложении, и значением по умолчанию на новой установке. Страницы, которые меняют настройки сразу, применяют их без задержки, если не указано иное. Страницы функций подробно объясняют каждую область; эта страница нужна для быстрого поиска.

## Полётный контроллер → Подключение

| Настройка | По умолчанию | Значения и примечания |
| --- | --- | --- |
| **Link enabled** | Вкл. | Включает или выключает связь с полётным контроллером. |
| **Link type** | **USB** | **USB** (собственный USB-порт полётного контроллера) или **UART / Serial** (порт TELEM на контактах GPIO или через USB-serial кабель). |
| **Port** | **Автоматически** | Автоматически находит полётный контроллер и следует за ним, если номер устройства меняется. **Пользовательский путь…** принимает устройство, например `/dev/ttyAMA0`. |
| **Baud rate** | **Автоматически** | Должна совпадать с `SERIALx_BAUD` на полётном контроллере. Автоматический режим перебирает 57600, 115200, 921600, 1500000, 460800, 230400 и 500000. Для USB не используется. |

Кнопки: **Автоопределение** (проверить все порты и скорости и сохранить результат), **Подключить**, **Перезапустить связь**, **Остановить**. Изменения применяются сразу, без перезапуска.

## Полётный контроллер → Инжекторы

| Настройка | По умолчанию | Значения и примечания |
| --- | --- | --- |
| **Тип ввода** |  | **HTTP**, **UDP** или **Serial**. После создания изменить нельзя. |
| **sysid MAVLink** | `1` | Как у полётного контроллера. |
| **compid MAVLink** | `194` | Пользовательская нагрузка. |
| **Префикс имени** | пусто | До 8 ASCII-символов, добавляется в начало каждого имени сигнала. |
| **Лимит частоты (Гц на сигнал)** |  | Максимальное количество отсчётов в секунду на каждое имя сигнала. |
| **Протокол** (UDP, Serial) |  | **Key=Value (построчно)** или **JSON** (`{name, value}`). |
| **Порт** / **Адрес прослушивания** (UDP) |  | Выберите свободный порт, например 14600. `0.0.0.0` = все интерфейсы, `127.0.0.1` = только локально. |
| **Путь к устройству** / **Скорость (бод)** (Serial) |  | Например `/dev/ttyUSB0`; скорость (бод) должна совпадать с отправителем. |

## Наземные станции

Одна карточка на каждый пункт назначения.

| Настройка | Значение по умолчанию для нового пункта назначения | Значения и примечания |
| --- | --- | --- |
| **Название** | пусто | До 50 символов. |
| **IP-адрес или хост назначения** | пусто | IPv4-адрес. Обязателен, прежде чем можно включить видео или телеметрию. |
| **Порт телеметрии** | `14550` | 1–65535. |
| **Порт видео** | `5600` | 1–65535. |
| **Порт видео (Камера 2)** | пусто (= Порт видео + 1) | Показывается, только когда включено **Два потока**. |
| **Включить конечную точку** | Вкл. | Выключение останавливает всё для этого пункта назначения: телеметрию, видео и аудио. |
| **Включить видео** | **Выкл.** |  |
| **Включить телеметрию** | **Выкл.** |  |
| **Read Only** | Выкл. | Наземная станция получает телеметрию, но не может ничего изменить на аппарате. Это действует начиная с UAVcast-Pro 6.5.3; в более ранних версиях Read Only не блокирует запись параметров. |

## Камера → Настройки камеры

| Настройка | По умолчанию | Значения и примечания |
| --- | --- | --- |
| **Включить камеру?** | Да |  |
| **Выберите камеру** | Камера Raspberry Pi | Обнаруженные CSI- и USB-камеры. |
| **Разрешение** | 640×480 | Предлагаются только размеры, которые поддерживает камера. |
| **Выберите FPS** | **Авто** | Камера согласует значение. |
| **Битрейт:** | `0` (авто) | 0–10000 kbps. |
| **Скорость Восстановления Потока** | **Авто** | Интервал ключевых кадров. Авто = один ключевой кадр в секунду. Более высокие уровни быстрее восстанавливают поток после потери пакетов, но расходуют больше полосы. |
| **Поворот:** / **Настройки Отражения** | 0°, без отражения | **Отразить по горизонтали**, **Отразить по вертикали**. |
| **Включить Предпросмотр в Реальном Времени?** | Да | Предварительный просмотр на этой странице и на карте полёта. |
| **Пользовательский Пайплайн** | тестовый конвейер | Переопределяет пункты назначения наземных станций. Не указывайте префикс `gst-launch-1.0`. |
| **Включить переключение камеры по RC каналу** | Выкл. |  |
| **RC Канал** | 7 | PWM < 1500 = Камера 1, PWM > 1500 = Камера 2. |
| **Сопоставить Разрешение Камеры 1** | Выкл. | Камера 2 снимает в разрешении камеры 1. |
| **Два потока** | Выкл. | Передаёт оба потока одновременно. |
| **Звук** | Выкл. | Аудио Opus в предварительном просмотре. |
| **Аудиоустройство** | **Авто (микрофон камеры, если есть)** | Или устройство захвата, или **Тестовый тон (микрофон не нужен)**. |
| **Битрейт** (звук) | 64 kbps |  |
| **Передавать звук на наземные станции** | Выкл. | RTP/Opus на каждый видеопункт назначения на Порт видео + 2. |
