# Глоссарий

> Простые объяснения терминов из документации UAVcast-Pro и Fleet Manager: MAVLink, GCS, heartbeat, APN, HiLink, NTRIP, RTCM, VRS, ZeroTier, Tailscale.

### AGL / AMSL (высота над землёй и над уровнем моря)

Высота над землёй (здесь: над точкой взлёта) и над средним уровнем моря. UAVcast-Pro использует эти термины начиная с v6.5.0, заменив REL и MSL.

### APN (имя точки доступа)

Название шлюза оператора связи, через который подключается сотовый модем. UAVcast-Pro определяет его автоматически, когда поле **Имя точки доступа (APN) (Необязательно)** пустое.

### ArduPilot

Открытая прошивка автопилота для мультикоптеров, самолётов, VTOL, наземных роверов и лодок. UAVcast-Pro работает с ArduPilot и с любым другим полётным контроллером MAVLink, например PX4. Кнопки полётных режимов используют названия режимов ArduPilot.

### Ключ аутентификации (Auth key)

Ключ Tailscale, который входит устройство в tailnet без браузера. Fleet Manager использует ключи аутентификации, чтобы подключать наземные станции к VPN организации.

### Битрейт (Bitrate)

Сколько бит в секунду производит видеокодер. Битрейт должен укладываться в восходящий канал вашего соединения с запасом.

### CSI-камера

Камера, подключённая к ленточному разъёму Raspberry Pi, например Camera Module 3.

### Пункт назначения (Destination)

В UAVcast-Pro — запись наземной станции в разделе **Наземные станции**: IP-адрес с портом телеметрии и портом видео.

### Два потока (Dual stream)

Одновременная передача видео с двух камер на наземную станцию по двум портам видео.

### Fleet Manager

Веб-панель UAVmatrix для мониторинга и управления множеством дронов UAVcast-Pro в одной организации.

### GCS (наземная станция управления)

Программа и компьютер, на котором она работает, с помощью которых вы следите за дроном и управляете им: QGroundControl, Mission Planner, MAVProxy.

### Failsafe GCS

Настройка полётного контроллера, которая заставляет дрон действовать самостоятельно (вернуться, сесть или зависнуть), когда он перестаёт получать сигнал от наземной станции.

### GGA

Сообщение NMEA с вашей позицией. Кастерам VRS и кастерам с ближайшей точкой монтирования оно нужно, чтобы вычислять поправки для вашего местоположения.

### H.264

Формат сжатия видео, который отправляет UAVcast-Pro. Его может декодировать любая распространённая наземная станция.

### Heartbeat (сигнал активности)

Сообщение MAVLink, которое полётный контроллер отправляет примерно раз в секунду, чтобы сообщить «я здесь». *Нет heartbeat* означает, что по каналу не передаётся читаемый MAVLink.

### Модем HiLink (HiLink modem)

USB-модем со встроенным маршрутизатором, который подключается сам и отображается в Linux как сетевой адаптер.

### Инжектор (Injector)

Слушатель UAVcast-Pro (HTTP, UDP или последовательный порт), который преобразует значения ваших собственных датчиков в сообщения MAVLink `NAMED_VALUE_FLOAT`.

### Ключевой кадр (Keyframe)

Полный видеокадр, с которого декодер может начать воспроизведение. Чем чаще ключевые кадры, тем быстрее восстановление после потери пакетов. Задаётся настройкой **Скорость Восстановления Потока**.

### MAVLink

Протокол обмена сообщениями между полётными контроллерами и наземными станциями.

### Точка монтирования (Mountpoint)

Именованный поток поправок на кастере NTRIP, обычно привязанный к одной базовой станции или к службе VRS.

### MQTT

Протокол обмена сообщениями, по которому дроны связываются с Fleet Manager; шифруется TLS на порту 8883.

### NTRIP / кастер NTRIP

Протокол и сервер для передачи поправок GNSS через интернет.

### Код сопряжения (Pairing code)

8-значный код, который UAVcast-Pro показывает, когда вы подключаете дрон к Fleet Manager. Действителен 5 минут, используется один раз.

### Read Only (пункт назначения)

Пункт назначения наземной станции, который получает телеметрию, но не может ничего изменить на аппарате: команды, смена режимов, а также запись параметров и миссий из него заблокированы. Это действует начиная с UAVcast-Pro 6.5.3; в более ранних версиях Read Only не блокирует запись параметров.

### Read Only (пользователь)

Роль пользователя UAVcast-Pro, который может просматривать страницы, но не может менять настройки или управлять дроном.

### RTCM3

Стандартный формат сообщений для поправок GNSS.

### RTK, RTK Float и RTK Fixed

Позиционирование в реальном времени с поправками. Float — приблизительное решение; Fixed — решение с точностью до сантиметров.

### RTP / UDP

Транспорт, который UAVcast-Pro использует для видео и телеметрии: быстрый, без повторных передач, что держит задержку низкой.

### SERIALx_PROTOCOL / SERIALx_BAUD

Параметры ArduPilot, которые задают, какой протокол использует последовательный порт (2 = MAVLink2), и его скорость.

### Привязка потока (Stream binding)

В Fleet Manager — связь, которая отправляет видео и телеметрию одного дрона на одну наземную станцию по её собственным портам.

### sysid / compid

ID системы MAVLink (какой аппарат) и ID компонента (какая его часть). Полётный контроллер обычно имеет sysid 1, compid 1.

### Tailnet

Частная сеть Tailscale.

### Tailscale

VPN на основе WireGuard. UAVcast-Pro может подключаться к вашему tailnet или к сети организации Fleet Manager.

### UAVnet

Размещённый контроллер сети ZeroTier компании UAVmatrix по адресу uavnet.uavmatrix.com. Он выводится из эксплуатации в пользу VPN Fleet Manager; существующим пользователям следует перейти на Fleet Manager.

### VRS (виртуальная опорная станция)

Сервис поправок, который вычисляет поправки для вашей позиции по сети базовых станций. Требует отправки GGA (GGA upstream).

### ZeroTier

Одноранговая VPN. UAVcast-Pro может подключаться к вашей собственной сети ZeroTier.

Source: https://docs.uavmatrix.com/ru/reference/glossary/
