Поддерживаемое оборудование

UAVcast-Pro v6 работает на любом 64-битном Linux-компьютере с Raspberry Pi OS, Debian или Ubuntu, на архитектуре arm64 или amd64 (платы arm64, кроме Raspberry Pi, поддерживаются начиная с UAVcast-Pro 6.5.3). В таблицах ниже перечислено то, что обнаруживается и протестировано. Сведения о блоках питания, проводке и выборе покупки см. в разделе Требования к оборудованию.

Платы arm64, отличные от Raspberry Pi

Jetson, Orange Pi, Banana Pi и другие платы arm64, которые не являются Raspberry Pi, требуют UAVcast-Pro 6.5.3 или новее. Старые установщики на них останавливаются с сообщением Device is not a Raspberry Pi.

Только для Raspberry Pi: CSI-камеры (rpicam/libcamera) работают только на Raspberry Pi. На Pi установщик включает UART, отключает последовательную консоль и на Pi 3/4/Zero 2 W отключает Bluetooth, чтобы полный UART был свободен.

Операционные системы​

ОССтатус
Raspberry Pi OS (64-bit)Рекомендуется на Raspberry Pi. Нужна для CSI-камер.
Debian (64-bit)Поддерживается.
Ubuntu (64-bit), включая Ubuntu for Raspberry PiПоддерживается. CSI-камеры на Pi в Ubuntu не работают, так как стек камер Raspberry Pi в нём не упакован; USB-камеры работают.
Любая 32-битная ОСНе поддерживается. Установщик останавливается с сообщением No installation candidate.

Полётные контроллеры​

UAVcast-Pro v6 работает с любым полётным контроллером MAVLink через USB или порт TELEM: ArduPilot (Copter, Plane, Rover, VTOL и другие типы аппаратов) и PX4 на платах семейств Pixhawk и Cube, а также Matek, Holybro, CUAV и других. Названия полётных режимов и кнопки режимов на карте полёта и в Fleet Manager соответствуют ArduPilot; при использовании PX4 меняйте режимы из вашей наземной станции.

Приёмники RTK GPS​

Поправки NTRIP требуют приёмника с поддержкой RTK (фазовые измерения несущей) на полётном контроллере, например модули на основе u-blox ZED-F9P, CubePilot Here3+ или Septentrio Mosaic. Стандартные навигационные модули, такие как M8N, M9N или M10, не могут использовать поправки RTK.
