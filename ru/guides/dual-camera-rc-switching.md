# Две камеры: переключение по RC или двойной поток

> Подключите две камеры к UAVcast-Pro и переключайтесь между ними с пульта RC или передавайте обе сразу в режиме двойного потока. Настройка, порты и нагрузка на CPU.

UAVcast-Pro работает с двумя камерами, например с передней камерой и камерой, направленной вниз, или с камерой с зумом. Вы выбираете один из двух режимов:

|  | **Переключение** (по умолчанию) | **Двойной поток** |
| --- | --- | --- |
| Что получает наземная станция | Один видеопоток с камерой 1 или камерой 2 | Два видеопотока одновременно |
| Как выбрать | Значки камер в веб-интерфейсе или канал RC | Обе камеры всегда активны |
| Порты | **Порт видео** | Камера 1 на **Порт видео**, камера 2 на **Порт видео (Камера 2)** (по умолчанию: Порт видео + 1) |
| Нагрузка на CPU и полоса | Одно кодирование | Два кодирования, примерно вдвое больший исходящий канал |

## 1. Добавьте вторую камеру

1. Подключите обе камеры. Две CSI-камеры на Pi 5, CSI- и USB-камера или две USB-камеры — всё работает.
2. Откройте **Камера → Настройки камеры**. В слотах камер отображаются **КАМ 1** и **КАМ 2**.
3. Нажмите **Добавить Камеру** во втором слоте и выберите камеру.
4. **Разрешение и FPS камеры 1 будут использоваться** в режиме переключения. Если камера 2 поддерживает разрешение камеры 1, включите **Сопоставить Разрешение Камеры 1**; иначе камера 2 использует собственное разрешение и масштабируется под него.

Если камеры нет в списке, см. [Камера не обнаружена](https://docs.uavmatrix.com/ru/troubleshooting/camera-not-detected/).

## 2a. Переключение камер с пульта

1. В разделе **Переключение по RC Каналу** включите **Включить переключение камеры по RC каналу**.
2. Выберите свободный канал в поле **RC Канал**. По умолчанию используется канал 7.
3. Назначьте двухпозиционный переключатель на пульте этому каналу.
4. Переключите тумблер и наблюдайте за **Текущий PWM**: ниже 1500 мкс выбирается камера 1, выше 1500 мкс — камера 2.

![Панель управления камерой: Включить камеру — Да, заполнен КАМ 1, пустой слот Добавить Камеру](https://docs.uavmatrix.com/ru/img/screenshots/uavcast-pro/camera--control-panel.webp)

*Панель управления камерой с одной камерой. Панель «Переключение по RC Каналу» появляется под ней только после добавления КАМ 2 и при выключенном двойном потоке.*

Пока переключение по RC включено, значки камер в веб-интерфейсе не переключают камеры. Выключите переключение по RC, чтобы снова выбирать камеры вручную.

## 2b. Передача обеих камер одновременно

1. Включите **Два потока**. Значок показывает **Обе активны**.
2. Теперь у каждой камеры есть собственные разрешение, FPS и битрейт в разделе **Настройки для каждой камеры**.
3. Откройте **Наземные станции**. Для каждого пункта назначения теперь отображается **Порт видео (Камера 2)**. Оставьте поле пустым, чтобы использовать **Порт видео** + 1 (5601), или введите порт.
4. На наземной станции принимайте второй поток на этом порту, например, с помощью второго источника видео в QGroundControl или окна GStreamer: см. [Наземные станции и видео](https://docs.uavmatrix.com/ru/uavcast-pro/ground-stations/#set-up-the-receiving-side) для QGroundControl, Mission Planner и GStreamer в каждой ОС.

> **Следите за нагрузкой на CPU**
>
> UAVcast-Pro кодирует видео программно. При двух потоках следите за **Загрузка системы**. Когда появится сообщение **Процессор близок к пределу**, уменьшите разрешение или битрейт одного потока либо выключите второй поток. Для двойного потока рекомендуется Raspberry Pi 4 или 5.

**Карта Полёта** показывает отдельное окно видео для каждого активного потока. Их можно скрыть в виде вкладок внизу карты.

## Планирование портов

При включённом двойном потоке каждый пункт назначения использует два видеопорта, а аудио (если включено **Передавать звук на наземные станции**) использует видеопорт + 2. Если вы добавляете больше пунктов назначения на одном компьютере, разнесите их видеопорты минимум на три, например 5600 и 5610. Порты, расположенные ближе, конфликтуют, как только включается двойной поток или аудио.

## Запись обеих камер

В разделе **Камера → Записи → Настройки** опция **Записывать камеру 2** работает только при включённом двойном потоке. См. [Записывайте полёты и разбирайте их](https://docs.uavmatrix.com/ru/guides/recording-flight-review/).
