# Камера не обнаружена

> UAVcast-Pro показывает «No cameras available»? Проверьте ленточный кабель CSI, rpicam-hello, поддержку камер в Ubuntu и v4l2-ctl для USB-камер.

**Камера → Настройки камеры** показывает **No cameras available** в поле **Выберите камеру**, нужной камеры нет в списке или в **Журнале действий** (Action Logs) появляется сообщение *Камера не обнаружена*.

| Что вы видите | Вероятная причина | Начните с |
| --- | --- | --- |
| Камера CSI Raspberry Pi (ленточный кабель) не видна | Кабель, разъём или стек камеры | [Проверка 1](https://docs.uavmatrix.com/ru/troubleshooting/camera-not-detected/#check-1) |
| Камера CSI на Ubuntu | В Ubuntu по умолчанию нет стека камер Raspberry Pi | [Проверка 2](https://docs.uavmatrix.com/ru/troubleshooting/camera-not-detected/#check-2) |
| USB-камера не видна | Linux её не видит или это не устройство видеозахвата | [Проверка 3](https://docs.uavmatrix.com/ru/troubleshooting/camera-not-detected/#check-3) |
| Камера в списке, но видео не запускается | Неподдерживаемое разрешение или камеру занимает другая программа | [Проверка 4](https://docs.uavmatrix.com/ru/troubleshooting/camera-not-detected/#check-4) |

## Проверка 1: Камера CSI Raspberry Pi

1. Выключите Pi. Заново вставьте ленточный кабель на обоих концах контактами в правильную сторону и закройте защёлки разъёма. Pi 5 и Pi Zero 2 W требуют более узкий 22-контактный кабель.

2. Загрузите Pi и выполните на нём:

   ```bash
   rpicam-hello --list-cameras
   ```

   На старых образах Raspberry Pi OS команда называется `libcamera-hello --list-cameras`.

3. Если камеры нет в этом списке, Linux её не видит. Попробуйте другой кабель или другую камеру, прежде чем что-либо менять в UAVcast-Pro.

4. Если камера есть в списке, перезапустите её на странице Камеры (**Restart** или **Stop**, затем **Start**) и снова откройте **Выберите камеру**. Каждая камера CSI отображается отдельной записью, например *CSI Camera 0 - imx708 (libcamera)*.

> **Две камеры CSI**
>
> Для двух камер драйверу камеры нужно больше памяти. Начиная с v6.2.2 установщик автоматически увеличивает память CMA в `config.txt` для конфигураций с несколькими камерами. Если вторую камеру вы добавили позже, перезагрузите устройство после установки.

## Проверка 2: Камера CSI на Ubuntu или Debian

UAVcast-Pro использует `rpicam-vid` для камер CSI. Установщик ставит `rpicam-apps` (или `rpicam-apps-core`) в Raspberry Pi OS и Debian. В Ubuntu стек камер Raspberry Pi не входит в пакеты, и в журнале появляется сообщение *CSI camera not available: Ubuntu requires building libcamera from source. USB cameras are supported.* (Камера CSI недоступна: для Ubuntu нужно собрать libcamera из исходного кода. USB-камеры поддерживаются.)

Если вам нужна камера CSI, используйте Raspberry Pi OS 64-bit, либо используйте USB-камеру на Ubuntu.

## Проверка 3: USB-камера

1. Подключите камеру напрямую к бортовому компаньону, а не через хаб без питания.

2. Выполните:

   ```bash
   v4l2-ctl --list-devices
   ```

3. Если камеры нет в списке, Linux её не видит. Проверьте `lsusb` и попробуйте другой порт и кабель.

4. Если камера есть в списке, перезапустите её кнопкой **Restart** на странице Камеры и снова откройте **Выберите камеру**.

Большинство UVC-веб-камер работают, например Logitech C920 и C615. Камеры, которые выдают только формат, не поддерживаемый кодировщиком, и устройства, которые не являются устройствами видеозахвата (некоторые карты видеозахвата), в списке не отображаются.

## Проверка 4: Камера в списке, но видео не запускается

- Если в журнале написано *Camera … does not support …x… - streaming at …x… instead* (Камера … не поддерживает …x…, вместо этого передача идёт в …x…), выберите в поле **Resolution** (Разрешение) разрешение, которое поддерживает камера.
- Закройте другие программы, которые используют камеру. Открыть её одновременно может только одна программа.
- Если **Enable Camera?** (Включить камеру?) показывает *Insufficient permissions* (Недостаточно прав), обновитесь до v6.5.2 или новее: в ней это исправлено.

## Всё ещё не обнаруживается?

[Скачайте логи](https://docs.uavmatrix.com/ru/troubleshooting/collect-logs/) с выбранным **Все журналы**, добавьте вывод `rpicam-hello --list-cameras` или `v4l2-ctl --list-devices` и отправьте всё на **[support@uavmatrix.com](mailto:support@uavmatrix.com)**.
