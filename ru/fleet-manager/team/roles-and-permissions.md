# Роли и права доступа

> Полная матрица прав ролей Fleet Manager Owner, Admin и Viewer: сопряжение, команды полёта, терминал, миссии, VPN и команда.

В Fleet Manager три роли, которые назначаются отдельно для каждой организации. Один человек может быть Admin в одной организации и Viewer в другой.

| Роль | Кратко |
| --- | --- |
| **Owner** | Всё, что может Admin, а также удаление организации и передача владения. Ровно один на организацию: тот, кто её создал, или тот, кому передано владение. |
| **Admin** | Управляет парком: сопрягает и удаляет дроны, отправляет команды, открывает терминал, планирует и загружает миссии, управляет VPN и привязками потоков, а также командой. |
| **Viewer** | Только чтение. Видит панель управления, парк, карту в реальном времени, историю полётов, миссии, сеть и команду, но не может ничего менять или отправлять команды. |

Новых участников приглашают как Admin или Viewer. Роль Owner переходит к другому человеку только через [Transfer Ownership](https://docs.uavmatrix.com/ru/fleet-manager/team/#transfer-ownership).

## Матрица прав

Матрица основана на правилах доступа, которые Fleet Manager применяет на сервере, поэтому скрытая кнопка никогда не является единственным препятствием.

| Действие | Owner | Admin | Viewer |
| --- | --- | --- | --- |
| **Парк и дроны** |  |  |  |
| Просмотр панели управления, списка парка, страниц UAV и карты в реальном времени | ✓ | ✓ | ✓ |
| Просмотр воспроизведения истории полётов | ✓ | ✓ | ✓ |
| Сохранение, переименование и удаление именованных полётов | ✓ | ✓ | – |
| Сопряжение дрона (**Pair Device**) | ✓ | ✓ | – |
| Переименование дрона, изменение цвета на карте | ✓ | ✓ | – |
| Удаление дрона | ✓ | ✓ | – |
| **Команды** |  |  |  |
| Смена режима полёта, RTL, Loiter, Circle | ✓ | ✓ | – |
| Взведение, разоружение, принудительное взведение | ✓ | ✓ | – |
| Предполётная калибровка | ✓ | ✓ | – |
| Запуск, остановка и чтение миссий на дроне | ✓ | ✓ | – |
| Перезагрузка или выключение бортового компаньона | ✓ | ✓ | – |
| SSH **Terminal** на странице UAV | ✓ | ✓ | – |
| **Open via Proxy** (веб-интерфейс UAVcast-Pro через Fleet Manager) | ✓ | ✓ | – |
| **Миссии** |  |  |  |
| Просмотр сохранённых миссий | ✓ | ✓ | ✓ |
| Создание, редактирование и удаление миссий | ✓ | ✓ | – |
| **Upload to Drone** | ✓ | ✓ | – |
| **Сеть и VPN** |  |  |  |
| Просмотр страницы Network, устройств и привязок потоков | ✓ | ✓ | ✓ |
| Просмотр ключа аутентификации VPN и **GCS Connection Command** | ✓ | ✓ | – |
| Включение VPN, создание ключей аутентификации, **Push to Drone** | ✓ | ✓ | – |
| Переименование, изменение типа или удаление устройств VPN | ✓ | ✓ | – |
| Добавление, приостановка или удаление привязок потоков | ✓ | ✓ | – |
| Удаление сети VPN | ✓ | ✓ | – |
| **Команда** |  |  |  |
| Просмотр участников и их ролей | ✓ | ✓ | ✓ |
| Приглашение участников (как Admin или Viewer) | ✓ | ✓ | – |
| Изменение роли участника (кроме Owner) | ✓ | ✓ | – |
| Удаление участников (кроме Owner), отзыв приглашений | ✓ | ✓ | – |
| Передача владения | ✓ | – | – |
| **Организация и настройки** |  |  |  |
| Переименование организации, редактирование описания | ✓ | ✓ | – |
| Изменение срока хранения телеметрии, очистка или удаление истории | ✓ | ✓ | – |
| Удаление организации | ✓ | – | – |
| **Все пользователи** |  |  |  |
| Использование FleetBot, создание и закрытие собственных обращений в поддержку | ✓ | ✓ | ✓ |
| Редактирование собственного профиля (в аккаунте UAVmatrix) | ✓ | ✓ | ✓ |

> **Admin может управлять другими Admin**
>
> Admin может приглашать новых Admin, понижать другого Admin до Viewer и удалять других Admin. Давайте роль Admin только тем, кому вы доверите весь парк. Owner — единственный участник, которого Admin не может изменить.

> **Что видит Viewer**
>
> Viewer видит те же страницы, но без элементов управления. Панель управления UAV показывает Viewer текущее состояние и логи, но без кнопок режима полёта, миссий и взведения и без вкладки Terminal. На странице **Network** Viewer не видит ключ аутентификации VPN: *Only Owners and Admins can see the VPN auth key.* Кроме того, Fleet Manager проверяет каждую команду на сервере, поэтому Viewer не сможет отправить команду никаким другим способом.

## Выбор ролей для коммерческого парка

| Участник | Рекомендуемая роль |
| --- | --- |
| Руководитель парка или операций | Owner (один человек) |
| Пилоты, техники, тот, кто сопрягает новые летательные аппараты | Admin |
| Клиенты, следящие за работой в реальном времени, руководство, аудиторы | Viewer |
| Подрядчики, которым нужно управлять вашими дронами | Admin, удаляется по окончании работы |

## Не роль: супер-админ

Сотрудники UAVmatrix имеют отдельную роль поддержки во всех организациях. Она используется для задач поддержки, например, для [добавления дополнительных email к лицензиям](https://docs.uavmatrix.com/ru/fleet-manager/licenses/#licenses-bought-with-another-email) аккаунта. Это не часть вашей организации, и её нельзя назначить.
