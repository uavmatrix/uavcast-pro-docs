# Сеть и VPN

> Включите частную VPN на базе WireGuard для организации в Fleet Manager, подключайте дроны и ноутбуки наземных станций и управляйте таблицей устройств.

У каждой организации может быть собственная частная VPN: сеть WireGuard между вашими дронами и наземными станциями, которой управляет Fleet Manager. В ней каждое устройство получает постоянный адрес `100.x.y.z` и может напрямую обращаться к другим, независимо от того, подключено ли оно через 4G, Wi-Fi или спутник, без проброса портов и публичных IP-адресов.

Fleet Manager использует эту сеть для маршрутизации [привязок потоков](https://docs.uavmatrix.com/ru/fleet-manager/network/stream-bindings/): видео и MAVLink от дрона к ноутбукам, на которых пилоты работают с QGroundControl или Mission Planner.

Всё это находится в разделе **Network** (боковая панель **Fleet Management → Network**).

## Когда нужна VPN?

VPN — **необязательна**: Fleet Manager показывает, отображает на карте и управляет дронами без неё, через собственное зашифрованное соединение дрона. Включайте VPN, когда хотите, чтобы потоки доходили до наземных станций.

| Рекомендуется VPN | VPN не требуется |
| --- | --- |
| Дрон и наземная станция в разных сетях (4G, удалённые площадки) | Дрон и наземная станция в одной локальной сети Wi-Fi |
| Нужна прямая потоковая передача видео и телеметрии | Используется прямое подключение телеметрии по USB или serial |
| Нужны зашифрованные каналы между площадками | Тестирование в контролируемой среде |
| Работа на нескольких площадках |  |

## Включение VPN

Только для Owner и Admin.

1. Откройте **Network**. Если VPN выключена, страница показывает **Enable VPN Network** и то, что она даёт: безопасные соединения на основе WireGuard, потоковую передачу видео и телеметрии с малой задержкой и работу в любой сети.
2. Нажмите **Enable VPN Network**.

![Страница Network с карточкой Enable VPN Network для организации без VPN](https://docs.uavmatrix.com/ru/img/screenshots/fleet-manager/network--enable.webp)

После включения VPN страница показывает четыре счётчика (**Total Devices**, **Online**, **UAVs**, **Ground Stations**) и три вкладки: **Devices**, **Stream Bindings** и **Settings**.

## Подключение дронов к VPN

Дронам не нужна ручная команда. Есть два способа:

- **При сопряжении.** Если VPN включена до сопряжения, на шаге **VPN Connection** мастера дрон подключается к сети. См. [Добавьте первый дрон](https://docs.uavmatrix.com/ru/fleet-manager/pair-uav/).
- **Push to Drone.** Для дронов, сопряжённых до включения VPN, карточка **Push to Drone** на вкладке **Devices** показывает все дроны, которых нет в вашей сети. Нажмите **Connect** рядом с дроном, чтобы отправить ему настройки VPN. Дрон должен быть в сети.

Если дрон уже находится в другой сети Tailscale, у него есть значок **Existing VPN**. Тогда **Connect** запросит подтверждение (**Existing VPN Connection Detected**), а **Replace & Connect** переведёт дрон в сеть вашей организации.

Дрон появится в **Connected Devices** с типом **UAV** и своим VPN-адресом, а на странице UAV появится кнопка **Open via VPN**.

## Подключение наземных станций к VPN

Наземные станции подключаются одной командой Tailscale из **Connect a Device**. Следуйте инструкции [Подключение наземной станции](https://docs.uavmatrix.com/ru/fleet-manager/connect-gcs/).

## Connected Devices

В таблице перечислены все устройства в сети:

| Столбец | Что показывает |
| --- | --- |
| **Status** | Онлайн или офлайн в VPN |
| **Device** | Имя и имя хоста |
| **Type** | **UAV**, **GCS** или **Unknown**. У неизвестных устройств есть кнопка **Configure**. |
| **IP Address** | VPN-адрес устройства (`100.x.y.z`) |
| **Last Check-in** | Когда устройство последний раз выходило на связь в сети |

Нажмите **Sync**, чтобы обновить список с VPN-сервера. В меню действий каждой строки есть:

- **Rename**: понятное название, например «Полевой ноутбук – Team North».
- **Change Type**: переключение между **UAV**, **GCS** и **Unknown**. Для UAV выберите, какой это из сопряжённых дронов.
- **Remove Device**: отключает устройство от сети. Для дрона Fleet Manager отправляет команду покинуть VPN, а его привязки потоков удаляются.

### Настройка неизвестного устройства

Новые наземные станции появляются как **Unknown**, а баннер показывает количество устройств, требующих настройки. Нажмите **Configure** и ответьте на вопрос **What type of device is this?**

- **Ground Control Station (GCS):** компьютер с QGroundControl, Mission Planner или аналогичным ПО. Он будет **получать** видео и телеметрию и станет доступен для привязок потоков.
- **Drone / UAV:** дрон с UAVcast-Pro. Выберите, какой это из сопряжённых дронов, чтобы управлять его потоковой передачей.

Нажмите **Continue**, затем **Complete Setup**.

## Вкладка Settings

**Danger Zone → Delete Network** навсегда удаляет сеть VPN, все подключённые устройства, все ключи аутентификации и все привязки потоков. Устройства выпадают из сети, и каждую наземную станцию и дрон придётся подключить заново.

Удаление сети также выключает VPN для организации, а онлайн-дронам передаётся команда покинуть VPN. После этого на странице Network снова появляется **Enable VPN Network**, которая создаёт новую пустую сеть. Отдельного переключателя для выключения VPN нет: выключить её можно только через **Delete Network**.

## Требования к сети

| Устройство | Требуется исходящий доступ |
| --- | --- |
| Дрон (подключение к Fleet Manager) | HTTPS (TCP 443) к `fleet-manager.uavmatrix.com`, TCP 8883 для MQTT через TLS |
| Дрон и наземная станция (VPN) | HTTPS (TCP 443) к `vpn-connect.uavmatrix.com`, а также UDP для WireGuard. Tailscale по умолчанию использует UDP 41641. |

Большинство сотовых и офисных сетей это разрешают. Если устройства подключились к VPN, но не могут связаться друг с другом, см. [VPN подключена, но не видит дрон](https://docs.uavmatrix.com/ru/troubleshooting/vpn-cant-reach-drone/).

Когда два устройства не могут связаться напрямую по UDP, их трафик передаётся через публичные релейные серверы DERP Tailscale по HTTPS (TCP 443). Он остаётся сквозным шифрованием, но ретранслятор добавляет задержку, поэтому по возможности разрешайте исходящий UDP.
