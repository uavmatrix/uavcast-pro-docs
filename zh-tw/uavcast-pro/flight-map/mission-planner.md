# 任務規劃器分頁

> 在 UAVcast-Pro 任務規劃器分頁中規劃航點任務、設定高度座標系與半徑、將其儲存為 .waypoints 檔案，並上傳至 ArduPilot 飛行控制器。

任務規劃器分頁可讓您在瀏覽器中規劃簡單的航點任務，並透過 UAVcast-Pro 將其上傳至飛行控制器，只要能連上網頁介面即可操作。任務會以 Mission Planner 與 QGroundControl 所使用的相同 `.waypoints` 格式（QGC WPL 110）儲存，因此您可以在各工具之間搬移任務。請開啟 **飛行地圖 → 任務規劃器**。

![任務規劃器分頁，包含衛星地圖、空白的航點表格，以及儲存、載入、上傳、讀取與清除按鈕](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/flight-map--mission-planner.webp)

*新增任何航點之前的飛行地圖 → 任務規劃器。點擊地圖即可新增航點。*

## 規劃任務

1. 點擊地圖上第一個航點應該出現的位置。首次使用時，**設定預設值**會要求您輸入 **預設高度（公尺）**、**航點半徑（公尺）**與**高度座標系**。選擇**繼續**。
2. 持續點擊以新增航點。拖曳標記即可移動它。
3. 在表格中調整每個航點的 **高度 (m)**、**座標系**與**半徑 (m)**。在**操作**欄中移除航點。
4. 查看**航點**與**距離**，以確認整條路線的總計。

| 預設值 | 數值 | 選項 |
| --- | --- | --- |
| **預設高度（公尺）** | `100` | 任意 |
| **航點半徑（公尺）** | `30` | 任意 |
| **高度座標系** | **相對** | **相對**（高於起飛點）、**絕對**（高於平均海平面）、**地形**（高於地面，需要飛行控制器上有地形資料） |

在表格中，座標系會縮寫為 **Rel**、**Abs** 與 **Ter**（即相對、絕對與地形）。航點會以 `MAV_CMD_NAV_WAYPOINT` 傳送。

## 上傳至飛行控制器

1. 在**飛行控制器**下，選擇**上傳**。
2. 確認**上傳任務**。對話框會警告此操作將取代飛行控制器上的任務。
3. 您會看到 *任務已上傳到飛行控制器*。

- **讀取**會將飛行控制器上的任務下載至規劃器。
- **清除**會從規劃器中移除航點。

若要執行此任務，請使用飛行地圖**操作**分頁中的**開始**，或從遙控器或地面站切換至 AUTO 模式。

## 儲存與載入檔案

在**檔案**下：

- **儲存**會將任務下載為 `mission.waypoints`。
- **載入**會開啟 QGC WPL 格式的 `.waypoints` 或 `.txt` 檔案，例如從 Mission Planner 儲存的檔案。

## 限制

此規劃器僅處理一般航點。**載入**會保留每一列的位置、高度、座標系與半徑，但會將每一列都轉換為一般航點：起飛、降落、懸停與 DO 指令（攝影機觸發、伺服）不會被保留，而沒有位置的指令會變成座標為 0, 0 的航點。若要規劃與上傳起飛與降落指令、DO 指令、測繪網格、圍欄與集結點，請直接使用 Mission Planner 或 QGroundControl。
