# 使用者與存取

> 以管理員登錄保護 UAVcast-Pro 網頁介面，新增可觀看遙測與視訊但無法控制無人機的唯讀使用者，並可更改或重設密碼。

全新安裝的 UAVcast-Pro 沒有任何使用者，也沒有登錄機制：任何能開啟網頁介面的人都擁有完整的管理員權限。新增一位管理員使用者即可啟用登錄功能。之後，您可以為觀察者、客戶或酬載操作人員新增**唯讀**使用者，讓他們能查看所有內容，但無法做任何變更。前往 **Management → 使用者**。

![使用者頁面已開啟新增使用者對話框，包含使用者名稱、密碼、確認密碼與角色欄位](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/users.webp)

*Management → 使用者，並已開啟新增使用者對話框。*

## 開啟登錄功能

1. 前往 **使用者**，然後選擇 **新增使用者**。
2. 輸入 **使用者名稱**（至少 3 個字元）、**密碼**（至少 6 個字元）與 **確認密碼**。
3. 選擇 **建立使用者**。第一位使用者一律為 **管理員**（*第一位使用者必須是管理員*）。

從此時起，每位訪客都會看到登錄頁面。登錄狀態會在該瀏覽器中保留 7 天，或直到您在側邊欄底部的使用者選單中選擇 **登出** 為止。

> **網頁介面使用純 HTTP**
>
> 登錄資訊與設定會以未加密的方式傳輸。在您自己的區域網路或 [VPN](https://docs.uavmatrix.com/zh-tw/uavcast-pro/connectivity/vpn/) 內使用沒有問題，但切勿將網頁介面的連接埠轉送至網際網路。

## 角色

| 可以… | **管理員** | **唯讀** |
| --- | --- | --- |
| 查看儀表板、資料流、飛行控制器、飛行地圖、地面控制站與攝影機頁面 | 是 | 是 |
| 觀看即時視訊與遙測，檢視儀表板與錄製內容 | 是 | 是 |
| 變更任何設定 | 是 | 否 |
| 解鎖、上鎖、變更模式、啟動或清除任務 | 是 | 否 |
| 啟動或停止錄製 | 是 | 否 |
| 開啟數據機、虛擬專用網路、動態DNS、網路、Fleet Management、使用者與應用程式 | 是 | 否（隱藏） |

在管理員存在之前，您無法建立**唯讀**使用者（*在新增唯讀使用者之前，請先建立管理員使用者*）。

網頁的唯讀使用者與地面站目標上的 **Read Only** 開關不同，後者會阻擋來自地面站程式的指令。請參閱[地面控制站](https://docs.uavmatrix.com/zh-tw/uavcast-pro/ground-stations/)。

## 更改密碼

選擇 **更改密碼**，輸入 **目前密碼**，並兩次輸入 **新密碼**，然後選擇 **更新密碼**。密碼會以 bcrypt 雜湊值的形式儲存。

## 刪除使用者

在該使用者的列上選擇 **刪除**，然後確認。

- 當其他使用者存在時，您無法刪除自己的帳戶。
- 刪除**最後一位**使用者會再次關閉登錄功能：*刪除後，在建立新使用者之前，應用程式將在無驗證的情況下開放。*

## 忘記管理員密碼

由於無人機沒有電子郵件，且密碼復原無法自行處理，因此系統沒有重設連結。

- 若其他管理員仍能登錄，該管理員可以在 **使用者** 下刪除您的使用者，然後重新建立。
- 若沒有任何管理員角色的帳戶能登錄，請聯絡支援：**[support@uavmatrix.com](mailto:support@uavmatrix.com)**。請附上您的許可證金鑰（或購買時使用的電子郵件）、設備的主機名稱或名稱（可於 **應用程式 → 許可證管理器 → 已啟動設備** 下查看）、UAVcast-Pro 版本，以及您是否可以透過 SSH 連線至該設備。
