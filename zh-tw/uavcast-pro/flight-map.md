# 飛行地圖

> 在 UAVcast-Pro 飛行地圖上即時追蹤您的無人機，並使用駕駛艙 HUD、影像視窗、解鎖／上鎖、飛行模式、RTL、懸停、GCS 故障保護與飛行控制器訊息。

飛行地圖是內建於 UAVcast-Pro 的瀏覽器地面控制站。它會在地圖上顯示無人機、其飛行軌跡、執行中的任務與起飛點標記，並提供駕駛艙 HUD、即時影像與飛行控制器的訊息。您可以解鎖與上鎖、變更飛行模式、開始任務，或觸發 RTL 與懸停，所有操作都會先經過確認對話框。請開啟 **飛行地圖 → 地圖檢視**。

本功能適用於從任何手機、平板或筆電進行監控與簡單的指令操作。若需要完整的任務規劃與參數設定，請繼續搭配 Mission Planner 或 QGroundControl 使用。

![飛行地圖，包含地圖、右側的駕駛艙 HUD，以及包含連結、電池、飛行控制器、遙測、GPS 與姿態卡片的狀態分頁](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/flight-map.webp)

*飛行地圖 → 地圖檢視，於沒有 GPS 定位的測試台上執行，因此地圖上不顯示無人機位置。*

## 版面配置

- **地圖**（左側）：顯示無人機（含機頭朝向）、飛行軌跡、起飛點標記與任務。**Sats** 顯示衛星數量；**Auto-Pan** 會讓無人機保持在地圖中央。使用圖層按鈕切換圖層（**街道地圖**、**Satellite** 等）。若無人機沒有定位，您會看到 **No GPS Lock**：*需要至少 4 顆衛星*。
- **頂部列**：**錄製**按鈕（**遙測**、**攝影機 1**、**攝影機 2**）、可用的錄製空間、遙測更新速率（**1 Hz** 至 **10 Hz**）、目前的資料速率，以及可將地圖開啟於獨立視窗的按鈕。
- **駕駛艙**（右側）：姿態 HUD，包含速度與高度刻度條、目前的飛行模式、解鎖狀態、電池電壓，以及最新的預先解鎖（pre-arm）訊息。
- **側邊分頁**：**狀態**、**儀表**、**操作**、**訊息**與**錄製**。拖曳面板邊緣可調整大小；雙擊把手即可重設。
- **影像視窗**：每個啟用中的攝影機串流各有一個視窗。您可以拖曳、最大化、最小化或隱藏它們；隱藏的視窗會停靠為地圖底部的分頁。

每個頁面頂端的列也會顯示 **FC Connected**、**Armed**（已解鎖）／**Disarmed**（已上鎖）、飛行器類型、飛行模式，以及 **GCS Failsafe Enabled** 或 **GCS Failsafe Disabled**。

## 解鎖與上鎖

1. 開啟 **操作** 分頁，或使用駕駛艙下方的解鎖控制項。
2. 選擇 **解鎖**。對話框會顯示警告：*螺旋槳可能開始轉動。請確認無人在無人機附近，且周圍區域已清空。*
3. 點擊 **解鎖** 確認。

飛行控制器自身的預先解鎖檢查仍會決定是否解鎖。若飛行控制器拒絕，您會看到 *無人機拒絕解鎖。請檢查畫面上的 PreArm 訊息。* 原因會顯示在駕駛艙下方以及 **訊息** 分頁中。

**上鎖**會立即停止馬達。無人機飛行中時，飛行控制器會拒絕此操作。

## 變更飛行模式

從飛行模式控制項中選擇模式。清單會依飛行器類型（Copter、Plane、Rover、Sub）顯示，並分為 **安全模式**（定點保持與穩定）、**導航**（自主模式）與 **進階**（手動與緊急模式）。風險較高的模式會標示警告圖示，並在送出指令前要求您確認。

## 操作分頁

| 群組 | 按鈕 | 執行內容 |
| --- | --- | --- |
| **任務** | **讀取**、**隱藏**、**開始**、**清除** | **讀取**會將飛行控制器上的任務載入地圖。**開始**會啟動任務（需經確認）。**清除**會刪除飛行控制器上的任務，並等待飛行控制器回覆確認。 |
| **模式** | **無限懸停**、**RTL** | 快速切換模式。 |
| **飛行前** | **飛行前校準**、**載入任務**、**清除任務** | 校準會執行飛行控制器的地面校準（陀螺儀、氣壓計）。僅能在地面執行。 |
| **緊急命令** | **返回起飛點**、**無限懸停** | 需經確認。RTL 會依飛行控制器的設定返回並降落或懸停。無限懸停會以目前位置為中心盤旋。 |
| **故障保護** | **地面站故障保護**開關 | 會在飛行控制器上寫入 `FS_GCS_ENABLE`（Copter）與 `FS_GCS_ENABL`（Plane）。 |

> **使用行動網路飛行時請開啟地面站故障保護**
>
> 地面站故障保護會在飛行控制器停止接收來自地面站的 MAVLink 心跳封包時觸發。透過 4G/LTE 連線時，連結可能隨時中斷。在依賴此功能之前，請先於地面站中設定故障保護的動作（`FS_GCS_ENABLE` 動作、`FS_GCS_TIMEOUT`）。

唯讀使用者可以看到操作分頁，但無法使用（*唯讀使用者無法控制無人機*）。

## 訊息

**訊息**會列出飛行控制器發出的每一則文字訊息。**目前警報**會將目前的問題（例如預先解鎖失敗）與**訊息記錄**分開顯示。開啟**只看問題**可隱藏例行訊息，點擊**清除記錄**則可重新開始。此分頁會以徽章顯示目前警報的數量。

## 狀態與儀表分頁

- **狀態**：卡片包括 **LINK**（封包遺失、已連線）、**FLIGHT CONTROLLER**（已解鎖、模式、飛行器）、遙測資料速率、位置、**GPS**（定位、衛星數、**ALTITUDE (AGL)**、**ALTITUDE (AMSL)**）與 **BATTERY**。
- **儀表**：以圓形儀器顯示相同的資料。

AGL 為相對於起飛點的高度；AMSL 為相對於平均海平面的高度。

## 地圖設定

| 設定 | 功能說明 |
| --- | --- |
| **Auto-Pan** | 讓無人機保持在地圖中央。 |
| **顯示機頭朝向** | 從無人機繪製一條朝向線。 |
| **軌跡長度** | 飛行路徑軌跡中保留的點數。 |
| **軌跡顏色** | 軌跡的顏色。**清除軌跡路徑**會移除軌跡。 |
| **顯示與起飛點的距離** | 顯示與起飛點標記之間的距離。 |
| **Reset to Defaults** | 還原所有地圖設定。 |

## 彈出視窗

- **飛行地圖視窗**：頂部列右側的按鈕會在新視窗中單獨開啟地圖（`/flightmapwindow`），視窗大小適合第二個螢幕。
- **HUD 視窗**：從駕駛艙中開啟，可在獨立視窗中顯示 HUD（`/hud`）。

![駕駛艙 HUD，包含姿態指示器、速度與高度刻度條、航向與飛行模式](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/hud.webp)

*位於 /hud 的駕駛艙 HUD。此處地平線是倒置的，因為此測試台的飛行控制器是倒裝安裝的。*

## 遙測更新速率

頂部列中的速率選擇器（**1 Hz**、**2 Hz**、**5 Hz**、**10 Hz**）設定 UAVcast-Pro 向瀏覽器推送遙測資料的頻率。它不會改變地面站接收的內容。若網頁介面的連線速度較慢，請使用較低的速率。
