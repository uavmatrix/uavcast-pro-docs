# 指南

> UAVcast-Pro 的分步指南：透過 4G 飛行、VPN 遠端存取、多地面站、經由 NTRIP 取得 RTK、雙攝影機，以及機隊上線。

結合多項功能、完成實際任務的端對端教學。每份指南都會在開頭列出所需條件，並以確認運作正常的檢查作結。

## 連線

[透過 4G 超視距飛行數據機、Fleet Manager VPN，以及將遙測與視訊傳送至 QGroundControl 或 Mission Planner。](https://docs.uavmatrix.com/zh-tw/guides/bvlos-4g/)[使用 Tailscale 遠端存取透過 LTE 存取 tailnet 上的無人機，無需連接埠轉送。](https://docs.uavmatrix.com/zh-tw/guides/remote-access-tailscale/)[串流至多個地面站同一台無人機供飛行員、酬載操作員與唯讀觀察者使用。](https://docs.uavmatrix.com/zh-tw/guides/multiple-ground-stations/)

## 定位與視訊

[透過 NTRIP 基準站使用 4G RTK從基準站將 RTCM3 校正資料傳送至飛行控制器，以取得 RTK Fixed。](https://docs.uavmatrix.com/zh-tw/guides/rtk-ntrip-caster/)[兩台攝影機：RC 切換或雙路串流以遙控器切換攝影機，或同時串流兩台攝影機。](https://docs.uavmatrix.com/zh-tw/guides/dual-camera-rc-switching/)[在地面站接收視訊Mission Planner、QGroundControl，以及 Windows、Linux 與 macOS 上的 GStreamer、Android、VLC 與 RTSP。](https://docs.uavmatrix.com/zh-tw/uavcast-pro/ground-stations/)[錄製飛行並回放檢視無人機上的視訊與遙測，在同一條時間軸上回放。](https://docs.uavmatrix.com/zh-tw/guides/recording-flight-review/)

## 機隊

[使用 Fleet Manager 完成機隊上線為 20 台以上的無人機規劃授權、命名、配對、組織 VPN 與串流綁定。](https://docs.uavmatrix.com/zh-tw/guides/fleet-onboarding/)

遇到問題了嗎？請先參閱[疑難排解](https://docs.uavmatrix.com/zh-tw/troubleshooting/)。
