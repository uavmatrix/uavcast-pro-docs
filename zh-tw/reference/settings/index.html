設定參考

依頁面分類列出 UAVcast-Pro 網頁介面中的每一項設定，標籤與應用程式顯示的完全相同，並附上全新安裝時的預設值。會即時套用設定的頁面，除非另有說明，都會立即生效。功能頁面會詳細說明各區域；本頁則方便查詢。

飛行控制器 → 連線​

設定預設值值與備註
Link enabled開啟開啟或關閉飛行控制器連線。
Link typeUSBUSB（飛行控制器本身的 USB 連接埠）或 UART / Serial（GPIO 腳位上的 TELEM 連接埠，或 USB 序列轉接線）。
PortAutomaticAutomatic 會找到飛行控制器，並在裝置編號變更時跟隨。Custom path… 可輸入裝置路徑，例如 /dev/ttyAMA0。
Baud rateAutomatic必須與飛行控制器上的 SERIALx_BAUD 相符。Automatic 會依序嘗試 57600、115200、921600、1500000、460800、230400 與 500000。USB 不使用此設定。

按鈕：Auto-detect（掃描所有連接埠與傳輸速率，並儲存結果）、連接、Restart link、停止。變更會立即套用，無需重新啟動。

飛行控制器 → NTRIP / RTK​

設定預設值值與備註
啟用 NTRIP 用戶端關閉
Caster 主機空白NTRIP Caster 的主機名稱。
連接埠2101部分 TLS Caster 使用 2102 或 443。
掛載點空白可透過 瀏覽掛載點 選擇。
使用 TLS（HTTPS）關閉適用於要求 TLS 的 Caster。
Username ／ Password空白rtk2go.com：以電子郵件地址作為使用者名稱，無須密碼。
上行傳送 GGA開啟VRS 與最近掛載點型 Caster 需要此設定。
傳送間隔（秒）10
位置來源來自飛控的即時位置或 固定的手動位置（Latitude、Longitude、高度（公尺）），在取得第一次 GPS 定位前也會作為備用。

飛行控制器 → 注入器​

設定預設值值與備註
Input typeHTTP、UDP 或 Serial。建立後無法變更。
MAVLink sysid1與飛行控制器相同。
MAVLink compid194使用者酬載。
Name prefix空白最多 8 個 ASCII 字元，會加在每個訊號名稱之前。
Rate limit (Hz per signal)每個訊號名稱每秒最多的取樣數。
Protocol（UDP、Serial）Key=Value（逐行） 或 JSON（{name, value}）。
Port ／ Bind address（UDP）選擇未使用的連接埠，例如 14600。0.0.0.0 表示所有介面，127.0.0.1 表示僅限本機。
Device path ／ Baud rate（Serial）例如 /dev/ttyUSB0；傳輸速率必須與傳送端相符。

地面控制站​

每個目標位址各有一張卡片。

設定新目標位址的預設值值與備註
名稱空白最多 50 個字元。
目標IP或主機空白IPv4 位址。必須先填寫，才能開啟視訊或遙測。
遙測連接埠145501–65535。
視訊連接埠56001–65535。
視訊連接埠（攝影機 2）空白（= 視訊連接埠 + 1）僅在 雙路視訊串流 開啟時顯示。
啟用終端開啟關閉後，所有傳送至此目標位址的內容都會停止：遙測、視訊與音訊。
啟用視訊關閉
啟用遙測關閉
Read Only關閉地面站可接收遙測，但無法變更飛行器上的任何內容。此行為自 UAVcast-Pro 6.5.3 起適用；在較早的版本中，Read Only 不會阻擋參數寫入。

攝影機 → 攝影機設定​

設定預設值值與備註
啟用攝影機？是
選擇攝影機Raspberry Pi 攝影機已偵測到的 CSI 與 USB 攝影機。
解析度640×480僅提供攝影機支援的尺寸。
選擇幀率自動由攝影機自動協商。
位元率：0（自動）0–10000 kbps。
串流恢復速率自動關鍵影格間隔。自動 = 每秒一個關鍵影格。較快的等級可更快從封包遺失中恢復，但會佔用更多頻寬。
旋轉： ／ 翻轉設定0°，不翻轉水平翻轉、垂直翻轉。
啟用即時預覽？是於本頁及飛行地圖中顯示預覽。
自訂管道測試管道會覆寫地面控制站的目標位址。請省略 gst-launch-1.0 前綴。
啟用 RC 通道攝影機切換關閉
RC 通道7PWM < 1500 = 攝影機 1，PWM > 1500 = 攝影機 2。
匹配攝影機 1 解析度關閉攝影機 2 以攝影機 1 的解析度擷取。
雙路視訊串流關閉同時串流兩台攝影機。
音訊關閉預覽中的 Opus 音訊。
音訊裝置Auto (camera microphone if present)或擷取裝置，或 Test tone (no microphone needed)。
位元率（音訊）64 kbps
傳送音訊到地面站關閉以 RTP/Opus 傳送至每個視訊目標位址的視訊連接埠 + 2。

攝影機 → 錄製 → 設定​

設定預設值值與備註
儲存位置內部儲存空間USB 隨身碟或 SSD，或 或其他資料夾。
保留空間2 GB0.5–1000 GB。
空間不足時刪除最舊的錄製開啟關閉時，磁碟寫滿即停止錄製。
刪除超過以下天數的錄製0 天0 表示保留，直到需要空間時再刪除。
解鎖時自動錄製開啟
錄製攝影機 1 ／ 錄製攝影機 2開啟 ／ 開啟攝影機 2 僅在雙路視訊串流時可用。
檔案長度1 分鐘每個檔案 1–30 分鐘。
錄製遙測解鎖時連線期間始終 或 關閉。

數據機​

設定預設值值與備註
啟用行動數據機？是
數據機類型傳統型（PPP）或 HiLink。
存取點名稱 (可選)空白（自動）留空即可自動偵測。
使用者名稱 (可選) ／ 密碼 (可選)空白多數電信業者不需要這兩項。
PIN碼 (可選)空白SIM 卡 PIN，除非已停用 PIN。

虛擬私人網路​

設定預設值值與備註
啟用 VPN否
服務ZeroTierZeroTier 或 Tailscale。
網路 ID（ZeroTier）空白來自您自己的 ZeroTier 控制器。
認證金鑰 ／ 主機名（可選）（Tailscale）空白或使用 網頁登入，或在配對後使用 Fleet Manager 分頁登入。

動態DNS​

設定預設值值與備註
啟用動態DNS？否
DNS系統noipgeneric（需搭配 DNS網址）、noip、dyndns、duck。
使用者名稱、Password、別名空白由您的 DNS 服務商提供。

網路​

設定預設值值與備註
網路優先順序系統路由WiFi優先（室內模式）、數據機優先（戶外模式） 或 自動（系統預設）。

Fleet Management​

設定預設值值與備註
Device Name空白會顯示於 Fleet Manager。未填寫時使用主機名稱。

使用者​

設定值與備註
角色管理員 - 完全存取 或 唯讀 - 僅查看。第一位使用者必須是管理員。

應用程式​

設定預設值值與備註
伺服器連接埠8080 或更高。點擊 提交並重啟伺服器 即可套用；位址會變為 http://<device>:<port>/。
語言瀏覽器語言English、Spanish、Portuguese、Italian、Dutch、Polish、Turkish、Russian、Chinese（Simplified 與 Traditional）。
深色主題
日誌：日誌清單 ／ 時間範圍所有日誌 ／ 最近 2 小時請參閱 收集日誌。

資料庫 提供 備份資料庫、恢復資料庫（.db 檔案），以及 重設資料庫（會刪除所有設定）。
