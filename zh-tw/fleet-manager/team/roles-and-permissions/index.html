角色與權限

Fleet Manager 有三種角色，依組織設定。同一個人可以在一個組織中擔任 Admin，同時在另一個組織中擔任 Viewer。

角色簡述
Owner擁有 Admin 可執行的所有操作，外加刪除組織與轉移擁有權。每個組織只有一位：建立組織的人，或擁有權被轉移給的人。
Admin負責管理機隊：配對與移除無人機、傳送指令、開啟終端機、規劃與上傳任務、管理 VPN 與串流綁定，以及管理團隊。
Viewer唯讀。可查看儀表板、機隊、即時地圖、飛行歷史、任務、網路與團隊，但無法變更或控制任何項目。

新成員會以 Admin 或 Viewer 身分受邀。Owner 角色只能透過轉移擁有權交接。

Admin 可以管理其他 Admin

Admin 可以邀請新的 Admin、將其他 Admin 降為 Viewer，以及移除其他 Admin。請只將 Admin 角色交給您信任能管理整個機隊的人。Owner 是 Admin 唯一無法變更的成員。

Viewer 看到的內容

Viewer 看到的頁面與其他角色相同，只是沒有控制項。UAV 控制面板會向 Viewer 顯示即時狀態與記錄，但不會顯示飛行模式、任務或解鎖按鈕，也沒有 Terminal 分頁。在 Network 頁面上，Viewer 看不到 VPN 驗證金鑰：Only Owners and Admins can see the VPN auth key. Fleet Manager 也會在伺服器端檢查每個指令，因此 Viewer 無法以其他方式傳送指令。

為商業機隊選擇角色​

人員建議角色
機隊或營運主管Owner（僅一人）
飛行員、技術人員、負責配對新機身的人員Admin
即時追蹤其工作的客戶、管理階層、稽核人員Viewer
需要飛行您無人機的外包人員Admin，工作結束後移除

非角色：超級管理員​

UAVmatrix 員工在所有組織中擁有獨立的支援角色。此角色用於支援工作，例如為帳戶新增額外的授權電子郵件。它不屬於您的組織，也無法被指派。
