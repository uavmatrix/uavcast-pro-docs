設定、帳戶與帳單

從側邊欄（Organization → Settings）或使用者選單開啟 Settings。其中有四個分頁：Profile、Organizations、Support 與 History。

個人資料​

您的姓名、電子郵件、大頭貼與密碼屬於您的 UAVmatrix 帳戶。個人資料的變更由 UAVMatrix Store 管理：在 Password & Security 下選擇 UAVMatrix Store，即可在該處變更。Fleet Manager 會自動套用這些變更。

組織​

重新命名組織、編輯其說明，或（僅限 Owner）刪除組織。請參閱設定您的組織。

支援​

您的支援工單及其狀態，以及用來顯示或隱藏浮動支援按鈕的 Support Chat Bubble 開關。請參閱支援與 FleetBot。

歷史紀錄​

遙測保留、清除，以及各無人機歷史紀錄的刪除，僅限 Owner 與 Admin 使用。請參閱飛行歷史。

帳單​

Fleet Manager 沒有帳單頁面。授權、裝置席位、訂單與發票都位於您在 uavmatrix.com 的帳戶中。請參閱授權與席位。

刪除帳戶​

Profile → Danger Zone → Delete Account 會刪除您的 Fleet Manager 帳戶。請輸入 DELETE 以確認。

此操作會移除：

  • 您在 Fleet Manager 中的個人資料與帳戶資訊
  • 您所有的組織成員資格
  • 您所有的作用中工作階段
  • 您建立的任務與您寄出的邀請

您在 Recent Activity 中留下的紀錄會保留，但不會顯示您的姓名。

擁有組織的人員必須先移交

您擁有組織時無法刪除帳戶。Fleet Manager 會列出這些組織，並要求您先轉移擁有權或先刪除這些組織。

刪除您的 Fleet Manager 帳戶不會刪除您的 UAVmatrix 商店帳戶或授權。請前往 uavmatrix.com 管理這些項目。
