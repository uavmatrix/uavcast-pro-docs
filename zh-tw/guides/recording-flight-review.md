# 錄製飛行並回放檢視

> 在解鎖時自動於無人機上錄製攝影機視訊與遙測，儲存至 USB 或 SSD，並在同一條時間軸上回放視訊、地圖與飛行資料。

自 v6.5.1 起，UAVcast-Pro 會直接在無人機上錄製：攝影機視訊加上遙測記錄，可在飛行地圖上一鍵開始，或在每次解鎖時自動開始。錄製會重複使用已編碼的串流，因此不會增加 CPU 負擔，也不會中斷傳送至地面站的即時視訊。之後，飛行回放播放器會在同一條時間軸上顯示視訊、地圖軌跡、駕駛艙視圖與飛行資料。

## 1. 選擇錄製的儲存位置

1. 若要錄製到 USB 隨身碟或 SSD，請先插入。錄製會很快佔滿儲存空間，而 USB SSD 比 SD 卡更耐用。
2. 開啟 **攝影機 → 錄製**，然後切換到 **設定** 分頁。
3. 在 **儲存位置** 下選擇磁碟，或選擇 **內部儲存空間**。若磁碟是在頁面開啟後才插入，請按下 **重新尋找磁碟**。**或其他資料夾** 可讓您輸入路徑，並以 **使用此資料夾** 確認。
4. 設定 **保留空間**（預設 2 GB）。錄製絕不會佔用超過此空間的磁碟容量。

![錄製設定分頁，包含儲存位置、保留空間、空間不足時刪除最舊的錄製、刪除超過以下天數的錄製，以及解鎖時自動錄製](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/camera--recordings-settings.webp)

*攝影機 → 錄製 → 設定，選取內部儲存空間，並開啟解鎖時自動錄製。*

## 2. 決定何時錄製

| 設定 | 預設 | 作用 |
| --- | --- | --- |
| **解鎖時自動錄製** | 開啟 | 馬達解鎖時開始，上鎖時停止。若飛行中連線中斷，錄製會繼續進行。 |
| **錄製攝影機 1** / **錄製攝影機 2** | 開啟 | 攝影機 2 僅在雙路視訊串流開啟時才會錄製。 |
| **空間不足時刪除最舊的錄製** | 開啟 | 運作方式類似行車記錄器：錄製不會因為空間不足而停止。關閉時，則會改為停止錄製。 |
| **刪除超過以下天數的錄製** | 0 天 | 0 表示保留錄製，直到需要空間時才刪除。 |
| **檔案長度** | 1 分鐘 | 錄製會分割成 1 至 30 分鐘的檔案。較短的檔案在斷電時遺失的內容較少。 |
| **錄製遙測** | **解鎖時** | **連線期間始終**也會在地面記錄，並在每次解鎖、上鎖與每小時開始新檔案。**關閉**則只錄製視訊。 |

## 3. 手動錄製

在 **飛行地圖** 上，**錄製** 按鈕可啟動與停止各攝影機（**錄製攝影機 1**、**停止錄製攝影機 1**），以及遙測記錄。唯讀使用者可以觀看，但無法開始錄製。

## 4. 尋找飛行紀錄

開啟 **攝影機 → 錄製 → 錄製庫**。每次飛行都會列出，並附有其視訊、縮圖與遙測資料。正在錄製中的項目會顯示 **REC** 標記。

![錄製庫，包含儲存空間列與兩筆飛行錄製，每筆皆有 CAM 1 與遙測標記，以及播放按鈕](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/camera--recordings.webp)

*攝影機 → 錄製 → 錄製庫，顯示兩筆飛行錄製，每筆皆包含攝影機視訊與遙測。*

在錄製庫中，您可以：

- **播放**某次飛行，以開啟飛行回放播放器，
- 將視訊片段**下載**為 MP4，
- **刪除**錄製：**僅刪除影片**，或**刪除影片和遙測**。

## 5. 回放檢視飛行

飛行回放播放器會在同一條時間軸上，將視訊與地圖軌跡、駕駛艙視圖及飛行資料（**高度**、**速度**、**電池**、**衛星**、**模式**）並排顯示。

![飛行回放播放器，包含視訊區域、地圖、駕駛艙視圖，以及帶有播放控制的時間軸](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/camera--flight-review.webp)

*飛行回放播放器：視訊、地圖與駕駛艙視圖位於同一條時間軸上方。*

- 時間軸會標示解鎖、上鎖與飛行模式的變更，方便您跳到重要的時刻。
- 使用 **後退 10 秒** 與 **前進 10 秒**，以及從 0.5× 到 4× 的 **播放速度**。
- 使用兩台攝影機時，**變更視訊版面配置** 可在 **子母畫面** 與 **並排** 之間切換；**將此攝影機放大顯示** 則會交換兩者。
- 若某筆錄製沒有遙測資料，播放器會顯示 *此錄製沒有遙測記錄。遙測會在無人機解鎖期間記錄。*

## 使用須知

- 錄製內容儲存在無人機上。在 **空間不足時刪除最舊的錄製** 將其刪除之前，請先下載您需要保留的內容。
- 儀表板的 **儲存空間** 卡片與 **錄製儲存空間** 摘要會顯示可用空間。
- 即使 **啟用即時預覽？** 已關閉，錄製仍會繼續進行。
- 若錄製服務停止回應，頁面會顯示 *錄製服務沒有回應。* 請在 **攝影機 → 攝影機設定** 中重新啟動攝影機服務；若問題再次發生，請[收集日誌](https://docs.uavmatrix.com/zh-tw/troubleshooting/collect-logs/)。
