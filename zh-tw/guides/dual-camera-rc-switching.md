# 兩台攝影機：RC 切換或雙路串流

> 將兩台攝影機連接到 UAVcast-Pro，並以遙控器在兩者之間切換，或使用雙路視訊串流同時串流兩者。包含設定、連接埠與 CPU 說明。

UAVcast-Pro 可處理兩台攝影機，例如前視攝影機與下視或變焦攝影機。您可以在兩種模式之間選擇：

|  | **切換**（預設） | **雙路視訊串流** |
| --- | --- | --- |
| 地面站接收的內容 | 一路視訊串流，顯示攝影機 1 或攝影機 2 | 同時兩路視訊串流 |
| 選擇方式 | 網頁介面中的攝影機標籤，或 RC 通道 | 兩路始終直播 |
| 連接埠 | **視訊連接埠** | 攝影機 1 使用**視訊連接埠**，攝影機 2 使用**視訊連接埠（攝影機 2）**（預設：視訊連接埠 + 1） |
| CPU 與頻寬 | 一次編碼 | 兩次編碼，上傳頻寬約為兩倍 |

## 1. 新增第二台攝影機

1. 連接兩台攝影機。兩台 CSI 攝影機（Pi 5）、一台 CSI 與一台 USB 攝影機，或兩台 USB 攝影機皆可運作。
2. 開啟 **攝影機 → 攝影機設定**。攝影機插槽會顯示 **CAM 1** 與 **CAM 2**。
3. 在第二個插槽上點擊 **新增攝影機**，然後選擇攝影機。
4. 在切換模式下，將使用攝影機 1 的 **解析度與 FPS**。若攝影機 2 支援攝影機 1 的解析度，請開啟 **匹配攝影機 1 解析度**；否則攝影機 2 會使用自身的解析度，並縮放以符合。

若清單中找不到攝影機，請參閱[找不到攝影機](https://docs.uavmatrix.com/zh-tw/troubleshooting/camera-not-detected/)。

## 2a. 從遙控器切換攝影機

1. 在 **RC 通道切換** 下，開啟 **啟用 RC 通道攝影機切換**。
2. 在 **RC 通道** 中選擇一個未使用的通道。預設為通道 7。
3. 將遙控器上的兩段式開關對應到該通道。
4. 撥動開關並觀察 **當前 PWM**：低於 1500 µs 選擇攝影機 1，高於 1500 µs 則選擇攝影機 2。

![攝影機控制面板，「啟用攝影機」設為「是」，CAM 1 已填入，且 Add Camera 插槽為空](https://docs.uavmatrix.com/zh-tw/img/screenshots/uavcast-pro/camera--control-panel.webp)

*攝影機控制面板（僅一台攝影機）。只有在新增 CAM 2 且未開啟雙路視訊串流後，RC 通道切換面板才會出現在其下方。*

開啟 RC 切換後，網頁介面中的攝影機標籤將不會切換攝影機。若要重新以手動方式選擇攝影機，請關閉 RC 切換。

## 2b. 同時串流兩台攝影機

1. 開啟 **雙路視訊串流**。標籤會顯示 **雙路直播**。
2. 每台攝影機現在都可在 **單攝影機設定** 下，分別設定解析度、FPS 與位元率。
3. 開啟 **地面控制站**。每個目的地現在都會顯示 **視訊連接埠（攝影機 2）**。若留空，會使用 **視訊連接埠** + 1（5601）；您也可以輸入指定的連接埠。
4. 在地面站上，於該連接埠接收第二路串流，例如使用第二個 QGroundControl 視訊來源或 GStreamer 視窗：各作業系統中 QGroundControl、Mission Planner 與 GStreamer 的設定，請參閱[地面站與視訊](https://docs.uavmatrix.com/zh-tw/uavcast-pro/ground-stations/#set-up-the-receiving-side)。

> **注意 CPU 用量**
>
> UAVcast-Pro 以軟體進行視訊編碼。使用兩路串流時，請留意 **系統負載**。當其顯示 *CPU is near its limit* 時，請降低其中一路串流的解析度或位元率，或關閉第二路串流。建議雙路串流使用 Raspberry Pi 4 或 5。

**飛行地圖** 會為每一路啟用中的串流顯示一個視訊視窗。您可以將它們隱藏為地圖底部的標籤。

## 連接埠規劃

開啟雙路串流後，每個目的地會使用兩個視訊連接埠；若開啟 **傳送音訊到地面站**，音訊則使用視訊連接埠 + 2。若同一台電腦上新增更多目的地，請讓各目的地的視訊連接埠至少相隔 3，例如 5600 與 5610。

## 錄製兩台攝影機

在 **攝影機 → 錄製 → 設定** 下，**錄製攝影機 2** 僅在雙路視訊串流開啟時有效。請參閱[錄製飛行並回放檢視](https://docs.uavmatrix.com/zh-tw/guides/recording-flight-review/)。
