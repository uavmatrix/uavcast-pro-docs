疑難排解

請從症狀開始排查。以下每個頁面都依現場實際發生的順序列出可能的原因，並提供編號的檢查步驟，使用 UAVcast-Pro 與 Fleet Manager 介面中的確切標籤。

先檢查儀表板

請在 UAVcast-Pro 中開啟儀表板。狀態卡會以一行摘要說明無人機狀態（All systems normal，或問題與警告的數量），並分別列出 Flight controller、Ground station、Cellular、VPN、RTK corrections、Video 與 Power supply 各一列。通常第一個紅色的列就是開始排查的地方。

依症狀查詢​

您看到的情況可能原因前往
遙測正常，但 QGroundControl 或 Mission Planner 中的視訊區域為黑色啟用視訊已為該地面站關閉、IP 錯誤，或防火牆地面站無視訊
視訊凍結、出現灰色色塊或落後數秒位元率對連線而言過高，或關鍵影格間隔過遠視訊卡頓或延遲
飛行控制器頁面顯示 No heartbeat、Waiting for device 或 Detecting baud rate線材、接線、連接埠或鮑率沒有 MAVLink 心跳
UAVcast-Pro 將飛行控制器顯示為已連接，但地面站仍在等待連線遙測未發送至地面站，或地面站未在監聽地面站沒有遙測
選擇攝影機中顯示沒有可用的攝影機CSI 攝影機驅動程式堆疊缺失、排線問題，或未識別 USB 攝影機未偵測到攝影機
Invalid license key、Maximum activations reached 或 License activation failed金鑰錯誤、沒有可用的裝置名額，或沒有網際網路授權無法啟用
數據機顯示訊號與電信業者，但無法載入任何內容APN、網路優先順序或 SIM 卡數據數據機已連線但無網路
安裝後，瀏覽器無法連至 http://<device-ip>/位址錯誤、服務未執行，或連接埠已變更網頁介面無法開啟
安裝程式因錯誤而停止32 位元作業系統、沒有網際網路，或磁碟空間不足安裝失敗
ZeroTier 或 Tailscale 顯示已連線，但無法 ping 或開啟無人機成員未獲授權、網路錯誤，或地面站不在 VPN 上VPN 已連線但無法連到無人機
NTRIP 狀態不是正在傳輸校正資料，或定位始終無法達到 RTK 固定Caster 設定、GGA，或接收器無法使用 RTKRTK 校正資料未送達
Voltage too low - use a stronger power supply 或 Slowed down (heat or power)電源供應或電線不足、過熱欠壓與降速
無人機在 Fleet Manager 中顯示 Offline無人機沒有網際網路、MQTT 連接埠被封鎖，或需要重新配對Fleet Manager 中無人機離線
Invalid pairing code、This pairing code has expired 或 License is not owned by any member of this organization配對碼輸入錯誤或過舊，或授權由組織以外的人擁有配對碼無效或已過期

仍然無法解決？​

  1. 收集日誌檔案。下載內容包含您的設定與硬體的 diagnostics.txt 快照，因此支援人員無需再向您詢問這些資訊。
  2. 將日誌寄送至 support@uavmatrix.com，並附上您的 UAVcast-Pro 版本、所使用的硬體，以及您已嘗試過的步驟。您也可以在 UAVmatrix Discord 中提問。

常見問題的簡短解答請參閱常見問題。
