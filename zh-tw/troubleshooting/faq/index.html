常見問題

硬體與設定​

我需要 LTE 數據機嗎？​

不需要。UAVcast-Pro 可透過任何 IP 連線運作：4G/LTE、Wi-Fi 或乙太網路。數據機可讓您在 Wi-Fi 範圍之外飛行。許多操作人員會先在 Wi-Fi 下測試，並在飛行前切換至數據機：前往網路 → 網路優先順序 → 數據機優先（戶外模式）。

哪些電腦可以執行 UAVcast-Pro？​

任何採用 arm64 或 amd64 架構、並執行 Raspberry Pi OS、Debian 或 Ubuntu 的 64 位元 Linux 開發板或電腦皆可：Raspberry Pi Zero 2 W、3、4 與 5、NVIDIA Jetson、Orange Pi，以及 x86 迷你電腦。若要處理視訊，Raspberry Pi 4 或 5 是較理想的選擇。請參閱支援的硬體。

支援哪些飛行控制器？​

任何透過 USB 或 TELEM 連接埠使用 MAVLink 通訊的飛行控制器皆可：適用於 Pixhawk 與 Cube 系列開發板、Matek 及類似產品的 ArduPilot（Copter、Plane、Rover、VTOL 及其他飛行器類型）與 PX4。遙測、視訊以及傳送至地面站的路由功能，皆可搭配上述任一飛行控制器使用。飛行地圖與 Fleet Manager 中的飛行模式按鈕，使用的是 ArduPilot 的模式名稱；若使用 PX4，請從地面站切換模式。

可以透過飛行控制器的 USB 連接埠連線嗎？​

可以，這是最簡單的選項：插上後保持連接埠為自動即可。請使用可傳輸資料的短傳輸線。若找不到飛行控制器，請參閱沒有 MAVLink 心跳。

地面站與網路​

哪些地面站可以使用？​

任何支援透過 UDP 接收 MAVLink 的軟體皆可使用，包括 QGroundControl、Mission Planner 與 MAVProxy。視訊為透過 RTP/UDP 傳輸的 H.264，QGroundControl 與 Mission Planner 可直接播放。GStreamer 與 VLC 也可以使用：請參閱地面站與視訊。

多個地面站可以同時觀看嗎？​

可以。在地面控制站下為每台電腦各新增一個目標位址，並分別設定視訊與遙測的開關。若某些站台只需觀看，請使用 Read Only。請參閱串流至多個地面站。

UAVcast-Pro 使用哪些連接埠？​

預設情況下，遙測會發送至各地面站的 UDP 14550 連接埠，視訊則發送至 UDP 5600 連接埠；第二台攝影機使用視訊連接埠 + 1，音訊則使用視訊連接埠 + 2。網頁介面位於連接埠 80。完整清單請參閱連接埠與協定。

我需要在路由器上設定連接埠轉送嗎？​

不需要。透過 4G 時，請讓無人機與地面站位於同一個 VPN 中：Fleet Manager VPN（包含於您的授權中），或您自己的 Tailscale 或 ZeroTier 網路。無人機會將遙測與視訊發送至地面站的 VPN 位址。請參閱透過 4G 超視距飛行。

我仍然可以透過 TCP 5760 連線嗎？​

不行。自 v6.5.0 起，TCP 5760 已關閉，因此只有您新增的目標位址才會接收資料。請將您的電腦新增為目標位址，並使用 UDP。

沒有網際網路可以使用嗎？​

可以。飛行控制器連線、遙測與視訊會在開機時即開始運作，無需等待網際網路，因此本地 Wi-Fi 網路或無線電連結皆可使用。啟用授權時需要一次網際網路連線。之後，若因連線中斷導致授權檢查失敗，裝置不會被停用。

授權與帳戶​

啟動無人機需要 UAVcast-Pro 許可證。請在 UAVmatrix 商店購買。

我的授權無法啟用，該怎麼辦？​

請參閱授權無法啟用。常見原因包括金鑰輸入錯誤、沒有可用的裝置名額，或裝置沒有網際網路連線。

授權到期時會發生什麼事？​

UAVcast-Pro 會被鎖定：網頁介面只會開啟應用程式，遙測、視訊及其他服務都會停止，直到您續約為止。請在到期日前於商店續約，然後在裝置上驗證金鑰。請參閱授權到期時。

Fleet Manager 包含在我的授權中嗎？​

是的。Fleet Manager（包括其 VPN）已包含在您的 UAVcast-Pro 授權中，無需額外付費。

我更換了 SD 卡，需要新的授權嗎？​

不需要，但裝置會被視為新裝置，並佔用一個名額。請在應用程式 → 許可證管理器 → 已啟動設備下取消註冊舊的項目。

Fleet Manager 是獨立的產品嗎？​

Fleet Manager 是 UAVmatrix 的網頁儀表板，用於管理多架無人機，網址為 fleet-manager.uavmatrix.com。它已包含在您的 UAVcast-Pro 授權中。您可以使用 uavmatrix.com 帳戶登入，而您配對的每架無人機都需要一個由您組織的成員擁有的有效 UAVcast-Pro 授權。請參閱 Fleet Manager。

如何將無人機與 Fleet Manager 配對？​

在 UAVcast-Pro 中開啟 Fleet Management，然後按下 Connect to Fleet Manager。請在 5 分鐘內，於 Fleet Manager 的 Fleet → Pair Device 下輸入 8 位數代碼。請參閱配對您的第一架無人機；若配對失敗，請參閱配對碼無效或已過期。

更新與資料​

如何更新 UAVcast-Pro？​

前往應用程式 → 更新應用，在選擇要更新的版本中選擇版本，然後按下立即更新。若卡片顯示等待重啟，請按下立即重啟。您也可以再次執行安裝程式。

可以從 v4 或 v5 匯入設定嗎？​

不行。v6 使用新的資料庫，因此在全新安裝後需要重新設定。在 v6 中，您可以使用應用程式 → 資料庫 → 備份資料庫與恢復資料庫，在不同的安裝之間移動設定。

UAVcast-Pro 可以錄製視訊嗎？​

可以，自 v6.5.1 起支援。它可以從飛行地圖錄製攝影機 1 與 2，或在無人機解鎖時自動錄製，並同時記錄遙測記錄。請參閱錄製飛行並回放。

UAVcast-Pro 會將檔案保存在哪裡？​

檔案位於 /opt/uavcast-pro 之下：資料庫 uavcast.db、logs/、recordings/ 與 missions/。請參閱服務與檔案。

我忘記了管理員密碼。​

網頁介面沒有密碼重設功能。其他管理員可以在使用者中刪除您的使用者帳號，然後重新建立。若您是唯一的管理員，則無法自行復原：請依照忘記管理員密碼中列出的資訊，聯絡 support@uavmatrix.com。

我在哪裡可以取得協助？​

請依照為支援收集日誌的說明收集日誌，並寄送電子郵件至 support@uavmatrix.com，或在 UAVmatrix Discord 中提問。
