Fleet Manager

UAVmatrix Fleet Manager is a web app at fleet-manager.uavmatrix.com for running many drones from one place. Every drone that runs UAVcast-Pro can be paired to your organization. After that you see it on a live map, open its terminal, send commands, upload missions and route its video and telemetry to the ground stations your pilots use.

What you can do with it​

Add your first dronePair a UAVcast-Pro drone with an 8-digit code in about two minutes.Track the fleet liveEvery drone on one map, with status rings, a 5-minute trail and follow mode.Control drones remotelyFlight modes, arm and disarm, missions and preflight calibration from the browser.Stream to ground stationsSend video and MAVLink from many drones to QGroundControl or Mission Planner over VPN.Invite your teamOwner, Admin and Viewer roles per organization.Plan missionsDraw waypoints, save missions for the organization and upload them to any drone.

How it fits together​

Fleet Manager never talks to the flight controller directly. UAVcast-Pro on the drone's companion computer does that, and keeps one encrypted connection to Fleet Manager:

  1. Pairing. UAVcast-Pro asks Fleet Manager for a pairing code. You type the code into Fleet Manager. Fleet Manager then hands the drone its own client certificate.
  2. Control channel. The drone connects to Fleet Manager's MQTT broker over TLS on port 8883, authenticated with that certificate. Telemetry, heartbeats, commands, terminal sessions and remote access to the UAVcast-Pro web interface all travel over this connection. It works through NAT and cellular networks because the drone always connects outward.
  3. Data channel (optional). Video and MAVLink to a ground station go peer to peer over your organization's private VPN, a WireGuard network run by Fleet Manager. Without VPN, Fleet Manager still shows and controls the drone, but it doesn't route streams.

Concepts​

TermWhat it means in Fleet Manager
OrganizationYour company or team. Drones, missions, the VPN network and members belong to one organization. Each user can own one organization and be a member of any number of others.
UAVA drone (or rover, boat or other vehicle) running UAVcast-Pro, paired to one organization at a time. Fleet Manager identifies it by a device ID that UAVcast-Pro derives from the companion computer's CPU serial and boot disk, so it keeps its identity across reboots and network changes.
PairingLinking a UAV to an organization with an 8-digit code that UAVcast-Pro shows. The code is valid for 5 minutes.
Ground station (GCS)A laptop or PC running QGroundControl, Mission Planner or similar, joined to your organization's VPN so it can receive streams.
Stream bindingA rule that says "send this UAV's video and telemetry to that ground station". Each binding gets its own UDP ports, so one ground station can receive many drones at once.
RolesOwner, Admin or Viewer, set per organization. Viewers can watch; Admins and the Owner can pair, control and configure. See Roles and permissions.
Licenses and seatsEvery paired UAV needs an active UAVcast-Pro license owned by a member of the organization. Team members don't use up seats. See Licenses.
Status and alertsOnline, offline, no-MAVLink and GPS warnings on the map and fleet list, plus system announcements. See Status indicators and notifications.

What you need​

Fleet Manager is included with your UAVcast-Pro license: no separate subscription, no extra seats.

Fleet Manager is included with a UAVcast-Pro license. Each drone you pair needs one.

  • A UAVmatrix account (the same one you use at uavmatrix.com to buy licenses).
  • At least one companion computer with UAVcast-Pro installed and its license activated. See Installation and Activate your license.
  • Internet on the drone with outbound HTTPS (443) and TCP 8883 open.
