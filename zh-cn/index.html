硬件要求

伴随计算机、飞行控制器、摄像头和调制解调器。购买配件前请先确认。

  • Raspberry Pi、NVIDIA Jetson、Orange Pi
  • 任何 arm64 或 amd64 Linux 计算机
  • 任何 MAVLink 飞行控制器（ArduPilot、PX4）
  • USB 和 HiLink LTE 调制解调器

  2. 打开 应用程序 › 许可证管理器
