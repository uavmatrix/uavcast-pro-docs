# 设置参考

> UAVcast-Pro 的全部设置集中于一页，包含准确标签、默认值和取值范围：飞行控制器、NTRIP、地面站、摄像头、录制、调制解调器、VPN。

以下按页面列出 UAVcast-Pro Web 界面中的每一项设置，标签与应用中显示的完全一致，并给出全新安装时的默认值。实时应用的设置会立即生效，除非另有说明。功能页面会详细介绍各个功能领域；本页便于您快速查询。

## 飞行控制器 → 连接

| 设置 | 默认值 | 取值与说明 |
| --- | --- | --- |
| **启用链路** | 开启 | 开启或关闭飞行控制器链路。 |
| **链路类型** | **USB** | **USB**（飞行控制器自带的 USB 接口）或 **UART / Serial**（GPIO 引脚上的 TELEM 接口或 USB 转串口线）。 |
| **端口** | **自动** | 自动模式会查找飞行控制器，并在设备编号变化时跟随。**自定义路径…** 用于指定设备，例如 `/dev/ttyAMA0`。 |
| **波特率** | **自动** | 必须与飞行控制器上的 `SERIALx_BAUD` 一致。自动模式会依次尝试 57600、115200、921600、1500000、460800、230400 和 500000。USB 连接不使用此项。 |

按钮：**自动检测**（扫描所有端口和速率并保存结果）、**连接**、**重启链路**、**停止**。更改立即生效，无需重启。

## 飞行控制器 → NTRIP / RTK

| 设置 | 默认值 | 取值与说明 |
| --- | --- | --- |
| **启用 NTRIP 客户端** | 关闭 |  |
| **播发站主机** | 留空 | NTRIP 播发站的主机名。 |
| **端口** | `2101` | 部分 TLS 播发站使用 2102 或 443。 |
| **挂载点** | 留空 | 使用 **浏览挂载点** 进行选择。 |
| **使用 TLS（HTTPS）** | 关闭 | 适用于需要 TLS 的播发站。 |
| **用户名** / **密码** | 留空 | rtk2go.com：用户名填写电子邮件地址，无需密码。 |
| **向上游发送 GGA** | 开启 | VRS 和就近挂载点类型的播发站需要此项。 |
| **发送间隔（秒）** | `10` |  |
| **位置来源** | **来自飞行控制器的实时位置** | 或 **固定手动位置**（**纬度**、**经度**、**高度 (m)**），在首次 GPS 定位前也会作为备用位置使用。 |

## 飞行控制器 → 注入器

| 设置 | 默认值 | 取值与说明 |
| --- | --- | --- |
| **输入类型** |  | **HTTP**、**UDP** 或 **串口**。创建后无法更改。 |
| **MAVLink sysid** | `1` | 与飞行控制器相同。 |
| **MAVLink compid** | `194` | 用户载荷。 |
| **名称前缀** | 留空 | 最多 8 个 ASCII 字符，会添加到每个信号名称之前。 |
| **速率限制（每信号 Hz）** |  | 每个信号名称每秒的最大采样数。 |
| **协议**（UDP、串口） |  | **Key=Value（按行分隔）** 或 **JSON**（`{name, value}`）。 |
| **端口** / **绑定地址**（UDP） |  | 选择一个未占用的端口，例如 14600。`0.0.0.0` 表示所有接口，`127.0.0.1` 表示仅本地。 |
| **设备路径** / **波特率**（串口） |  | 例如 `/dev/ttyUSB0`；波特率必须与发送端一致。 |

## 地面控制站

每个目标地址对应一张卡片。

| 设置 | 新目标地址的默认值 | 取值与说明 |
| --- | --- | --- |
| **名称** | 留空 | 最多 50 个字符。 |
| **目标地址 IP 或主机** | 留空 | IPv4 地址。开启视频或遥测之前必须填写。 |
| **遥测端口** | `14550` | 1–65535。 |
| **视频端口** | `5600` | 1–65535。 |
| **视频端口（摄像头 2）** | 留空（= 视频端口 + 1） | 仅在开启 **双流** 时显示。 |
| **启用终端** | 开启 | 关闭后将停止发送至该目标地址的所有内容：遥测、视频和音频。 |
| **启用视频** | **关闭** |  |
| **启用遥测** | **关闭** |  |
| **只读** | 关闭 | 地面站接收遥测数据，但无法更改飞行器上的任何内容。 此行为自 UAVcast-Pro 6.5.3 起生效；在更早的版本中，只读不会阻止参数写入。 |

## 摄像头 → 摄像头设置

| 设置 | 默认值 | 取值与说明 |
| --- | --- | --- |
| **启用摄像头？** | 是 |  |
| **选择摄像头** | Raspberry Pi 摄像头 | 已检测到的 CSI 和 USB 摄像头。 |
| **分辨率** | 640×480 | 仅提供摄像头支持的尺寸。 |
| **选择帧率** | **自动** | 由摄像头协商确定。 |
| **比特率：** | `0`（自动） | 0–10000 kbps。 |
| **流恢复速率** | **自动** | 关键帧间隔。自动 = 每秒一个关键帧。更快的级别可以更早地从丢包中恢复，但会占用更多带宽。 |
| **旋转：** / **翻转设置** | 0°，不翻转 | **水平翻转**、**垂直翻转**。 |
| **启用实时预览？** | 是 | 在本页及飞行地图中显示预览。 |
| **自定义处理管道** | 测试管道 | 将覆盖地面控制站的目标地址设置。无需填写 `gst-launch-1.0` 前缀。 |
| **启用遥控通道摄像头切换** | 关闭 |  |
| **遥控通道** | 7 | PWM < 1500 = 摄像头 1，PWM > 1500 = 摄像头 2。 |
| **与摄像头 1 分辨率一致** | 关闭 | 摄像头 2 以摄像头 1 的分辨率采集。 |
| **双流** | 关闭 | 同时推送两台摄像头的视频。 |
| **音频** | 关闭 | 预览中的 Opus 音频。 |
| **音频设备** | **自动（如有摄像头麦克风则使用该麦克风）** | 或选择采集设备，或选择 **测试音（无需麦克风）**。 |
| **比特率**（音频） | 64 kbps |  |
| **向地面站发送音频** | 关闭 | 以 RTP/Opus 形式发送至每个视频目标地址的视频端口 + 2。 |

## 摄像头 → 录制 → 设置

| 设置 | 默认值 | 取值与说明 |
| --- | --- | --- |
| **存储位置** | **内部存储** | USB 驱动器或 SSD，或 **其他文件夹**。 |
| **保留空闲空间** | 2 GB | 0.5–1000 GB。 |
| **空间不足时删除最早的录像** | 开启 | 关闭后，磁盘写满时录制将停止。 |
| **删除早于以下时间的录像** | 0 天 | 0 表示在需要空间之前一直保留。 |
| **解锁时自动录制** | 开启 |  |
| **录制摄像头 1** / **录制摄像头 2** | 开启 / 开启 | 摄像头 2 仅在开启双流时可用。 |
| **文件时长** | 1 分钟 | 每个文件 1–30 分钟。 |
| **录制遥测** | **解锁时** | **连接期间始终** 或 **关闭**。 |
