# 双摄像头：遥控切换或双路传输

> 将两个摄像头连接到 UAVcast-Pro，通过遥控发射机切换，或使用双路传输同时传输两路视频。包括设置、端口和 CPU 说明。

UAVcast-Pro 支持两个摄像头，例如前向摄像头和下视或变焦摄像头。您可以在两种模式之间选择：

|  | **切换**（默认） | **双路传输** |
| --- | --- | --- |
| 地面控制站接收到的内容 | 一路视频流，显示摄像头 1 或摄像头 2 | 同时接收两路视频流 |
| 如何选择 | Web 界面中的摄像头标签，或遥控通道 | 两路始终处于实时状态 |
| 端口 | **视频端口** | 摄像头 1 使用 **视频端口**，摄像头 2 使用 **视频端口（摄像头 2）**（默认：视频端口 + 1） |
| CPU 和带宽 | 一次编码 | 两次编码，上行带宽约翻倍 |

## 1. 添加第二个摄像头

1. 连接两个摄像头。Pi 5 上的两个 CSI 摄像头、一个 CSI 摄像头加一个 USB 摄像头，或两个 USB 摄像头均可使用。
2. 打开 **摄像头 → 摄像头设置**。摄像头插槽会显示 **CAM 1** 和 **CAM 2**。
3. 点击第二个插槽上的 **添加摄像头**，然后选择摄像头。
4. 在切换模式下，将使用 **摄像头 1 的分辨率和帧率**。如果摄像头 2 支持摄像头 1 的分辨率，请开启 **与摄像头 1 分辨率匹配**；否则摄像头 2 将使用其自身分辨率，并缩放以匹配。

如果列表中找不到某个摄像头，请参阅 [未检测到摄像头](https://docs.uavmatrix.com/zh-cn/troubleshooting/camera-not-detected/)。

## 2a. 通过发射机切换摄像头

1. 在 **遥控通道切换** 下，开启 **启用遥控通道摄像头切换**。
2. 在 **遥控通道** 中选择一个空闲通道。默认为通道 7。
3. 将发射机上的两位开关映射到该通道。
4. 拨动开关并观察 **当前 PWM**：低于 1500 µs 选择摄像头 1，高于 1500 µs 选择摄像头 2。

![摄像头控制面板，启用摄像头设为是，CAM 1 已填充，添加摄像头插槽为空](https://docs.uavmatrix.com/zh-cn/img/screenshots/uavcast-pro/camera--control-panel.webp)

*仅有一个摄像头时的摄像头控制面板。只有在添加 CAM 2 且双路传输关闭后，遥控通道切换面板才会显示在其下方。*

开启遥控切换后，Web 界面中的摄像头标签将无法切换摄像头。如需手动重新选择摄像头，请关闭遥控切换。

## 2b. 同时传输两个摄像头

1. 开启 **双路传输**。标签将显示 **两路均实时**。
2. 每个摄像头现在都可以在 **各摄像头设置** 下设置各自的分辨率、帧率和码率。
3. 打开 **地面控制站**。每个目标地址现在都会显示 **视频端口（摄像头 2）**。将其留空即可使用 **视频端口** + 1（5601），也可以输入其他端口。
4. 在地面控制站上，在该端口接收第二路视频流，例如使用第二个 QGroundControl 视频源或 GStreamer 窗口。各操作系统上 QGroundControl、Mission Planner 和 GStreamer 的接收端设置，请参阅 [地面站与视频](https://docs.uavmatrix.com/zh-cn/uavcast-pro/ground-stations/#set-up-the-receiving-side)。

> **注意 CPU 负载**
>
> UAVcast-Pro 使用软件进行视频编码。在双路传输时，请留意 **系统负载**。当它显示 **CPU 接近上限** 时，请降低其中一路的分辨率或码率，或关闭第二路视频流。建议使用 Raspberry Pi 4 或 5 进行双路传输。

**飞行地图** 会为每个活动的视频流显示一个视频窗口。您可以将它们隐藏为地图底部的标签页。

## 端口规划

开启双路传输后，每个目标地址将使用两个视频端口；如果开启了 **向地面站发送音频**，音频将使用视频端口 + 2。如果同一台计算机上添加了更多目标地址，请使各目标地址的视频端口至少相隔 3，例如 5600 和 5610。

## 双摄像头录制

在 **摄像头 → 录制 → 设置** 下，**录制摄像头 2** 仅在开启双路传输时可用。请参阅 [录制飞行并进行复盘](https://docs.uavmatrix.com/zh-cn/guides/recording-flight-review/)。
