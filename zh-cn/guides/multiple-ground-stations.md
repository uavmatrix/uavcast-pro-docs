# 向多个地面控制站传输

> 使用 UAVcast-Pro 将一架无人机的遥测和实时视频发送到多个 QGroundControl 或 Mission Planner 地面站，并支持只读观察者。

一架无人机，多块屏幕：Mission Planner 上的飞手、QGroundControl 上的载荷操作员，以及在办公室里监看的主管。UAVcast-Pro 会将遥测和视频发送到您添加的每个目标地址，且每个目标地址都有各自的开关。

## 工作原理

**地面控制站** 下的每一项都是一个目标地址，包含一个 IPv4 地址、一个遥测端口和一个视频端口。UAVcast-Pro 会按以下方式发送数据：

- 当 **启用遥测** 开启时，通过 UDP 将 MAVLink 遥测发送到 **遥测端口**（默认 14550），
- 当 **启用视频** 开启时，通过 RTP/UDP 将 H.264 视频发送到 **视频端口**（默认 5600），
- 当 **启用终端** 关闭时，不发送任何数据。

除非某个目标地址被设为 **只读**，否则每个目标地址发出的命令都会到达飞行控制器。

## 1. 为每个地面站添加目标地址

1. 打开 **地面控制站**，为每个地面站分别按下一次 **添加目标地址**。
2. 为每个目标地址填写便于识别的 **名称**，例如 *飞手 – Mission Planner* 和 *载荷 – QGC*。
3. 在 **目标IP或主机** 中输入每台计算机的 IPv4 地址。通过 4G 连接时，请使用 VPN 地址。
4. 在需要的地方开启 **启用遥测** 和 **启用视频**。仅需要遥测的地面站可以关闭视频以节省带宽。

![地面控制站页面，包含两张目标地址卡片和添加目标地址按钮](https://docs.uavmatrix.com/zh-cn/img/screenshots/uavcast-pro/ground-control.webp)

*包含两张目标地址卡片的地面控制站。每点击一次添加目标地址，就会为一个地面站增加一张卡片。*

## 2. 将观察者设为只读

对于只需观看、不需操控飞行的人员，请在其目标地址上开启 **只读**。该地面站仍可接收实时遥测，但无法对飞行器进行任何更改：该地面站发出的命令、模式切换、解锁、参数写入、任务写入和遥控覆盖均会被阻止。此行为自 UAVcast-Pro 6.5.3 起生效；在更早的版本中，只读不会阻止参数写入。 在此模式下，地面站软件可能会显示警告，因为其部分请求（例如下载参数或任务）将得不到响应。

> **两名飞手，一架无人机**
>
> 如果未开启只读，每个地面站都可以对无人机下达命令。请事先约定由谁操控飞行，并将其他所有地面站设为只读。

## 3. 同一台计算机上运行两个地面站

同一台计算机上的两个程序无法监听相同的端口。请添加两个 IP 相同但端口不同的目标地址，例如：

| 目标地址 | 遥测端口 | 视频端口 |
| --- | --- | --- |
| Mission Planner | 14550 | 5600 |
| QGroundControl | 14551 | 5603 |

然后将第二个程序设置为监听这些端口（在 QGroundControl 中，添加一个监听 14551 端口的 UDP 通信链路，并将视频 UDP 端口设为 5603）。

视频端口之间请**相隔 3**（5600、5603、5606……）。每个目标地址使用其视频端口；在[双路传输](https://docs.uavmatrix.com/zh-cn/guides/dual-camera-rc-switching/)时，第二个摄像头使用视频端口 + 1；[音频](https://docs.uavmatrix.com/zh-cn/uavcast-pro/camera/audio/)使用视频端口 + 2。如果端口间隔过近，一旦开启双路传输或音频，端口就会冲突。

## 4. 注意上行带宽

每个视频目标地址都会获得一份独立的视频流副本。三个视频目标地址各以 1500 kbps 传输，无人机需要约 4.5 Mbit/s 的上行带宽。通过 4G 连接时，请仅向需要视频的地面站发送视频，或在 **摄像头 → 摄像头设置** 中降低码率。**仪表盘 → 网络流量** 可显示调制解调器的实际发送量。

## 5. 检查每个地面站是否都收到数据

在 **仪表盘** 上，**地面站** 一行会显示 *发送至 n · x 包/秒*。**飞行控制器 → 连接** 下的 **连接检查** 会列出每个地面站的输出，以及因地址无效而被排除的目标地址。

## 与 Fleet Manager 配合使用

在 Fleet Manager 中，地面站会加入组织的 VPN，并通过 **网络** 页面中的 **Stream Bindings** 将其与无人机相连。每架绑定到同一地面站的额外无人机都会获得自己的一组端口。 请参阅 [流绑定](https://docs.uavmatrix.com/zh-cn/fleet-manager/network/stream-bindings/)。
