角色与权限

Fleet Manager 共有三种角色，按组织单独设置。同一人员可以在一个组织中担任 Admin，而在另一个组织中担任 Viewer。

角色简要说明
Owner拥有 Admin 的全部权限，另外还可以删除组织和转让所有权。每个组织有且仅有一位 Owner：即创建该组织的人，或获得所有权转让的人。
Admin负责管理机队：配对和移除无人机，发送命令，打开终端，规划和上传任务，管理 VPN 和流绑定，并管理团队。
Viewer只读。可查看仪表盘、机队、实时地图、飞行历史、任务、网络和团队，但不能更改或控制任何内容。

新成员以 Admin 或 Viewer 的身份受邀加入。Owner 角色只能通过转让所有权交接。

Admin 可以管理其他 Admin

Admin 可以邀请新的 Admin，将其他 Admin 降级为 Viewer，并移除其他 Admin。请仅将 Admin 角色授予您信任能够管理整个机队的人员。Owner 是 Admin 唯一无法更改的成员。

Viewer 可以看到的内容

Viewer 看到的页面与其他角色相同，但没有控制功能。UAV 控制面板会向 Viewer 显示实时状态和日志，但不显示飞行模式、任务或解锁按钮，也没有 Terminal 标签页。在 Network 页面上，Viewer 无法看到 VPN 认证密钥：Only Owners and Admins can see the VPN auth key. 此外，Fleet Manager 会在服务器端检查每条命令，因此 Viewer 无法通过其他方式发送命令。

为企业机队选择角色​

人员建议角色
机队或运营经理Owner（仅一人）
飞手、技术人员、负责配对新机身的人员Admin
跟踪任务进展的客户、管理层、审计人员Viewer
需要驾驶您无人机的承包商Admin，任务结束后移除

并非角色：超级管理员​

UAVmatrix 工作人员拥有一种跨所有组织的独立支持角色。该角色用于处理支持任务，例如为账户添加额外的许可证电子邮件。它不属于您的组织，也无法被分配。
