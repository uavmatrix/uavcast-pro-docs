# 蜂窝调制解调器（4G/LTE）

> 将 HiLink 或传统 4G/LTE USB 调制解调器连接到 UAVcast-Pro，支持自动 APN 检测、SIM PIN、自动重连以及调制解调器信号信息，适用于蜂窝网络飞行。

4G/LTE 调制解调器可让无人机在任何蜂窝网络覆盖范围内接入互联网，使遥测和视频能够传输到远超 Wi-Fi 覆盖距离的地面站。UAVcast-Pro 支持 **HiLink** 调制解调器（可自行连接）和 **传统（PPP）** 调制解调器（由 UAVcast-Pro 通过 ModemManager 连接）。对于传统调制解调器，它会自动查找 APN，在开机时连接，并在断线后自动重连。在侧边栏中打开 **调制解调器**。

## 我的调制解调器是哪种类型？

|  | HiLink | 传统（PPP） |
| --- | --- | --- |
| 显示方式 | 一块网卡（`usb0` 或 `eth1`）。调制解调器自带路由器和 Web 页面，通常位于 `192.168.8.1`。 | 由 ModemManager 管理的调制解调器设备。连接通常显示为 `ppp0` 或 `wwan0`。 |
| 由谁连接 | 调制解调器本身。 | UAVcast-Pro，通过 ModemManager 和 NetworkManager。 |
| UAVcast-Pro 中的设置 | 无。如有需要，请在调制解调器自己的 Web 页面中设置 APN。 | APN（可选）、用户名、密码、PIN。 |
| 示例 | Huawei E3372h、E8372 | Huawei E3372s、Quectel EC25 / EG25、Sierra Wireless |

不确定？插入调制解调器后，在无人机上运行 `mmcli -L`。如果 ModemManager 列出了它，请选择 **传统（PPP）**。如果没有列出，但 **网络** 中出现了新的网络接口，则它是 HiLink。

## 设置传统调制解调器

1. 插入数据 SIM 卡，并将调制解调器连接到伴随计算机。
2. 前往 **调制解调器**。将 **启用调制解调器** 设置为 **是**，并将 **调制解调器类型** 设置为 **传统（PPP）**。
3. 将 **接入点名称（可选）** 留空。UAVcast-Pro 会自动检测。
4. 如果您的 SIM 卡需要，请输入 **PIN 码（可选）**。
5. 等待 30 至 90 秒。连接成功后，**调制解调器信息** 会显示运营商、网络制式以及 **IPv4 信息**。

插入后的调制解调器会自动连接。如果您选择 **断开连接**，它将保持断开状态，直到您再次连接，即使重启之后也是如此。

### 自动 APN 的工作方式

当 APN 字段为空时，UAVcast-Pro 将按以下顺序尝试：

1. 此 SIM 卡运营商上次成功使用的 APN，
2. 网络默认 APN（空 APN），
3. 调制解调器附着到 LTE 网络时所使用的 APN，
4. 来自移动宽带服务商数据库的运营商互联网 APN。

第一个获得互联网地址的 APN 会针对该运营商保存。更换为其他运营商的新 SIM 卡后，它会重新检测。如果您的运营商需要特殊 APN（专用 APN、M2M 或企业 SIM 卡），请手动输入。此时仅会尝试用户设置的 APN。

## 设置 HiLink 调制解调器

1. 插入调制解调器。等待其指示灯显示稳定连接。
2. 在 **调制解调器** 中，将 **启用调制解调器** 设置为 **是**，并将 **调制解调器类型** 设置为 **HiLink**。
3. 检查 **HiLink 调制解调器信息**：您应该能看到 **接口** 和 **IP 地址**。

HiLink 调制解调器会自行连接、选择网络并重新连接，因此没有连接按钮。请在调制解调器自己的 Web 页面中更改 APN、PIN 或网络模式（从无人机所在网络访问，通常为 `http://192.168.8.1`）。

## 设置参考

| 设置 | 默认值 | 可选值 | 说明 |
| --- | --- | --- | --- |
| **启用调制解调器** | **是** | **是**、**否** |  |
| **调制解调器类型** | **传统（PPP）** | **HiLink**、**传统（PPP）** |  |
| **接入点名称（可选）** | 留空（**自动**） | 您的运营商提供的 APN | 仅适用于传统调制解调器。 |
| **用户名（可选）** / **密码（可选）** | 留空 |  | 仅适用于传统调制解调器。大多数运营商两者都不需要。 |
| **PIN 码（可选）** | 留空 | SIM 卡 PIN | 仅适用于传统调制解调器。如果 SIM 卡没有 PIN，请留空。 |

## 调制解调器信息

对于传统调制解调器，**调制解调器信息** 会显示 **信号质量**、**网络制式**（LTE、UMTS 等）、**需要解锁**、**状态**、**制造商**、**IMEI**、网络信息（**运营商**、**代码**、**注册**）、**IPv4 信息**（**IP 地址**、**网关**、**DNS**、**MTU**）以及 **连接属性**（**APN**、**IP 类型**、**漫游**）。

仪表盘中的 **蜂窝** 行会显示相同的信号摘要。

## 蜂窝网络飞行前的准备

- 在 [网络](https://docs.uavmatrix.com/zh-cn/uavcast-pro/connectivity/networks/) 页面中，选择 **调制解调器优先（户外模式）**，这样即使起飞时 Wi-Fi 仍在覆盖范围内，流量也会保持在调制解调器上。
- 使用 [VPN](https://docs.uavmatrix.com/zh-cn/uavcast-pro/connectivity/vpn/)：蜂窝运营商不会为无人机分配地面站可以访问的地址。
- 在飞行控制器上启用 **地面站故障保护**。
- 在高空检查信号：覆盖范围是针对地面规划的，爬升时信号会发生变化。

## 故障排除

| 现象 | 检查项 |
| --- | --- |
| *未连接调制解调器* | 未检测到调制解调器。请检查 USB 连接以及调制解调器的电源指示灯。如果树莓派在调制解调器连接时重启，请使用带外接电源的 USB 集线器。 |
| **需要解锁** 显示 *已锁定* | 输入 SIM 卡 PIN，或在手机中禁用 PIN。 |
| 已注册，但没有 IP 地址 | APN 错误。请输入运营商的 APN，而不是使用自动。 |
| 连接后在负载下断开 | 通常是电源问题。请检查仪表盘中的 **电源** 行。 |

**操作日志** 会显示每次 APN 尝试及其失败原因。更多帮助请参阅 [调制解调器已连接但无法上网](https://docs.uavmatrix.com/zh-cn/troubleshooting/modem-no-internet/)。
