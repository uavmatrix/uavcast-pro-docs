连接：调制解调器、VPN、DNS 与网络

通过 4G/LTE 将 UAVcast-Pro 连接到互联网，通过 VPN 访问设备，使用动态 DNS 对外发布，并选择由哪个网络承载流量。

📄️蜂窝调制解调器

将 HiLink 或传统 4G/LTE USB 调制解调器连接到 UAVcast-Pro，支持自动 APN 检测、SIM PIN、自动重连以及调制解调器信号信息，适用于蜂窝网络飞行。

📄️VPN

使用 Fleet Manager VPN，或您自己的 Tailscale 或 ZeroTier 网络，将无人机与地面站置于同一专用网络中，使遥测和视频可通过 4G/LTE 正常工作。

📄️动态DNS

使用 UAVcast-Pro 动态DNS（No-IP、DynDNS、DuckDNS 或通用 URL）让主机名始终指向无人机变化的公网 IP，并说明何时 VPN 是更好的选择。

📄️网络

查看无人机上的每个网络接口，并选择由 Wi-Fi 还是 4G/LTE 调制解调器承载流量，使飞出 Wi-Fi 覆盖范围时链路仍保持在蜂窝网络上。
