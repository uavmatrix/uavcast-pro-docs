摄像头设置

UAVcast-Pro 从树莓派 CSI 摄像头或 USB 网络摄像头采集视频，将其编码为 H.264，并以 RTP over UDP 的形式发送到每个启用了 启用视频 的地面控制站。Mission Planner 和 QGroundControl 可直接通过端口 5600 播放。视频流的副本会用于 Web 界面中的实时预览以及无人机上的录制器。打开 摄像头 → 摄像头设置。

设置摄像头​

  1. 连接摄像头，然后前往 摄像头 → 摄像头设置。
  2. 将 启用摄像头？ 设置为 是。
  3. 点击 CAM 1 插槽并选择摄像头。CSI 摄像头显示为 Raspberry Pi Camera - imx708 (CSI) 或类似名称；USB 摄像头则显示其名称。
  4. 在 摄像头设置 下，选择摄像头支持的 分辨率。不受支持的尺寸会被标记。
  5. 首次设置时，将 选择帧率 保持为 自动，并将 比特率 保持为 0（自动）。
  6. 在 流设置 下，勾选 启用实时预览？ 并选择 启动。
  7. 在 地面控制站 中，为每个需要接收视频的地面站启用 启用视频。

如果列表中没有出现摄像头，请查看页面底部的 操作日志：其中会显示摄像头检测器检查过的每个设备，以及跳过该设备的原因。

为您的链路选择设置​

没有唯一正确的设置：比特率必须适配链路中最慢的部分，并为遥测保留余量。以下是单个摄像头的起始参考值：

链路分辨率帧率比特率流恢复速率
本地 Wi-Fi 或有线以太网1920x1080304000–6000 kbps自动
良好的 4G/LTE1280x720301500–2500 kbps30 帧
较弱的 4G 或远距离链路1280x720 或 854x48015–20800–1200 kbps15 帧

如果丢包后画面卡顿或出现灰色拖影，请先降低比特率，然后降低 流恢复速率，使关键帧更频繁地出现。

CPU 负载​

系统负载 指示器显示编码器的工作强度。在树莓派 5 上，每路视频流都使用软件编码（树莓派 5 没有 H.264 硬件编码器），因此高分辨率或两路视频流可能会使 CPU 满载。当它提示 CPU 接近上限。请降低分辨率或比特率。 时，请在飞行前进行调整。

实时预览​

实时预览 通过内置媒体服务器（WebRTC，端口 8889）在浏览器中播放视频流。根据网络情况，它比地面站接收到的 UDP 视频流延迟约数百毫秒。使用新标签页打开按钮可全屏观看。浏览器默认以静音状态启动预览；如果您使用 音频，请在播放器中取消静音。

预览需要浏览器能够直接访问无人机的 8889 端口。它可在局域网和 VPN 中使用，但无法通过 Fleet Manager 的 Open via Proxy 访问，因为该功能仅转发 Web 界面。预览请使用 Open via VPN。

视频流传输方式地面站上的端口

摄像头 2 视频（双路流）H.264，RTP over UDP视频端口（摄像头 2），默认为视频端口 + 1（5601）
音频（可选）Opus，RTP over UDP视频端口 + 2（5602）
