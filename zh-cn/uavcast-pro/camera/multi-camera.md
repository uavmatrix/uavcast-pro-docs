# 两台摄像头：RC 切换与双路流

> 将两台摄像头连接到 UAVcast-Pro，并通过遥控器的 RC 通道在两者之间切换，或将两路视频以不同的 UDP 端口同时发送到 QGroundControl 或 Mission Planner。

UAVcast-Pro 支持两台摄像头，例如前向 FPV 摄像头和向下或云台摄像头。您可以通过两种方式使用它们：

- **切换**：只有一路视频流，您可以通过 Web 界面或遥控器上的 RC 通道选择由哪台摄像头提供视频流。占用一路视频流的带宽和 CPU。
- **双路流**：两台摄像头同时推流，各自使用独立的 UDP 端口，并且各自拥有独立的分辨率、帧率和比特率。占用两倍的带宽和 CPU。

支持的组合：CSI + USB、两台 USB 摄像头，或在具有两个摄像头接口的主板（Raspberry Pi 5、Compute Module 载板）上使用两台 CSI 摄像头。

## 添加第二台摄像头

1. 前往 **摄像头 → 摄像头设置**。确保 **CAM 1** 已有摄像头。
2. 在 CAM 1 旁选择 **添加摄像头**，然后选择第二台摄像头。它会出现在 **CAM 2** 插槽中。
3. 点击某个插槽，将该摄像头设为当前活动摄像头（*点击切换到摄像头 2*）。

在切换模式下，两台摄像头共享摄像头 1 的分辨率和帧率（*将使用摄像头 1 的分辨率和帧率*）。如果摄像头 2 不支持该尺寸，它将使用其原生分辨率并进行缩放，除非您为支持该功能的摄像头启用了 **与摄像头 1 分辨率匹配**。

## 通过遥控器切换摄像头

只有当两个摄像头都已设置且未启用双路流时，才会显示 **RC 通道切换**。

1. 在遥控器上，将一个双位开关分配到空闲通道，例如通道 7。在 Mission Planner 中，或在 **飞行地图 → Radio** 中，确认该通道在约 1000 至 2000 µs 之间变化。
2. 在 **RC 通道切换** 下，启用 **启用 RC 通道摄像头切换**。
3. 选择 **RC 通道**。
4. 拨动开关并观察 **当前 PWM**。低于 1500 时选择摄像头 1，高于 1500 时选择摄像头 2。

![摄像头控制面板，CAM 1 已填充，添加摄像头插槽为空](https://docs.uavmatrix.com/zh-cn/img/screenshots/uavcast-pro/camera--control-panel.webp)

*摄像头插槽：CAM 1 已占用，**添加摄像头** 用于添加第二台摄像头。当两个插槽都已填充且未启用双路流时，将显示 **RC 通道切换**。*

启用 RC 切换时，点击摄像头插槽不会有任何效果，因为此时由发射机控制。如需手动选择摄像头，请禁用 RC 切换。

| 设置 | 默认值 | 可选值 | 说明 |
| --- | --- | --- | --- |
| **启用 RC 通道摄像头切换** | 禁用 | 启用、禁用 |  |
| **RC 通道** | 通道 7 | 通道 1–18 | 从飞行控制器的 RC 输入读取。 |
| 切换点 | 1500 µs | 固定 | PWM < 1500 = 摄像头 1，PWM > 1500 = 摄像头 2。 |

## 同时推送两台摄像头的视频流（双路流）

1. 设置好两台摄像头后，在摄像头页面中启用 **双路流**。徽章会显示 **Both live**。
2. 在 **单摄像头设置** 下，分别为每台摄像头设置分辨率、帧率和比特率。
3. 在 [地面控制站](https://docs.uavmatrix.com/zh-cn/uavcast-pro/ground-stations/) 中，每个目标地址现在都有 **视频端口（摄像头 2）**。留空则使用 **视频端口** + 1（`5601`），或输入其他端口。如果同一台计算机上有多个目标地址，请将其视频端口间隔 3（`5600`、`5603` …），以免摄像头 2 和音频落到另一个目标地址的端口上。
4. 在地面站上为该端口设置第二个视频接收端。

摄像头 1 会发送到每个地面站的 **视频端口**（默认 `5600`），摄像头 2 会发送到 **视频端口（摄像头 2）**（默认 `5601`）。

QGroundControl 一次只能显示一路视频流。要观看摄像头 2，请运行第二个接收端，例如在端口 5601 上运行第二个 QGroundControl 实例、在 Mission Planner 中使用端口 5601 的 GStreamer 源，或直接使用 GStreamer：

```bash
gst-launch-1.0 udpsrc port=5601 caps="application/x-rtp, media=(string)video, clock-rate=(int)90000, encoding-name=(string)H264" ! rtph264depay ! avdec_h264 ! videoconvert ! autovideosink sync=false
```

> **注意 CPU 和链路**
>
> 两路视频流会使编码负载和带宽翻倍。请留意 **系统负载**（*CPU 接近上限。请降低某路视频流的分辨率/比特率，或关闭第二路视频流。*），并将合计比特率控制在蜂窝上行链路的余量之内。常见的分配方式是：主摄像头使用 1280x720、1500 kbps，第二台摄像头使用 854x480、600 kbps。

飞行地图会为每路活动视频流显示一个视频窗口。录制可以同时包含两台摄像头：请参阅 [录制](https://docs.uavmatrix.com/zh-cn/uavcast-pro/camera/recordings/) 中的 **录制摄像头 2**。

## 故障排除

- **列表中缺少第二台摄像头**：两台 CSI 摄像头需要具有两个摄像头接口的主板。在树莓派上，安装 UAVcast-Pro 后请重启：安装程序会扩大摄像头内存池（CMA），以便两台摄像头同时运行。
- **摄像头 2 画面变形**：在切换模式下，摄像头 2 会被缩放到摄像头 1 的分辨率。请使用宽高比相同的摄像头，或启用 **与摄像头 1 分辨率匹配**。
- **切换无反应**：检查 **当前 PWM**。*无信号* 表示飞行控制器未在该通道上报告 RC 输入。
