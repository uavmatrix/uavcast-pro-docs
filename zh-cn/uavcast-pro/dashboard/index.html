仪表盘

仪表盘是伴随计算机的飞行前检查清单。一张状态卡片会告诉您飞行控制器、GPS、电池、地面站链路、调制解调器、VPN、RTK、视频和电源供应是否正常，并给出 所有系统正常 或 2 个问题 之类的摘要。其下方是系统信息、网络流量、内存和存储。请在侧边栏中打开 仪表盘。

状态卡片​

该卡片分为三组。每一行都有一个彩色圆点：绿色表示正常，黄色表示警告，红色表示问题。

行示例值如果不是绿色，应如何处理
飞行控制器已解锁、已上锁、链路已停止、连接中…参阅飞行控制器。
GPS3D 定位 · 14 颗卫星、RTK 固定、未定位、无 GPS在户外等待定位，或检查 GPS 接线。
电池电压和百分比为电池充电，或检查飞行控制器的电池监测设置。
地面站发送至 2 个 · 16 包/秒、未发送、已设置 1 个 · 等待飞行控制器、未设置参阅地面控制站。
蜂窝网络运营商和信号，未检测到调制解调器参阅蜂窝调制解调器。
VPN已连接、未连接、已关闭参阅 VPN。
RTK 修正数据连接中…、错误 - 请检查设置、已关闭参阅 NTRIP / RTK。
视频运行中、已停止、已关闭参阅摄像头。
动态DNS运行中、已关闭参阅动态DNS。
电源稳定、电压过低 - 请使用功率更大的电源、已降速（过热或供电）、启动后电压下降参阅电源与温度。

任一行上显示的 服务故障 - 正在重启 表示该服务已崩溃，并正在自动重启。如果持续显示，请从 应用程序 → 日志 下载日志。

电源与温度​

在树莓派上，系统信息 会显示 电源、CPU限制 和 温度：

  • 电压过低 - 请使用功率更大的电源：树莓派当前处于欠压状态。这会导致 USB 复位，因此调制解调器或飞行控制器可能会断开。飞行前请先修复供电。
  • 启动后电压下降：自开机以来的某个时刻曾出现过欠压。通常由调制解调器的发射峰值引起。
  • 降速（过热或供电）：CPU 已被降频。视频编码会首先受到影响。请加装散热片或改善风道，或修复供电。

当树莓派接近降频阈值时，温度条会变为红色。

其他卡片​

卡片显示内容
系统信息操作系统、硬件（CPU 和内核数）、运行时间、电源和温度。
网络流量每个接口的接收和发送总量及速率。可选择 最近 50 至 最近 1000 个采样点。便于检查视频在调制解调器上占用了多少流量。
内存使用总计、已用和空闲。每 10 秒收集一次数据。
存储每个分区的总计、已用和空闲。

图表需要在开机后收集几分钟的数据，才会显示内容。

导览指引​

首次打开 Web 界面时，导览会提供主要页面的逐步介绍。您可以选择 跳过导览 或 不再显示。如需重新开始，请前往 应用程序 → 设置 → 导览。

电源问题的详细说明，请参阅欠压与降频。
