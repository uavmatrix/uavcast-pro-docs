# 数据流

> 创建 UAVcast-Pro 数据流仪表板，使用图表、仪表和面板显示任何 MAVLink 字段或 NAMED_VALUE_FLOAT 传感器数值，并支持阈值、历史记录以及 JSON 导入/导出。

数据流可让您构建自己的实时遥测仪表板。添加数字面板、折线图、仪表盘、条形指示器和状态灯，并将每个组件绑定到飞行控制器发送的任何 MAVLink 数值，或来自传感器或[注入器](https://docs.uavmatrix.com/zh-cn/uavcast-pro/flight-controller/injectors/)的任何 `NAMED_VALUE_FLOAT` 信号。仪表板保存在无人机上，因此每个打开 Web 界面的人看到的都是同一组面板。请在侧边栏中打开 **数据流**。

典型用途：载荷操作员查看传感器读数的屏幕、显示 RSRP 和 SINR 的 LTE 链路面板，或用于长航时飞行的电池与电源面板。

![数据流页面，显示尚无仪表板，并带有创建仪表板按钮](https://docs.uavmatrix.com/zh-cn/img/screenshots/uavcast-pro/mission-data.webp)

*创建第一个仪表板之前的数据流页面：选择 **创建仪表板** 即可新建一个。*

## 创建仪表板

1. 选择 **创建仪表板**（如果已有仪表板，则选择 **新建仪表板**），为其设置 **名称**，然后选择 **创建**。
2. 选择 **编辑** 进入编辑模式，然后选择 **添加小部件** 并选取一种类型。
3. 在 **来源** 标签页中搜索并选择一个信号。绿点表示样本正在到达。
4. 在 **显示** 中设置标题、单位和小数位，在 **范围** 中设置限值和颜色阈值，在 **图表** 中设置图表选项。选择 **保存**。
5. 拖动并调整小部件大小，然后选择 **完成**。

只有管理员可以创建和编辑仪表板。只读用户可以查看仪表板。

## 小部件类型

| 类型 | 显示内容 |
| --- | --- |
| **数字面板** | 当前值，字体较大，可选前缀和后缀。 |
| **迷你折线图** | 数值下方的小型趋势线。 |
| **折线图** | 一个或多个信号在时间窗口内的变化。 |
| **仪表盘** | 以圆形刻度显示数值，并带有彩色阈值。 |
| **条形指示器** | 以介于最小值和最大值之间的条形显示数值。 |
| **状态** | 由阈值决定的彩色状态，例如 正常 / 警告 / 报警。 |
| **命名值表** | 所有 `NAMED_VALUE_FLOAT` 信号，包含 **值**、**时长** 和 **源**。**过滤器** 接受子字符串或 `*.glob`。 |

当超过 5 秒未收到样本时，小部件会显示 **已过期**；当从未见过该信号时，则显示 *尚无样本*。

## 信号

- **MAVLink 字段**：飞行控制器发送的每个数值字段（姿态、VFR HUD、电池、GPS、Home、RTK、故障保护、心跳以及状态值）都会自动出现，并尽可能附带易读的名称和单位。
- **命名值**：`NAMED_VALUE_FLOAT` 信号，显示为 `NAME@sysid:compid`，例如 `LTE_RSRP@1:194`。

您可以输入尚未发送数据的信号，然后按 Enter 添加，因此可以在连接传感器之前先搭建仪表板。在选中的来源上使用铅笔图标，即可为其设置显示名称。

## 图表选项

| 选项 | 取值 |
| --- | --- |
| **时间窗口** | **1 分钟**、**5 分钟**、**15 分钟**、**1 小时**，或**自定义（秒）** |
| **曲线** | **线性**、**平滑（单调）**、**阶梯**、**前阶梯**、**后阶梯**、**基础样条** |
| 其他 | **显示图例**、**显示网格**、**线宽**、**区域填充**、**显示数据点**、**阈值参考线**、**Y 轴标签** |

## 历史记录

UAVcast-Pro 会在无人机上保存每个信号的短期历史（每个信号最多 3600 个样本，以 1 Hz 计约为一小时），因此打开仪表板后，图表会立即填充数据，即使刷新页面之后也是如此。

## 共享仪表板

- **导出 JSON** 会将仪表板复制到剪贴板。
- **导入 JSON** 可从粘贴的 JSON 创建仪表板。可用于将面板复制到另一台无人机。
- **复制** 和 **重命名** 位于工具栏中；**删除** 会删除仪表板及其小部件。
- **全屏** 会隐藏界面的其余部分，适用于专用显示器。
