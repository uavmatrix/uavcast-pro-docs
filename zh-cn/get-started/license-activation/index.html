许可证与激活

每架无人机都需要已激活的 UAVcast-Pro 许可证密钥。您可以在 UAVmatrix 商店购买许可证，然后在无人机的应用程序 → 许可证管理器中粘贴密钥并选择验证。每个许可证都有若干设备名额：激活一架无人机占用一个名额，注销后即可释放该名额供其他无人机使用。

激活无人机需要 UAVcast-Pro 许可证。请在 UAVmatrix 商店购买。

购买 UAVcast-Pro查看套餐和价格

购买许可证​

许可证在 uavmatrix.com/products 上销售。每个许可证都包含整个有效期内的更新，以及 Fleet Manager 的使用权，其中包括用于通过 4G 访问无人机的 VPN。

套餐设备名额有效期
Basic11 年
Silver21 年
Gold42 年

商店页面始终显示当前的套餐和价格。没有免费试用许可证。

付款后，您将收到一封订单确认邮件，其中包含许可证密钥（由五组、每组四个字符组成）。

密钥也可在商店账户的许可证下查看，并附带设备名额和到期日期。

许可证有效期从首次激活时开始计算

今天购买、下个月才激活的许可证，将从激活日期起计一个有效期后到期，而不是从购买日期算起。

在无人机上激活许可证​

激活时，无人机需要访问互联网（Wi-Fi、以太网或调制解调器均可）。

  1. 打开 UAVcast-Pro 网页界面。未获得许可证的设备始终会打开应用程序页面。
  2. 在许可证管理器中，将密钥粘贴到输入许可证密钥中。
  3. 选择验证。随后会显示许可证激活成功的提示，侧边栏的其余部分随即解锁。

许可证详情中显示：

字段含义
注册名称许可证所属的商店账户。
许可证状态有效、未激活或已过期。
允许设备数设备名额总数。
剩余设备数空闲的名额数。
激活日期 / 过期日期许可证有效期的开始和结束时间。

已激活设备列出该许可证下的每架无人机，包括其设备名称、主机名和激活日期。当前所在的无人机会标记为当前。选择编辑可以为设备设置一个便于识别的名称。

激活错误​

消息处理方法
已达到最大激活数。请先停用其他设备或升级您的许可证。所有名额均已占用。注销设备或添加名额。
许可证密钥无效检查是否有拼写错误或多余空格。请从商店账户中复制密钥。
此设备已激活该许可证无需操作。此设备已拥有名额（例如在同一张 SD 卡上重装系统后）。
网络错误！无法获取许可证详情…设备无法访问互联网。请检查网络并重试。

许可证检查方式​

  • 无人机每 4 小时向 UAVmatrix 许可证服务器检查一次许可证。
  • 如果无法连接服务器，无人机将保留最后已知的状态。即使完全没有网络连接也可以飞行；离线时不会锁定任何功能。
  • 设备通过 CPU 序列号和启动盘（SD 卡或 SSD）的序列号进行识别。在同一台树莓派上使用同一张卡重装系统，将保持相同的标识和名额。新的 SD 卡或 SSD 将被视为新设备。
  • 无人机上的许可证数据使用该标识加密，因此，将数据库备份恢复到其他硬件上后，需要重新激活许可证。

注销设备​

注销后会立即释放名额。您可以从该许可证已激活的任何无人机上注销该许可证下的任意设备，而不仅限于当前所在的无人机。

  1. 进入应用程序 → 许可证管理器 → 已激活设备。
  2. 找到该设备并选择注销。随后会显示设备注销成功的提示。

如果注销的是当前正在操作的无人机，它将变为未授权状态，网页界面会锁定在应用程序页面，直到重新激活密钥为止。

无法在商店中注销设备

商店会显示已注册的设备，但无法将其移除。请在该许可证下的某台设备上通过 UAVcast-Pro 进行注销。如果该许可证下的所有设备均已丢失或被清除，请将许可证密钥发送至 support@uavmatrix.com。

迁移到新硬件​

在更换树莓派、更换 SD 卡，或将设备从测试台转移到飞机上时，请按以下步骤操作。

  1. 在旧设备上，进入应用程序 → 许可证管理器，并在其旁边选择注销。请在清除存储卡之前执行此操作。
  2. 在新硬件上安装 UAVcast-Pro。参见安装。
  3. 在新设备上激活同一密钥。

如果旧设备已损坏，请从同一许可证下的其他无人机上注销它，或联系支持团队。

续订或升级​

在商店账户中打开该许可证，然后选择升级选项：

  • 延长订阅会增加一个有效期。如果许可证仍在有效期内，新的有效期将加在当前到期日期之后；如果已过期，则从续订日期开始计算。密钥保持不变。
  • 添加设备会为许可证增加名额。已过期的许可证必须先续订。
  • 升级套餐会将许可证切换为名额更多的套餐。

无人机将在下一次检查（4 小时内）时获取新的到期日期和名额。若要立即刷新，请在许可证管理器中选择更改，输入相同的密钥，然后选择验证。

许可证过期时​

许可证过期后将锁定 UAVcast-Pro

许可证过期后，其下的任何无人机都无法继续使用 UAVcast-Pro。它不会继续在已安装的版本上运行。

当许可证服务器报告许可证已过期时，无人机会将自身标记为未授权：网页界面仅会打开应用程序页面，遥测、视频、NTRIP 和动态 DNS 会在各服务下次重启时停止。请在到期日之前续订许可证以避免服务中断，然后在无人机上重新验证密钥（或等待其在 4 小时内的下次检查）以解锁。

许可证与 Fleet Manager​

Fleet Manager 包含在 UAVcast-Pro 许可证中，并使用同一许可证。无人机只能与其许可证所属成员所在的组织配对。如果购买许可证时使用的邮箱与登录 Fleet Manager 时使用的邮箱不同，请在 Fleet Manager 中添加该邮箱（参见 Fleet Manager 中的许可证）。参见将无人机与 Fleet Manager 配对。
