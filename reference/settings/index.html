Settings reference

Every setting in the UAVcast-Pro web interface, grouped by page, with the label exactly as the app shows it and the default on a fresh install. Pages that change settings live apply them straight away unless noted. The feature pages explain each area in depth; this page is for looking things up.

Flight Controller → Connection​

SettingDefaultValues and notes
Link enabledOnTurns the flight controller link on or off.
Link typeUSBUSB (the flight controller's own USB port) or UART / Serial (TELEM port on GPIO pins or a USB-serial cable).
PortAutomaticAutomatic finds the flight controller and follows it if the device number changes. Custom path… takes a device such as /dev/ttyAMA0.
Baud rateAutomaticMust match SERIALx_BAUD on the flight controller. Automatic tries 57600, 115200, 921600, 1500000, 460800, 230400 and 500000. Not used for USB.

Buttons: Auto-detect (scan all ports and speeds and save the result), Connect, Restart link, Stop. Changes apply immediately, without a restart.

Flight Controller → Injectors​

SettingDefaultValues and notes
Input typeHTTP, UDP or Serial. Can't be changed after creation.
MAVLink sysid1Same as the flight controller.
MAVLink compid194User payload.
Name prefixemptyUp to 8 ASCII characters, prepended to every signal name.
Rate limit (Hz per signal)Maximum samples per second per signal name.
Protocol (UDP, Serial)Key=Value (line-delimited) or JSON ({name, value}).
Port / Bind address (UDP)Pick an unused port, for example 14600. 0.0.0.0 = all interfaces, 127.0.0.1 = local only.
Device path / Baud rate (Serial)For example /dev/ttyUSB0; the baud rate must match the sender.

Ground Control Stations​

One card per destination.

NameemptyUp to 50 characters.
Destination IP or HostemptyAn IPv4 address. Required before video or telemetry can be switched on.
Telemetry Port145501–65535.
Video Port56001–65535.
Video Port (Camera 2)empty (= Video Port + 1)Only shown when Dual stream is on.
Enable EndpointOnOff stops everything to this destination: telemetry, video and audio.
Enable VideoOff
Enable TelemetryOff
Read OnlyOffThe ground station receives telemetry but can't change anything on the vehicle. This applies from UAVcast-Pro 6.5.3; on earlier versions, Read Only does not block parameter writes.
