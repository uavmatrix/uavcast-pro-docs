# Fleet

**Fleet** (sidebar **Fleet Management → Fleet**) lists every UAV in the selected organization. It updates live, so you can leave it open on a wall screen next to the [map](../map/index.mdx).

<Screenshot id="fleet-manager/fleet" alt="Fleet page with a grid of UAV cards showing online and offline status, battery and last seen" caption="Fleet page with UAVs (46): ONLINE cards with battery levels, and dimmed OFFLINE cards with Last seen times." />

## UAV cards

The header shows **UAVs (n)**. Each card shows:

- **Name** and a status badge: **ONLINE**, **OFFLINE** or **PAIRING**.
- **Battery** in percent. It turns yellow below 50 % and red below 20 %.
- **Last seen**, as relative time. Offline cards are dimmed.
- **Re-pair required**, when the drone must be paired once more (see [Re-pair a drone](./remove-or-transfer.mdx#re-pair-a-drone)).

A drone counts as offline after **20 seconds** without a message from UAVcast-Pro, which sends a heartbeat every 5 seconds.

Two buttons on each card:

- **Operations** opens the [control panel](./remote-control.mdx): flight modes, arm and disarm, missions.
- **Details** opens the [UAV page](./uav-details.mdx): live telemetry, terminal, logs, system actions, rename and remove.

## Buttons on the page

- **Pair Device** starts the [pairing wizard](../pair-uav.mdx). Owners and Admins only.
- **Refresh** reloads the list.
- **Need more devices?** → **View Plans** opens the UAVmatrix store, where you buy more UAVcast-Pro licenses. See [Licenses](../licenses.mdx).

## Re-pair banner

When one or more drones use an older connection certificate, a banner at the top says **n UAV(s) must be re-paired**. Re-pair each listed drone once; it keeps its name and history. See [Re-pair a drone](./remove-or-transfer.mdx#re-pair-a-drone).

## Tips for large fleets

- **Name drones for the map.** Names appear on map labels and in binding lists. A tail number or role ("Inspection-07") beats the default hostname. Rename from the UAV page.
- **Give each drone its own color.** Fleet Manager assigns colors from a 24-color palette automatically. Set a fixed color in the control panel (**Change map color**) for drones your team should recognize at a glance.
- **Use organizations to separate customers.** Drones belong to exactly one organization. If you operate for several customers who should each see only their drones, give each one an organization.
