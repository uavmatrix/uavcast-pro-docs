# What is UAVcast-Pro?

UAVcast-Pro is software for a companion computer on your drone, usually a Raspberry Pi. It reads MAVLink from an ArduPilot flight controller, streams H.264 video from one or two cameras, and sends both to your ground control station over Wi-Fi, Ethernet or a 4G/LTE modem. You set it up and monitor it from a web interface that runs on the drone.

UAVmatrix Fleet Manager is the cloud dashboard that goes with it. Pair a drone running UAVcast-Pro with Fleet Manager and you can see the whole fleet on one map, open a remote terminal, plan missions and route video and telemetry to ground stations without port forwarding. Fleet Manager is included with every UAVcast-Pro license.

## How the pieces connect

```text
 Flight controller ──USB/UART──►  Companion computer running UAVcast-Pro
 (ArduPilot)                       │  MAVLink router, camera server, modem,
 Camera(s) ──CSI/USB────────────►  │  VPN, NTRIP client, recorder, web UI
                                   │
                                   ├── UDP 14550 (telemetry) ─┐
                                   ├── UDP 5600  (video)    ──┼─► Mission Planner / QGroundControl
                                   │                          │   over LAN, VPN or 4G
                                   └── MQTT/TLS 8883 ─────────┴─► Fleet Manager (optional)
```

- **On the drone**: UAVcast-Pro owns the flight controller's serial port and forwards MAVLink to every ground station you add. The camera server encodes H.264 and sends RTP over UDP to the same ground stations. Nothing listens for incoming telemetry connections unless you add it.
- **Between drone and ground**: on a local network the ground station's own IP is enough. Over 4G the drone has no public address, so you put both ends on a VPN. UAVcast-Pro has built-in [ZeroTier and Tailscale](../uavcast-pro/connectivity/vpn.mdx), and every license includes a UAVnet (ZeroTier) account.
- **In the cloud**: when paired, the drone keeps an outbound, certificate-authenticated MQTT connection to Fleet Manager. See [Pair a drone with Fleet Manager](../uavcast-pro/fleet-pairing.mdx).

## What you need

- A 64-bit Linux companion computer. Raspberry Pi 3, 4, 5 and Zero 2 W are the common choice. See [Hardware requirements](./hardware-requirements.mdx).
- An ArduPilot flight controller. UAVcast-Pro is built and tested for ArduPilot.
- A UAVcast-Pro license from the [UAVmatrix store](https://uavmatrix.com/products/). See [Licensing & activation](./license-activation.mdx).
- For flights beyond Wi-Fi range: a 4G/LTE modem and a data SIM.
