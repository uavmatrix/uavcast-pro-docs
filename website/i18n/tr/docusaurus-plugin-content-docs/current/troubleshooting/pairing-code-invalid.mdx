# Eşleştirme kodu geçersiz veya süresi dolmuş {/* #pairing-code-invalid-or-expired */}

UAVcast-Pro'daki kodu Fleet Manager'ın **Pair Device** sihirbazına girdiniz ve kod reddedildi.

Eşleştirme şu yönde çalışır: **UAVcast-Pro kodu gösterir, siz kodu Fleet Manager'a yazarsınız.** Kod 8 haneli olup 5 dakika geçerlidir.

<Screenshot id="fleet-manager/pair-device--code-expired" alt="Fleet Manager Pair UAV sihirbazı, This pairing code has expired hata bildirimiyle" caption="Fleet Manager kodu reddediyor: hata, Pairing Code adımında bir bildirim olarak görünür; burada This pairing code has expired." />

| Fleet Manager'daki hata | Neden | Çözüm |
|---|---|---|
| **Pairing code must be 8 digits** / **Please enter a valid 8-digit code** | Çok az hane var veya harf girilmiş | [Kontrol 1](#check-1) |
| **Invalid pairing code** | Yazım hatası veya hiç var olmamış bir kod | [Kontrol 1](#check-1) |
| **This pairing code has expired** | 5 dakikadan fazla zaman geçti | [Kontrol 2](#check-2) |
| **This pairing code has already been used** | Kod bir kez kullanılmış | [Kontrol 2](#check-2) |
| **License is not owned by any member of this organization** | Drone'un lisansı organizasyon dışındaki bir hesaba ait | [Kontrol 3](#check-3) |
| **Invalid license key** / **License has expired** / **License has been refunded** | Drone'un lisansı mağazada geçerli değil | [Kontrol 4](#check-4) |
| **This UAV is already paired to an organization** | UAV başka bir organizasyonla eşleştirilmiş | [Kontrol 5](#check-5) |
| **Too many attempts. Please wait a minute and try again.** | Tekrarlanan denemelerden sonra hız sınırı | Bir dakika bekleyin |

## Kontrol 1: Güncel kodu yazın {/* #check-1 */}

<Steps>

1. UAVcast-Pro'da **Fleet Management** bölümüne gidin ve **Connect to Fleet Manager** düğmesine basın.
2. **Pairing Code** altında gösterilen 8 haneyi kopyalayın.
3. Fleet Manager'da **Fleet → Pair Device** bölümüne gidin, organizasyonu seçin ve kodu **Enter Pairing Code** alanına girin.

</Steps>

## Kontrol 2: Yeni bir kod alın {/* #check-2 */}

Kod 5 dakika geçerlidir ve yalnızca bir kez çalışır. **Expires in** değeri sıfıra ulaştığında, yeni bir kod için UAVcast-Pro'da **Connect to Fleet Manager** düğmesine tekrar basın. UAVcast-Pro hiç kod alamazsa *Unable to connect to Fleet Manager. Please check your internet connection.* mesajını gösterir: önce drone'un internet bağlantısını düzeltin.

## Kontrol 3: Lisans organizasyon dışındaki biri tarafından sahiplenilmiş {/* #check-3 */}

Fleet Manager yalnızca, eşleştirdiğiniz organizasyonun bir üyesi tarafından UAVcast-Pro lisansı satın alınmış bir drone'u kabul eder. Eşleşme, lisansın sahibi olan mağaza hesabının e-posta adresi üzerinden yapılır.

Şu yollardan birini uygulayın:

- Lisansı satın alan hesabı organizasyona (**Team**) davet edin, ardından yeniden eşleştirin.
- Lisans sahibinin bir üye olduğu bir organizasyonla eşleştirin.
- Lisans başka bir e-posta adresinizle satın alındıysa, **support@uavmatrix.com** adresinden o adresi Fleet Manager kullanıcınıza lisans e-postası olarak eklemesini isteyin.

Bkz. [Fleet Manager'da lisanslar](../fleet-manager/licenses.mdx).

## Kontrol 4: Lisans geçerli değil {/* #check-4 */}

Drone'da **Uygulama → Lisans Yöneticisi** bölümünü açın ve **License Status** değerini kontrol edin. Süresi dolmuş veya iade edilmiş bir lisans [uavmatrix.com](https://uavmatrix.com) üzerinden yenilenmelidir. UAVcast-Pro'nun kendisinde etkin bir lisans yoksa kod isteyemez (*No valid license found. Please activate your license first.*): bkz. [Lisans etkinleştirilemiyor](./license-activation-failed.mdx).

## Kontrol 5: Başka yerde zaten eşleştirilmiş {/* #check-5 */}

Bir UAV tek bir organizasyona aittir. Taşımak için önce onu eski organizasyondan kaldırın. Aynı organizasyona yeniden eşleştirmeye izin verilir ve UAV'nin geçmişini korur. Bkz. [UAV'yi kaldırma veya aktarma](../fleet-manager/fleet/remove-or-transfer.mdx).

## Hâlâ reddediliyor mu? {/* #still-refused */}

Tam hata metnini, UAV'nin sunucu adını ve organizasyon adını **support@uavmatrix.com** adresine gönderin.
