# Ustawienia, konto i rozliczenia {/* #settings-account-and-billing */}

Otwórz **Settings** z paska bocznego (**Organization → Settings**) lub z menu użytkownika. Ma cztery karty: **Profile**, **Organizations**, **Support** i **History**.

## Profil {/* #profile */}

Imię, e-mail, zdjęcie i hasło należą do twojego konta UAVmatrix. **Zmiany profilu zarządza się w UAVMatrix Store**: w sekcji **Password & Security** wybierz **UAVMatrix Store**, aby zmienić je tam. Fleet Manager automatycznie uwzględnia te zmiany.

<Screenshot id="fleet-manager/settings--profile" alt="Karta Profile w Settings z danymi konta, linkiem do UAVMatrix Store i Danger Zone" caption="Settings → Profile z wierszem Password & Security i Danger Zone." />

## Organizacje {/* #organizations */}

Zmień nazwę organizacji, edytuj jej opis lub (tylko Owner) usuń ją. Zobacz [Konfiguracja organizacji](./set-up-organization.mdx#rename-or-delete-the-organization).

## Wsparcie {/* #support */}

Twoje zgłoszenia do wsparcia wraz ze statusem oraz przełącznik **Support Chat Bubble**, który pokazuje lub ukrywa pływający przycisk wsparcia. Zobacz [Wsparcie i FleetBot](./support.mdx).

## Historia {/* #history */}

Retencja telemetrii, czyszczenie i usuwanie historii poszczególnych dronów, dostępne dla Owner i Admin. Zobacz [Historia lotów](./map/flight-history.mdx#how-long-history-is-kept).

## Rozliczenia {/* #billing */}

Fleet Manager nie ma strony rozliczeń. Licencje, sloty urządzeń, zamówienia i faktury znajdują się w twoim koncie na [uavmatrix.com](https://uavmatrix.com). Zobacz [Licencje i miejsca](./licenses.mdx).

## Usuwanie konta {/* #delete-your-account */}

**Profile → Danger Zone → Delete Account** usuwa twoje konto Fleet Manager. Aby potwierdzić, wpisz `DELETE`.

Usunięte zostaje:

- twój profil i dane konta w Fleet Manager
- wszystkie twoje członkostwa w organizacjach
- wszystkie aktywne sesje
- misje, które utworzyłeś, oraz zaproszenia, które wysłałeś

Wpisy, które dodałeś w **Recent Activity**, pozostają, ale bez twojego imienia.

:::warning Właściciele najpierw muszą przekazać własność
Nie możesz usunąć konta, dopóki jesteś właścicielem organizacji. Fleet Manager wyświetli listę organizacji i poprosi o [przekazanie własności](./team/index.mdx#transfer-ownership) lub najpierw ich usunięcie.
:::

Usunięcie konta Fleet Manager nie usuwa konta w sklepie UAVmatrix ani twoich licencji. Zarządzaj nimi na [uavmatrix.com](https://uavmatrix.com).
