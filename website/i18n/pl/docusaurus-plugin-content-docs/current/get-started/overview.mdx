# Czym jest UAVcast-Pro? {/* #what-is-uavcast-pro */}

UAVcast-Pro to oprogramowanie dla komputera pokładowego na dronie, zwykle Raspberry Pi. Odczytuje MAVLink z dowolnego kontrolera lotu obsługującego MAVLink (ArduPilot lub PX4), przesyła strumień wideo H.264 z jednej lub dwóch kamer i wysyła oba do stacji naziemnej przez Wi-Fi, Ethernet lub modem 4G/LTE. Konfigurujesz go i monitorujesz z interfejsu web działającego na dronie.

UAVmatrix Fleet Manager to chmurowy panel, który jest jego uzupełnieniem. Po sparowaniu drona z UAVcast-Pro z Fleet Manager zobaczysz całą flotę na jednej mapie, otworzysz zdalny terminal, zaplanujesz misje i będziesz kierować wideo oraz telemetrię do stacji naziemnych bez przekierowywania portów. Fleet Manager jest dołączony do każdej licencji UAVcast-Pro.

## Jak łączą się elementy {/* #how-the-pieces-connect */}

```text
 Kontroler lotu ──USB/UART──►  Komputer pokładowy z UAVcast-Pro
 (ArduPilot, PX4)                  │  router MAVLink, serwer kamery, modem,
 Kamera(y) ──CSI/USB────────────►  │  VPN, klient NTRIP, rejestrator, interfejs web
                                   │
                                   ├── UDP 14550 (telemetria) ─┐
                                   ├── UDP 5600  (wideo)    ──┼─► Mission Planner / QGroundControl
                                   │                          │   przez LAN, VPN lub 4G
                                   └── MQTT/TLS 8883 ─────────┴─► Fleet Manager (opcjonalnie)
```

- **Na dronie**: UAVcast-Pro przejmuje port szeregowy kontrolera lotu i przekazuje MAVLink do każdej dodanej stacji naziemnej. Serwer kamery koduje H.264 i wysyła RTP przez UDP do tych samych stacji. Nic nie nasłuchuje przychodzących połączeń telemetrii, dopóki ich nie dodasz.
- **Między dronem a ziemią**: w sieci lokalnej wystarczy adres IP stacji naziemnej. Przez 4G dron nie ma publicznego adresu, więc oba końce łączysz w VPN. [VPN Fleet Manager](../uavcast-pro/connectivity/vpn.mdx), dołączony do każdej licencji, robi to za ciebie; UAVcast-Pro może też dołączyć do twojej własnej sieci Tailscale lub ZeroTier.
- **W chmurze**: po sparowaniu dron utrzymuje wychodzące połączenie MQTT uwierzytelniane certyfikatem z Fleet Manager. Zobacz [Sparuj dron z Fleet Manager](../uavcast-pro/fleet-pairing.mdx).

## Co możesz z tym zrobić {/* #what-you-can-do-with-it */}

| Obszar | Co robi | Strona |
|---|---|---|
| Telemetria | Automatycznie wykrywa port i prędkość bodów kontrolera lotu, kieruje MAVLink do dowolnej liczby stacji naziemnych, opcjonalne miejsca docelowe tylko do odczytu | [Kontroler lotu](../uavcast-pro/flight-controller/index.mdx), [Stacje naziemne](../uavcast-pro/ground-stations/index.mdx) |
| Wideo | Kamery CSI i USB Raspberry Pi, dwie kamery z przełączaniem RC lub podwójnym strumieniem, dźwięk, niestandardowe pipeline'y GStreamer | [Kamera i wideo](../uavcast-pro/camera/index.mdx) |
| Nagrywanie | Nagrywa wideo i telemetrię każdego lotu na dronie, z odtwarzaczem do przeglądu lotu | [Nagrania](../uavcast-pro/camera/recordings.mdx) |
| Mapa lotu | Mapa na żywo, kokpit HUD, uzbrój/rozbrój, RTL i loiter, planer misji, inspektor MAVLink, analiza logów | [Mapa lotu](../uavcast-pro/flight-map/index.mdx) |
| Łączność | Modemy 4G/LTE z automatycznym APN, VPN Fleet Manager lub własna sieć Tailscale albo ZeroTier, dynamiczny DNS, priorytet Wi-Fi a modem | [Łączność](/uavcast-pro/connectivity/) |
| RTK | Klient NTRIP wysyłający poprawki RTCM3 do kontrolera lotu | [NTRIP / RTK](../uavcast-pro/flight-controller/ntrip-rtk.mdx) |
| Dane niestandardowe | Przenosi czujniki i skrypty do MAVLink i wyświetla je na wykresach | [Wstrzykiwacze](../uavcast-pro/flight-controller/injectors.mdx), [Strumienie danych](../uavcast-pro/data-streams.mdx) |

## Czego potrzebujesz {/* #what-you-need */}

- 64-bitowego komputera pokładowego z Linuksem (arm64 lub amd64). Najczęstszym wyborem są Raspberry Pi 3, 4, 5 i Zero 2 W; działają też mini PC z x86, a NVIDIA Jetson, Orange Pi i inne płytki arm64 pojawią się od {/* PENDING-RELEASE: non-pi-arm64 version */}następnego wydania UAVcast-Pro. Zobacz [Wymagania sprzętowe](./hardware-requirements.mdx).
- Kontrolera lotu obsługującego MAVLink: ArduPilot lub PX4. Przyciski trybów lotu używają nazw trybów ArduPilot.
- Licencji UAVcast-Pro ze [sklepu UAVmatrix](https://uavmatrix.com/products/). Zobacz [Licencjonowanie i aktywacja](./license-activation.mdx).
- Do lotów poza zasięgiem Wi-Fi: modemu 4G/LTE i karty SIM z transmisją danych.
