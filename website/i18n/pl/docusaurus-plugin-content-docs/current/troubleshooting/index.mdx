# Rozwiązywanie problemów {/* #troubleshooting */}

Zacznij od objawu. Każda poniższa strona wymienia prawdopodobne przyczyny w kolejności, w jakiej występują w terenie, wraz z numerowanymi sprawdzeniami, które używają dokładnych etykiet z interfejsów UAVcast-Pro i Fleet Manager.

:::tip Najpierw sprawdź panel
Otwórz **Panel Główny** w UAVcast-Pro. Karta statusu podsumowuje drona w jednej linii (**All systems normal** albo liczba problemów i ostrzeżeń) i ma wiersz dla każdego z: **Flight controller**, **Ground station**, **Cellular**, **VPN**, **RTK corrections**, **Video** i **Power supply**. Pierwszy czerwony wiersz to zwykle miejsce, od którego warto zacząć.
:::

<Screenshot id="uavcast-pro/dashboard" alt="Panel Główny UAVcast-Pro z kartą statusu pokazującą 2 problemy: GPS no fix i VPN not connected" caption="Panel Główny → karta statusu. Wiersze z problemem stają się czerwone i są liczone w odznace problemów, tutaj GPS (no fix) i VPN (not connected)." />

## Dopasuj swój objaw {/* #match-your-symptom */}

| Co widzisz | Prawdopodobna przyczyna | Przejdź do |
|---|---|---|
| Telemetria działa, ale obszar wideo w QGroundControl lub Mission Planner jest czarny | **Włącz Wideo** jest wyłączone dla tej stacji naziemnej, zły IP albo zapora | [Brak wideo w stacji naziemnej](./no-video-in-gcs.mdx) |
| Wideo się zacina, ma szare zakłócenia lub opóźnienie kilku sekund | Bitrate za wysoki dla łącza albo klatki kluczowe zbyt daleko od siebie | [Poszarpane lub opóźnione wideo](./choppy-or-delayed-video.mdx) |
| Strona Kontroler Lotu pokazuje **No heartbeat**, **Waiting for device** lub **Detecting baud rate** | Kabel, okablowanie, port lub prędkość bodów | [Brak heartbeat MAVLink](./no-mavlink-heartbeat.mdx) |
| UAVcast-Pro pokazuje kontroler lotu jako **Połączono**, a stacja naziemna czeka na połączenie | Telemetria nie jest wysyłana do stacji naziemnej albo stacja nie nasłuchuje | [Brak telemetrii w stacji naziemnej](./no-telemetry-in-gcs.mdx) |
| **No cameras available** w **Wybierz Kamerę** | Brak stosu kamery CSI, uszkodzona taśma albo kamera USB nie jest widziana | [Nie wykryto kamery](./camera-not-detected.mdx) |
| **Invalid license key**, **Maximum activations reached** lub **License activation failed** | Zły klucz, brak wolnego miejsca na urządzenie albo brak internetu | [Licencja nie aktywuje się](./license-activation-failed.mdx) |
| Modem pokazuje sygnał i operatora, ale nic się nie ładuje | APN, priorytet sieci lub dane na karcie SIM | [Modem połączony, brak internetu](./modem-no-internet.mdx) |
| Przeglądarka nie może otworzyć `http://<device-ip>/` po instalacji | Zły adres, usługa nie działa albo port się zmienił | [Interfejs webowy się nie otwiera](./web-interface-wont-open.mdx) |
| Instalator kończy się błędem | System 32-bitowy, brak internetu albo mało miejsca na dysku | [Instalacja się nie udaje](./installation-fails.mdx) |
| ZeroTier lub Tailscale pokazuje połączenie, ale nie możesz pingować ani otworzyć drona | Członek nieautoryzowany, zła sieć albo stacja naziemna nie jest w VPN | [VPN połączony, ale brak dostępu do drona](./vpn-cant-reach-drone.mdx) |
| Status NTRIP nie pokazuje **Strumieniowanie korekcji** albo poprawka nigdy nie dociera do **RTK Fixed** | Ustawienia castera, GGA albo odbiornik bez obsługi RTK | [Korekcje RTK nie docierają](./rtk-corrections-not-arriving.mdx) |
| **Voltage too low - use a stronger power supply** lub **Slowed down (heat or power)** | Słabe zasilanie lub kabel, przegrzewanie | [Podnapięcie i throttling](./undervoltage-and-throttling.mdx) |
| Dron jest **Offline** w Fleet Manager | Dron nie ma internetu, zablokowany port MQTT albo wymagane ponowne parowanie | [Dron offline w Fleet Manager](./drone-offline-fleet-manager.mdx) |
| **Invalid pairing code**, **This pairing code has expired** lub **License is not owned by any member of this organization** | Kod wpisany źle lub za stary, albo licencja należy do osoby spoza organizacji | [Kod parowania nieprawidłowy lub wygasły](./pairing-code-invalid.mdx) |

## Nadal masz problem? {/* #still-stuck */}

1. [Zbierz pliki logów](./collect-logs.mdx). Pobranie zawiera migawkę `diagnostics.txt` z ustawieniami i sprzętem, więc support nie musi o nie pytać.
2. Wyślij je na **support@uavmatrix.com** wraz z wersją UAVcast-Pro, używanym sprzętem i tym, co już sprawdziłeś. Możesz też zapytać na [UAVmatrix Discord](https://discord.gg/xwqMTXh).

Krótkie odpowiedzi na częste pytania znajdziesz w [FAQ](./faq.mdx).
