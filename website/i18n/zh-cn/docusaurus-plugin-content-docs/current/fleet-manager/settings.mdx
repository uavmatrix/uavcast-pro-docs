# 设置、账户与账单 {/* #settings-account-and-billing */}

从侧边栏（**Organization → Settings**）或用户菜单打开 **Settings**。它包含四个标签页：**Profile**、**Organizations**、**Support** 和 **History**。

## 个人资料 {/* #profile */}

您的姓名、电子邮件、头像和密码属于您的 UAVmatrix 账户。**个人资料的更改通过 UAVMatrix Store 管理**：在 **Password & Security** 下选择 **UAVMatrix Store**，即可在那里进行更改。Fleet Manager 会自动获取这些更改。

## 组织 {/* #organizations */}

重命名组织、编辑其描述，或（仅 Owner）删除组织。请参阅[设置组织](./set-up-organization.mdx#rename-or-delete-the-organization)。

## 支持 {/* #support */}

您的支持工单及其状态，以及用于显示或隐藏悬浮支持按钮的 **Support Chat Bubble** 开关。请参阅[支持与 FleetBot](./support.mdx)。

## 历史记录 {/* #history */}

遥测数据保留、清理以及单台无人机历史记录的删除，仅 Owner 和 Admin 可以操作。请参阅[飞行历史](./map/flight-history.mdx#how-long-history-is-kept)。

## 账单 {/* #billing */}

Fleet Manager 没有账单页面。许可证、设备席位、订单和发票都位于您在 [uavmatrix.com](https://uavmatrix.com) 的账户中。请参阅[许可证与席位](./licenses.mdx)。

## 删除账户 {/* #delete-your-account */}

**Profile → Danger Zone → Delete Account** 会删除您的 Fleet Manager 账户。输入 `DELETE` 进行确认。

此操作将删除：

- 您在 Fleet Manager 中的个人资料和账户信息
- 您的所有组织成员身份
- 您所有的活动会话
- 您创建的任务和发出的邀请

您在 **Recent Activity** 中的记录会保留，但不再显示您的姓名。

:::warning Owner 必须先转交所有权
当您仍拥有某个组织时，无法删除您的账户。Fleet Manager 会列出这些组织，并要求您先[转让所有权](./team/index.mdx#transfer-ownership)或删除这些组织。
:::

删除 Fleet Manager 账户不会删除您的 UAVmatrix 商店账户或许可证。请在 [uavmatrix.com](https://uavmatrix.com) 管理这些内容。
