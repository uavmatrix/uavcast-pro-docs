# Mission Planner 标签页 {/* #mission-planner-tab */}

Mission Planner 标签页让您可以在浏览器中规划简单的航点任务，并通过 UAVcast-Pro 将其上传到飞行控制器，只要能够访问 Web 界面，即可在任何地方操作。任务以与 Mission Planner 和 QGroundControl 相同的 `.waypoints` 格式（QGC WPL 110）保存，因此可以在不同工具之间迁移。打开 **飞行地图 → 任务规划器**。

<Screenshot id="uavcast-pro/flight-map--mission-planner" alt="Mission Planner 标签页，包含卫星地图、空白的航点表格，以及保存、加载、上传、读取和清除按钮" caption="飞行地图 → 任务规划器，尚未添加任何航点。点击地图即可添加一个。" />

## 规划任务 {/* #plan-a-mission */}

<Steps>

1. 点击地图上第一个航点应处的位置。首次使用时，**设置默认值** 会要求输入 **默认高度（米）**、**航点半径（米）** 和 **高度坐标系**。选择 **继续**。
2. 继续点击以添加航点。拖动标记可移动航点。
3. 在表格中调整每个航点：**高度 (m)**、**坐标系** 和 **半径 (m)**。在 **操作** 列中可删除航点。
4. 在 **航点** 和 **距离** 中查看整条航线的总计。

</Steps>

| 默认值 | 数值 | 选项 |
|---|---|---|
| **默认高度（米）** | `100` | 任意 |
| **航点半径（米）** | `30` | 任意 |
| **高度坐标系** | **相对** | **相对**（相对于起飞点上方）、**绝对**（相对于平均海平面上方）、**地形**（相对于地面上方，需要飞行控制器具有地形数据） |

在表格中，坐标系缩写为 **Rel**、**Abs** 和 **Ter**。航点以 `MAV_CMD_NAV_WAYPOINT` 发送。

## 上传到飞行控制器 {/* #upload-to-the-flight-controller */}

<Steps>

1. 在 **飞行控制器** 下，选择 **上传**。
2. 确认 **上传任务**。对话框会提示：这将替换飞行控制器上的任务。
3. 将显示：*任务已上传到飞行控制器*。

</Steps>

- **读取** 会将飞行控制器上的任务下载到规划器中。
- **清除** 会从规划器中删除航点。

要执行任务，请使用飞行地图 **操作** 标签页中的 **启动**，或在遥控器或地面站中切换到 AUTO 模式。

## 保存与加载文件 {/* #save-and-load-files */}

在 **文件** 下：

- **保存** 会将任务下载为 `mission.waypoints`。
- **加载** 会打开 QGC WPL 格式的 `.waypoints` 或 `.txt` 文件，例如从 Mission Planner 保存的文件。

## 限制 {/* #limits */}

该规划器仅支持普通航点。**加载** 会保留每行的位置、高度、坐标系和半径，但会将每一行都转换为普通航点：起飞、降落、悬停以及 DO 命令（摄像头触发、舵机）都不会被保留，没有位置的命令会变为位于 0, 0 的航点。对于起飞和降落命令、DO 命令、测绘网格、电子围栏和集结点，请直接在 Mission Planner 或 QGroundControl 中规划并上传。
