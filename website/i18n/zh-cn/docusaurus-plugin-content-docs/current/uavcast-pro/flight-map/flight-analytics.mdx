# 飞行分析 {/* #flight-analytics */}

飞行分析可以绘制随时间变化的 MAVLink 数值，数据来源可以是飞行控制器的实时数据，也可以是已录制的 `.tlog` 文件。您可以用它检查振动、电池压降、高度保持或信号数值，而无需将日志复制到 PC。请打开 **飞行地图 → 飞行分析**。

<Screenshot id="uavcast-pro/flight-map--flight-analytics" alt="飞行分析标签页，显示未加载日志文件、打开日志文件按钮、实时开关以及参数面板" caption="加载日志之前的飞行分析。**打开日志文件** 用于加载 .tlog 文件。" />

## 绘制实时遥测 {/* #plot-live-telemetry */}

<Steps>

1. 选择 **实时**。参数列表会随消息到达而填充。如果一直显示 *等待 MAVLink 数据*，请先连接飞行控制器。
2. 在 **参数** 中搜索并勾选要绘制的数值。最多可同时绘制 **10** 个。
3. 开启 **累积数据** 以保留每个数据点（*正在存储所有数据点*）。关闭时，图表会保留滚动窗口（*最近 … 个点*）。

</Steps>

## 分析已录制的日志 {/* #analyze-a-recorded-log */}

<Steps>

1. 选择 **打开日志文件**。
2. 在 **选择日志文件** 中，选择已录制的 `.tlog`。遥测日志来自[录制](../camera/recordings.mdx)（默认每次解锁飞行生成一个）。
3. 勾选要绘制的参数。文件的**持续时间**和**参数**数量显示在顶部。

</Steps>

**全部清除** 会删除所有已绘制的参数。

## 日志的来源 {/* #where-the-logs-come-from */}

遥测数据会根据 **摄像头 → 录制 → 设置** 中的 **录制遥测** 在无人机上记录：**解锁时**（默认）、**连接时始终记录** 或 **关闭**。同样的 `.tlog` 文件也可以在 Mission Planner、MAVExplorer 和 UAV Log Viewer 中打开。

飞行地图的 **录制** 侧边标签页会列出相同的遥测日志，并显示 **消息**、**最大高度** 和 **距离**，还可以 **下载 .tlog**、**删除** 或 **播放** 日志。播放会将录制的遥测数据流式传输到地图上，就像无人机正在飞行一样。
