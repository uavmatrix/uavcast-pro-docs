# 网络 {/* #networks */}

网络页面会显示无人机上的每个网络接口（以太网、Wi-Fi、调制解调器、VPN），以及哪一个是默认路由。您也可以在此选择：当 Wi-Fi 和蜂窝调制解调器都已连接时，优先使用哪一个。在侧边栏中打开 **网络**。

## 选择网络优先级 {/* #choose-the-network-priority */}

当 Wi-Fi 和调制解调器都已连接时，Linux 会通过路由度量值最低的接口发送流量。**网络优先级** 会为您设置这些度量值：

| 选项 | 适用场景 | 效果 |
|---|---|---|
| **WiFi优先（室内模式）** | 在工作台或家中，为节省移动数据流量。 | Wi-Fi 度量值 100，调制解调器度量值 600。 |
| **调制解调器优先（户外模式）** | 每次通过蜂窝网络飞行之前。 | 调制解调器度量值 100，Wi-Fi 度量值 600。 |
| **自动（系统默认）** | 您不希望 UAVcast-Pro 更改任何设置。 | NetworkManager 自身的度量值。 |

:::warning 起飞前切换到调制解调器优先
如果无人机在 Wi-Fi 优先的状态下起飞，链路会一直保持在 Wi-Fi 上，直到 Wi-Fi 信号丢失，然后才不得不在空中切换到调制解调器。这会导致遥测和视频中断。请在地面上选择 **调制解调器优先（户外模式）**。
:::

此更改会直接应用于活动连接，无需重启（*正在应用更改...*）。

:::note 哪些连接会被更改
Wi-Fi 度量值会设置在名为 `preconfigured` 的 NetworkManager 连接上，该名称是 Raspberry Pi Imager 在烧录镜像时为您输入的 Wi-Fi 所指定的。以其他方式设置的 Wi-Fi 会保留其自身的度量值，以太网则永远不会被更改。
:::

## 接口信息 {/* #interface-information */}

摘要卡片显示 **活动接口**、**默认网关**（以及其所经过的接口）和 **接口总数**。**网络接口** 列出每个接口的 **名称**、**IP 地址**、**网关**、**状态**（**活动**、**非活动**、**VPN**）、**速度**、**类型**，以及哪一个是 **默认**。

常见的接口名称：

| 名称 | 说明 |
|---|---|
| `eth0`、`end0` | 有线以太网 |
| `wlan0` | Wi-Fi |
| `ppp0`、`wwan0` | 传统调制解调器 |
| `usb0`、`eth1` | HiLink 调制解调器 |
| `zt…` | ZeroTier |
| `tailscale0` | Tailscale |
