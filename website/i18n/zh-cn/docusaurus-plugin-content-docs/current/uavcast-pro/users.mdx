# 用户与访问 {/* #users--access */}

全新安装的 UAVcast-Pro 没有用户，也没有登录界面：任何能打开 Web 界面的人都拥有完全的管理员权限。添加一个管理员用户即可启用登录功能。之后，可以为观察者、客户或载荷操作员添加**只读**用户，让他们查看全部内容但不做任何更改。打开 **管理 → 用户**。

<Screenshot id="uavcast-pro/users" alt="用户页面，打开了添加新用户对话框，包含用户名、密码、确认密码和角色字段" caption="管理 → 用户，并打开添加新用户对话框。" />

## 启用登录 {/* #turn-on-the-login */}

<Steps>

1. 前往**用户**，然后选择**添加用户**。
2. 输入**用户名**（至少 3 个字符）、**密码**（至少 6 个字符）和**确认密码**。
3. 选择**创建用户**。第一个用户始终是**管理员**（*第一个用户必须是管理员*）。

</Steps>

此后，每位访问者都会看到登录页面。在同一浏览器上登录的有效期为 7 天，或直到在侧边栏底部的用户菜单中选择**退出登录**为止。

:::warning Web 界面使用明文 HTTP
登录信息和设置以未加密形式传输。在自有局域网内或 [VPN](./connectivity/vpn.mdx) 中使用没有问题，但切勿把 Web 界面的端口转发到互联网。
:::

## 角色 {/* #roles */}

| 功能 | **管理员** | **只读** |
|---|---|---|
| 查看仪表盘、数据流、飞行控制器、飞行地图、地面控制站和摄像头页面 | 是 | 是 |
| 观看实时视频和遥测，查看仪表盘和录制 | 是 | 是 |
| 更改任何设置 | 是 | 否 |
| 解锁、上锁、更改模式、启动或清除任务 | 是 | 否 |
| 启动或停止录制 | 是 | 否 |
| 打开调制解调器、虚拟专用网络、动态 DNS、网络、Fleet Management、用户和应用程序 | 是 | 否（隐藏） |

必须先创建管理员，才能添加只读用户（*请先创建管理员用户，然后再添加只读用户*）。

Web 只读用户与地面控制站目标地址上的**只读**开关不同，后者用于阻止来自地面站程序的命令。请参阅[地面控制站](./ground-stations/index.mdx)。

## 更改密码 {/* #change-a-password */}

选择**更改密码**，输入**当前密码**，然后两次输入**新密码**，并选择**更新密码**。密码以 bcrypt 哈希形式存储。

## 删除用户 {/* #delete-a-user */}

在该用户所在行选择**删除**，然后确认。

- 在仍有其他用户时，无法删除自己的账户。
- 删除**最后一个**用户会再次关闭登录功能：*删除后，在创建新用户之前，应用程序将无需身份验证即可访问。*

## 忘记管理员密码 {/* #forgot-the-admin-password */}

没有重置链接：无人机无法发送电子邮件，密码找回也不支持自助操作。

- 如果其他管理员仍能登录，可以在**用户**下删除该用户，然后重新创建。
- 如果没有任何具有管理员角色的用户能够登录，请联系支持人员：**support@uavmatrix.com**。请提供许可证密钥（或购买时所用的电子邮箱）、设备的主机名或名称（可在**应用程序 → 许可证管理器 → 已激活设备**下查看）、UAVcast-Pro 版本，以及是否可以通过 SSH 访问该设备。
