# 应用程序设置、日志与备份 {/* #application-settings-logs-and-backups */}

**应用程序**页面包含 UAVcast-Pro 本身的所有内容：许可证、更新、界面设置、日志下载和设置数据库。该页面仅对管理员可见，并且是设备获得许可之前唯一可用的页面。打开 **管理 → 应用程序**。

## 设置 {/* #settings */}

| 设置 | 默认值 | 可选值 | 说明 |
|---|---|---|---|
| **导览** | | | 重新开始界面的引导导览。 |
| **深色主题** | 启用 | 启用、禁用 | 按浏览器保存。顶部栏中的主题切换按钮也可以设置此项。 |
| **服务器端口** | `80` | 1–65535 | Web 界面的端口。详见下文。 |
| **语言** | 浏览器语言，否则为 English | English、Español、简体中文、繁體中文、Italiano、Nederlands、Polski、Português、Русский、Türkçe | 也可在侧边栏底部的用户菜单中设置。 |

### 更改 Web 界面端口 {/* #change-the-web-interface-port */}

<Steps>

1. 在 **服务器端口** 中输入新端口。
2. 选择 **提交并重启服务器**。对话框会显示 **新URL**，例如 `http://192.168.1.50:8080`。
3. 等待几秒钟，然后打开新 URL。

</Steps>

旧地址的书签和链接将失效。更改端口后会显示警告：*服务器端口已从默认端口 80 更改。* 从 UAVcast-Pro 6.5.3 起，端口设置会在更新时保留；更早的版本会将其重置为 80。

## 日志 {/* #logging */}

UAVcast-Pro 会分别记录每项服务的日志。出现问题时，请下载日志并发送给支持团队。

<Steps>

1. 启用 **调试模式** 以获取更多详细信息。重现问题。
2. 在 **选择要下载的日志** 中，保留 **所有日志**，或选择某一项服务。
3. 在 **选择时间范围** 中，选择一个覆盖问题发生时段的时间窗口（从 **最近 10 分钟** 到 **所有时间**）。
4. 选择 **下载**。您将获得一个 zip 文件。
5. 通过电子邮件将其发送至 support@uavmatrix.com，并附上简要的问题描述。之后请再次禁用 **调试模式**。

</Steps>

下载的内容包含一个 `diagnostics.txt` 快照（设置、串口、电源和 USB 事件），有助于加快支持响应速度。

| 日志 | 涵盖内容 |
|---|---|
| **Mavlink Manager**、**Mavlink Publisher** | 飞行控制器链路，以及发往地面站的路由 |
| **Camera Server**、**Camera Detector** | 视频管道，摄像头检测 |
| **Modem Manager**、**Modem Detector** | 调制解调器连接，APN 尝试 |
| **VPN Manager** | ZeroTier 和 Tailscale |
| **NTRIP Client** | RTK 校正数据 |
| **DNS Manager** | 动态DNS 更新 |
| **License Manager** | 激活，以及每 4 小时一次的许可证检查 |
| **Application Updater**、**Application Installer** | 更新与安装 |
| **Backend API Server** | 内部 API |

**清除所有日志** 会删除所有日志文件。此操作无法撤销。如果希望在重现问题前获得干净的日志，请先执行此操作。在无人机上，日志位于 `/opt/uavcast-pro/logs`。

每个页面还有一个 **操作日志** 控制台，显示该页面对应服务的实时日志。

## 数据库 {/* #database */}

所有设置（地面控制站、飞行控制器、摄像头、调制解调器、VPN、NTRIP、用户、仪表盘、注入器和许可证数据）都保存在同一个 SQLite 数据库中，位于 `/opt/uavcast-pro/uavcast.db`。

| 操作 | 作用 |
|---|---|
| **备份数据库** | 将数据库下载为 `uavcast_backup.db`。 |
| **恢复数据库** | 上传 `.db` 备份文件，并替换当前设置（包括用户）。 |
| **重置数据库** | 将地面控制站、飞行控制器、摄像头、VPN 和动态DNS 设置重置为默认值。用户、许可证、调制解调器、NTRIP、录制设置、仪表盘、注入器以及 Fleet Manager 配对会被保留。此操作无法撤销。 |

在更改前使用备份保存一份已知可用的配置，或以相同方式设置第二架无人机。恢复后请重启，使所有服务以恢复的设置启动。

:::note 在不同硬件上恢复
数据库中的许可证数据与其来源设备绑定。在另一台树莓派或 SD 卡上恢复备份后，请在新设备上激活许可证。恢复操作还会导入备份中的用户和密码。
:::
