# Поддерживаемое оборудование {/* #supported-hardware */}

UAVcast-Pro v6 работает на любом 64-битном Linux-компьютере с Raspberry Pi OS, Debian или Ubuntu, на архитектуре **arm64** или **amd64** (платы arm64, кроме Raspberry Pi, поддерживаются начиная с UAVcast-Pro 6.5.3). В таблицах ниже перечислено то, что обнаруживается и протестировано. Сведения о блоках питания, проводке и выборе покупки см. в разделе [Требования к оборудованию](../get-started/hardware-requirements.mdx).

## Бортовые компаньоны {/* #companion-computers */}

| Плата | Архитектура | Последовательный порт для TELEM | Примечания |
|---|---|---|---|
| Raspberry Pi 5 | arm64 | GPIO UART (`uart0`) | Лучшая производительность видео. Для непрерывного кодирования нужно активное охлаждение. |
| Raspberry Pi 4 | arm64 | GPIO UART | Рекомендуемый универсальный выбор. |
| Raspberry Pi 3 | arm64 | GPIO UART | Подходит для телеметрии и одной камеры при умеренных настройках. |
| Raspberry Pi Zero 2 W | arm64 | GPIO UART | Работает, но установка медленная, а возможности для видео ограничены. Одна камера, низкое разрешение. |
| Raspberry Pi Compute Module | arm64 | Зависит от платы-носителя | Поддержка установщика исправлена в v6.3.1. |
| NVIDIA Jetson (Nano, Orin Nano, Xavier NX, AGX, TX2) | arm64 | `ttyTHS*` на 40-контактном разъёме | USB-камеры. CSI-камеры Jetson сервер камер не обрабатывает; для них нужен самостоятельно написанный **Пользовательский Пайплайн**. |
| Orange Pi (Zero, Zero 2, 3, 4, 5, Plus) | arm64 | `ttyS*`, зависит от модели | USB-камеры. UART может потребовать включения в дереве устройств. |
| Banana Pi и другие платы arm64 | arm64 | Зависит от модели | USB-камеры. |
| Мини-ПК x86, Intel NUC, ноутбук | amd64 | USB-последовательный адаптер | USB-камеры. |

:::note Платы arm64, отличные от Raspberry Pi
Jetson, Orange Pi, Banana Pi и другие платы arm64, которые не являются Raspberry Pi, требуют UAVcast-Pro 6.5.3 или новее. Старые установщики на них останавливаются с сообщением *Device is not a Raspberry Pi*.
:::

**Только для Raspberry Pi:** CSI-камеры (rpicam/libcamera) работают только на Raspberry Pi. На Pi установщик включает UART, отключает последовательную консоль и на Pi 3/4/Zero 2 W отключает Bluetooth, чтобы полный UART был свободен.

## Операционные системы {/* #operating-systems */}

| ОС | Статус |
|---|---|
| Raspberry Pi OS (64-bit) | Рекомендуется на Raspberry Pi. Нужна для CSI-камер. |
| Debian (64-bit) | Поддерживается. |
| Ubuntu (64-bit), включая Ubuntu for Raspberry Pi | Поддерживается. CSI-камеры на Pi в Ubuntu не работают, так как стек камер Raspberry Pi в нём не упакован; USB-камеры работают. |
| Любая 32-битная ОС | **Не поддерживается.** Установщик останавливается с сообщением *No installation candidate*. |

## Полётные контроллеры {/* #flight-controllers */}

UAVcast-Pro v6 работает с любым полётным контроллером MAVLink через USB или порт TELEM: ArduPilot (Copter, Plane, Rover, VTOL и другие типы аппаратов) и PX4 на платах семейств Pixhawk и Cube, а также Matek, Holybro, CUAV и других. Названия полётных режимов и кнопки режимов на карте полёта и в Fleet Manager соответствуют ArduPilot; при использовании PX4 меняйте режимы из вашей наземной станции.

## Камеры {/* #cameras */}

| Тип | Примеры | Примечания |
|---|---|---|
| Raspberry Pi CSI | Camera Module 2 и 3, HQ Camera, другие сенсоры libcamera (imx219, imx708 …) | Raspberry Pi OS или Debian. Две CSI-камеры на платах с двумя разъёмами (Pi 5, Compute Module). |
| USB (UVC) | Logitech C920, C615 и большинство UVC-веб-камер | Любая ОС. |
| Другие источники | IP-камеры, захват HDMI | Через **Пользовательский Пайплайн**. |

До двух камер, которые переключаются или передают поток одновременно. Звук — с USB-микрофона или со встроенного микрофона камеры.

## LTE / 4G модемы {/* #lte--4g-modems */}

| Тип | Принцип работы | Примеры |
|---|---|---|
| **HiLink** | Модем — небольшой маршрутизатор, который отображается как сетевой адаптер (драйверы `cdc_ether`, `huawei_cdc_ncm`, `rndis_host`) | Huawei E3372h, E8372h |
| **Традиционный (PPP)** | Управляется ModemManager; UAVcast-Pro подключает его, выбирает APN и переподключает | Huawei E3372s, модули Quectel и Sierra Wireless на USB-носителях |

Традиционные модемы должны поддерживаться ModemManager: см. [список устройств, поддерживаемых ModemManager](https://www.freedesktop.org/wiki/Software/ModemManager/SupportedDevices/). Выбирайте модель, диапазоны которой совпадают с диапазонами вашего оператора.

## Приёмники RTK GPS {/* #rtk-gps-receivers */}

Поправки NTRIP требуют приёмника с поддержкой RTK (фазовые измерения несущей) на полётном контроллере, например модули на основе u-blox ZED-F9P, CubePilot Here3+ или Septentrio Mosaic. Стандартные навигационные модули, такие как M8N, M9N или M10, не могут использовать поправки RTK.
