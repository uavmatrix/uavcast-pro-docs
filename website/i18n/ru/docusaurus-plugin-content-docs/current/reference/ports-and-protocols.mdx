# Порты и протоколы {/* #ports-and-protocols */}

Используйте эту страницу, чтобы настроить брандмауэры на наземной станции, в сети дрона и в корпоративных сетях. Показаны значения по умолчанию; там, где порт можно изменить, указана соответствующая настройка.

## Наземная станция: входящий трафик {/* #ground-station-incoming-traffic */}

UAVcast-Pro **отправляет** телеметрию и видео на каждую наземную станцию. Наземной станции нужно только принимать входящий UDP; на дроне для этого ничего слушать не нужно.

| Порт (по умолчанию) | Протокол | Назначение | Настройка |
|---|---|---|---|
| **14550** | UDP | Телеметрия MAVLink, в обе стороны, как только GCS отвечает | **Наземные станции → Порт телеметрии** |
| **5600** | UDP | Видео: H.264 в RTP, тип полезной нагрузки 96 | **Порт видео** |
| **Порт видео + 1** (5601) | UDP | Видео камеры 2, когда включено **Два потока** | **Порт видео (Камера 2)** (пусто = Порт видео + 1) |
| **Порт видео + 2** (5602) | UDP | Аудио: Opus в RTP, тип полезной нагрузки 97, когда включено **Передавать звук на наземные станции** | Следует за **Порт видео** |

:::note Порт TCP 5760 закрыт
Начиная с v6.5.0 маршрутизатор телеметрии не слушает TCP 5760. Наземные станции подключаются по UDP к пунктам назначения, которые вы добавили.
:::

**С привязками потоков Fleet Manager** первый дрон, привязанный к наземной станции, использует 5600/14550, а каждый следующий дрон получает собственный блок портов: порт видео с местом для камеры 2 и аудио после него, а также порт телеметрии. Смотрите порты в каждой привязке. {/* PENDING-RELEASE: port-blocks */}

## Дрон: службы, к которым вы подключаетесь {/* #drone-services-you-connect-to */}

| Порт | Протокол | Назначение | Примечания |
|---|---|---|---|
| **80** | TCP (HTTP) | Веб-интерфейс | Меняется в **Приложение → Настройки → Порт сервера** (80 или выше). |
| **8889** | TCP (HTTP) | Предварительный просмотр в браузере (WebRTC) | Используется в **Камера → Предварительный просмотр** и в окнах видео на карте полёта. |
| 8189 | UDP | Медиа WebRTC для предварительного просмотра | Значение медиасервера по умолчанию. |
| **9996** | TCP (HTTP) | Воспроизведение записей | Используется библиотекой записей и плеером разбора полёта. |
| **8554** | TCP (RTSP) | Копия потока камеры по RTSP (`/camera`, `/camera2`) | Доступна, пока включены предварительный просмотр или запись. |
| 8888 | TCP (HTTP) | Копия потока камеры по HLS | Веб-интерфейсом не используется. |
| HTTP-инжектор | TCP (HTTP) | `http://<drone>/api/inject/<token>` | Обслуживается на порту веб-интерфейса. См. [Инжекторы](../uavcast-pro/flight-controller/injectors.mdx). |
| UDP-инжектор | UDP | На ваш выбор (14600 — безопасное значение по умолчанию) | Задаётся для каждого инжектора в **Полётный контроллер → Инжекторы**. |

Через VPN эти порты должны быть доступны по VPN-адресу дрона. На стороне сотовой связи проброс портов не требуется.

## Дрон: исходящий трафик {/* #drone-outgoing-traffic */}

Дрон сам открывает эти соединения. Сети, которые пропускают только веб-трафик, будут блокировать некоторые из них.

| Назначение | Порт | Протокол | Что передаётся |
|---|---|---|---|
| Наземные станции | 14550, 5600 (+1, +2) | UDP | Телеметрия, видео, аудио |
| `uavmatrix.com` | 443 | HTTPS | Активация лицензии и периодические проверки |
| `install.uavmatrix.com` | 443 | HTTPS | Установщик и обновления |
| `fleet-manager.uavmatrix.com` | 443 | HTTPS | Сопряжение с Fleet Manager |
| Брокер Fleet Manager | **8883** | MQTT через TLS (клиентские сертификаты) | Статус, телеметрия и команды Fleet Manager |
| `vpn-connect.uavmatrix.com` | 443 | HTTPS | Сервер входа в VPN Fleet Manager |
| Ваш кастер NTRIP | 2101 (или как задано) | TCP, опционально TLS | Поправки RTCM |
| ZeroTier / Tailscale | ZeroTier 9993, Tailscale 41641 (и 443 как запасной) | UDP | Туннели VPN |
| Ваш провайдер DNS | 443 | HTTPS | Обновления динамического DNS |

## Внутри дрона (только локально) {/* #inside-the-drone-local-only */}

Эти порты используются между собственными службами UAVcast-Pro и не требуют правил брандмауэра:

| Порт | Назначение |
|---|---|
| 6379 | Redis, внутренняя шина сообщений |
| 12550, 12551 | Маршрутизатор телеметрии к приложению UAVcast-Pro и к клиенту NTRIP |
| 8090 | HTTP-слушатель инжектора (доступен через `/api/inject/…` на порту 80) |
| 9997 | API медиасервера |
| 5000 | API фоновой службы UAVcast-Pro, используется веб-интерфейсом |

## Правила брандмауэра для наземной станции {/* #firewall-rules-for-the-ground-station */}

<Tabs>
<TabItem value="windows" label="Windows" default>

```powershell title="PowerShell (Administrator)"
New-NetFirewallRule -DisplayName "MAVLink Telemetry" -Direction Inbound -Protocol UDP -LocalPort 14550 -Action Allow
New-NetFirewallRule -DisplayName "UAV Video" -Direction Inbound -Protocol UDP -LocalPort 5600-5602 -Action Allow
```

</TabItem>
<TabItem value="linux" label="Linux (UFW)">

```bash
sudo ufw allow 14550/udp comment 'MAVLink Telemetry'
sudo ufw allow 5600:5602/udp comment 'UAV Video and audio'
```

</TabItem>
</Tabs>

Добавьте другие порты, если вы используете другие порты телеметрии или видео либо несколько дронов через привязки потоков Fleet Manager.
