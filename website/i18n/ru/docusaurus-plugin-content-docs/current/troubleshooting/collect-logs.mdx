# Сбор журналов для поддержки {/* #collect-logs-for-support */}

Один архив журналов отвечает на большинство вопросов, которые поддержка иначе задала бы вам. Каждый архив содержит выбранные вами журналы служб и снимок `diagnostics.txt`: версию, ОС и плату, настройки, сгенерированную конфигурацию маршрутизатора телеметрии, последовательные устройства и процессы, которые их занимают, а также события питания и USB из ядра. Пароли, ключи и токены никогда не включаются.

## Скачивание через веб-интерфейс {/* #download-from-the-web-interface */}

<Steps>

1. Перейдите в **Приложение** и прокрутите страницу до раздела **Логирование**.
2. В первом списке оставьте **Все журналы** или выберите службу, которая соответствует проблеме (см. таблицу).
3. Во втором списке выберите временной диапазон, который охватывает проблему. По умолчанию выбрано **Последние 2 часа**.
4. Нажмите **Скачать**. Браузер сохранит файл `.zip`.

</Steps>

| Проблема | Что выбрать в списке журналов |
|---|---|
| Связь с полётным контроллером, нет heartbeat, нет телеметрии | **Mavlink менеджер** (Mavlink Manager) |
| Камера, видео, предпросмотр | **Сервер камеры** (Camera Server) |
| Модем, сотовая связь | **Менеджер модема** (Modem Manager) |
| ZeroTier, Tailscale | **VPN менеджер** (VPN Manager) |
| RTK, NTRIP | **NTRIP клиент** (NTRIP Client) |
| Лицензия | **Менеджер лицензий** (License Manager) |
| Динамический DNS | **DNS менеджер** (DNS Manager) |
| Установка | **Установщик приложения** (Application Installer) |
| Не уверены | **Все журналы** (All Logs) |

Скачивать журналы могут только администраторы. **Очистить все журналы** (Prune All Logs) удаляет все файлы журналов и не может быть отменено, поэтому сначала скачайте их.

## Из командной строки {/* #from-the-command-line */}

Если веб-интерфейс не открывается, соберите журналы по SSH:

```bash
sudo tar czf ~/uavcast-logs.tar.gz /opt/uavcast-pro/logs /opt/uavcast-pro/installer.log
journalctl -u uavcast-web -u uavcast-factory -u mavlink-manager -u uavcast-camera --since "2 hours ago" > ~/uavcast-journal.txt
```

Скопируйте оба файла на свой компьютер, например с помощью `scp`.

## Отправка в поддержку {/* #send-them-to-support */}

Напишите на **support@uavmatrix.com** и приложите:

- архив журналов,
- версию UAVcast-Pro (указана внизу боковой панели),
- плату, ОС, полётный контроллер, камеру и модем, которые вы используете,
- что вы ожидали, что произошло и что вы уже попробовали по этим страницам.

Вы также можете задать вопрос в [UAVmatrix Discord](https://discord.gg/xwqMTXh). Не публикуйте файлы журналов в открытом доступе: они содержат IP-адреса и имена устройств.

См. также: [Настройки приложения](../uavcast-pro/application-settings.mdx)
