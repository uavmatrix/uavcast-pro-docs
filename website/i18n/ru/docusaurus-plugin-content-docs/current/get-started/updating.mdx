# Обновление UAVcast-Pro {/* #update-uavcast-pro */}

Обновите UAVcast-Pro в веб-интерфейсе в разделе **Приложение → Обновление приложения** или запустив установщик повторно по SSH. Оба способа сохраняют ваши настройки, пользователей, лицензию и записи. Дрону нужен доступ в интернет, а по завершении обновления необходимо перезагрузить устройство.

:::warning Никогда не обновляйте перед полётом
Обновление останавливает все службы UAVcast-Pro, включая телеметрию и видео, и требует перезагрузки. Обновляйте на земле, когда летательный аппарат разоружён.
:::

## Обновление через веб-интерфейс {/* #update-from-the-web-interface */}

<Steps>

1. Перейдите в **Приложение**. Карточка **Обновление приложения** показывает **Текущая версия** и **Последняя версия**. Когда выходит более новая версия, появляется зелёный баннер *New version … available*.
2. Оставьте **Выберите версию для обновления** на последней версии или выберите другую.
3. Выберите **Обновить до версии …** (или **Обновить сейчас**). В разделе **Прогресс** отображаются шаги загрузки и установки. Это занимает несколько минут, на Pi Zero 2 W или Pi 3 — дольше.
4. Когда появится баннер **Ожидается перезапуск**, выберите **Перезапустить сейчас**. Устройство перезагрузится.
5. Снова откройте веб-интерфейс и проверьте **Текущая версия**.

</Steps>

## Обновление через командную строку {/* #update-from-the-command-line */}

Запустите установщик повторно. Он заменит программные файлы и сохранит базу данных:

```bash title="На дроне"
curl -fsSL https://install.uavmatrix.com | sudo bash
sudo reboot
```

Чтобы установить конкретную версию, выведите список версий (root-права не нужны), затем установите одну из них с помощью `-b`:

```bash title="На дроне"
# List the versions available for this device
curl -fsSL https://install.uavmatrix.com | bash -s -- -l

# Install a specific version
curl -fsSL https://install.uavmatrix.com | sudo bash -s -- -b 6.5.1
```

## Возврат к более старой версии {/* #go-back-to-an-older-version */}

Выберите более старую версию в поле **Выберите версию для обновления** и обновите как обычно или используйте `-b` в командной строке. Настройки, сделанные в новой версии, могут отсутствовать в старой.

## Что сохраняется и заменяется при обновлении {/* #what-an-update-keeps-and-replaces */}

| Сохраняется | Заменяется |
|---|---|
| База данных настроек (`/opt/uavcast-pro/uavcast.db`): наземные станции, камера, модем, VPN, пользователи, лицензия | Программные файлы в `/opt/uavcast-pro` (`build`, `dist`, `factory`, `install`) |
| Записи и журналы телеметрии | Файлы служб systemd |
| Членство в ZeroTier и Tailscale | Системные пакеты, от которых зависит UAVcast-Pro (обновляются через apt) |

Начиная с UAVcast-Pro 6.5.3 пользовательский **Порт сервера**, заданный на странице Приложение, сохраняется при обновлении. Более ранние версии сбрасывают его на 80: после обновления с такой версии откройте веб-интерфейс на порту 80 и сохраните свой порт снова.

## Что изменилось {/* #see-what-changed */}

Каждый выпуск перечислен с изменениями в [журнале изменений](../reference/changelog.mdx). Прочтите его перед обновлением дрона, который используется в эксплуатации.
