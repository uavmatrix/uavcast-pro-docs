# Что такое UAVcast-Pro? {/* #what-is-uavcast-pro */}

UAVcast-Pro — это программа для бортового компаньона на вашем дроне, обычно Raspberry Pi. Она читает MAVLink с любого полётного контроллера MAVLink (ArduPilot или PX4), передаёт видеопоток H.264 с одной или двух камер и отправляет оба на вашу наземную станцию управления по Wi-Fi, Ethernet или через 4G/LTE-модем. Вы настраиваете систему и контролируете её через веб-интерфейс, который работает на дроне.

UAVmatrix Fleet Manager — это облачная панель управления, которая работает вместе с ним. Сопрягите дрон с UAVcast-Pro с Fleet Manager, и вы сможете видеть весь парк на одной карте, открывать удалённый терминал, планировать миссии и направлять видео и телеметрию на наземные станции без проброса портов. Fleet Manager входит в каждую лицензию UAVcast-Pro.

## Как связаны компоненты {/* #how-the-pieces-connect */}

```text
 Flight controller ──USB/UART──►  Companion computer running UAVcast-Pro
 (ArduPilot, PX4)                  │  MAVLink router, camera server, modem,
 Camera(s) ──CSI/USB────────────►  │  VPN, NTRIP client, recorder, web UI
                                   │
                                   ├── UDP 14550 (telemetry) ─┐
                                   ├── UDP 5600  (video)    ──┼─► Mission Planner / QGroundControl
                                   │                          │   over LAN, VPN or 4G
                                   └── MQTT/TLS 8883 ─────────┴─► Fleet Manager (optional)
```

- **На дроне**: UAVcast-Pro монопольно использует последовательный порт полётного контроллера и передаёт MAVLink на каждую добавленную вами наземную станцию. Сервер камеры кодирует H.264 и отправляет RTP по UDP на те же наземные станции. Входящие подключения телеметрии никто не принимает, пока вы сами их не добавите.
- **Между дроном и землёй**: в локальной сети достаточно собственного IP-адреса наземной станции. По 4G у дрона нет публичного адреса, поэтому обе стороны подключаются к одному VPN. [VPN Fleet Manager](../uavcast-pro/connectivity/vpn.mdx), входящий в каждую лицензию, делает это за вас; UAVcast-Pro также может подключаться к вашей собственной сети Tailscale или ZeroTier.
- **В облаке**: после сопряжения дрон поддерживает исходящее подключение MQTT к Fleet Manager с аутентификацией по сертификату. См. [Сопряжение дрона с Fleet Manager](../uavcast-pro/fleet-pairing.mdx).

| Область | Что делает | Страница |
|---|---|---|
| Телеметрия | Автоматически определяет порт полётного контроллера и скорость (бод), направляет MAVLink на любое количество наземных станций, а также на необязательные пункты назначения только для чтения | [Полётный контроллер](../uavcast-pro/flight-controller/index.mdx), [Наземные станции](../uavcast-pro/ground-stations/index.mdx) |

| Запись | Записывает видео и телеметрию каждого полёта на дроне, с плеером для разбора полёта | [Записи](../uavcast-pro/camera/recordings.mdx) |
| Карта полёта | Карта в реальном времени, кабинный HUD, взведение и разоружение, RTL и Loiter, планировщик миссий, инспектор MAVLink, анализ журналов | [Карта Полёта](../uavcast-pro/flight-map/index.mdx) |

| Пользовательские данные | Передавайте данные датчиков и скриптов в MAVLink и отображайте их графиками | [Инжекторы](../uavcast-pro/flight-controller/injectors.mdx), [Потоки данных](../uavcast-pro/data-streams.mdx) |

## Что понадобится {/* #what-you-need */}

- 64-битный Linux-компьютер на борту (arm64 или amd64). Чаще всего выбирают Raspberry Pi 3, 4, 5 и Zero 2 W; подходят и мини-ПК x86, а также NVIDIA Jetson, Orange Pi и другие платы arm64, которые поддерживаются начиная с UAVcast-Pro 6.5.3. См. [Требования к оборудованию](./hardware-requirements.mdx).
- Полётный контроллер MAVLink: ArduPilot или PX4. Кнопки полётных режимов используют названия режимов ArduPilot.
- Лицензия UAVcast-Pro из [магазина UAVmatrix](https://uavmatrix.com/products/). См. [Лицензирование и активация](./license-activation.mdx).
- Для полётов за пределами зоны Wi-Fi: 4G/LTE-модем и SIM-карта с передачей данных.
