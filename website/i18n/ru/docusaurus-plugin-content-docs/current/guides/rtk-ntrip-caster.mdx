# RTK GPS по 4G с NTRIP-кастером {/* #rtk-gps-over-4g-with-an-ntrip-caster */}

UAVcast-Pro может получать поправки RTCM3 от NTRIP-кастера через собственное интернет-подключение дрона и передавать их на полётный контроллер. Вы получаете позиционирование RTK Float или RTK Fixed без базовой станции и отдельного радио. Подойдёт любой стандартный NTRIP-кастер v1 или v2.

```text
NTRIP caster ──RTCM3 over TCP/TLS──► UAVcast-Pro ──MAVLink GPS_RTCM_DATA──► flight controller ──► RTK GPS
      ▲                                    │
      └──────── GGA position (VRS) ────────┘
```

**Вам понадобится:**

- GPS с поддержкой RTK на полётном контроллере, например модуль u-blox F9P, Here3+ или Septentrio Mosaic. Стандартные навигационные модули M8N/M10 не могут работать в режиме RTK.
- UAVcast-Pro с полётным контроллером в статусе **Подключено** и доступом в интернет на дроне.
- Учётная запись у кастера: национальная сеть CORS, коммерческий сервис (Trimble, Hexagon, Topcon …) или бесплатный кастер сообщества rtk2go.com.

## 1. Введите данные кастера {/* #1-enter-the-caster */}

<Steps>

1. Откройте **Полётный контроллер → NTRIP / RTK**.
2. Введите **Хост кастера** и **Порт** (обычно `2101`).
3. Включите **Использовать TLS (HTTPS)**, только если этого требует ваш провайдер. Коммерческие кастеры часто требуют, открытые — редко.
4. Введите **Имя пользователя** и **Пароль**. Для rtk2go.com используйте адрес электронной почты как имя пользователя, а поле пароля оставьте пустым.
5. Нажмите **Проверить подключение** и дождитесь сообщения **Кастер принял учётные данные.**

</Steps>

## 2. Выберите точку монтирования {/* #2-pick-a-mountpoint */}

<Steps>

1. Нажмите **Просмотреть точки монтирования**. UAVcast-Pro загрузит список кастера.
2. Выберите точку монтирования ближе всего к месту полётов. В списке показаны **Формат**, **GNSS**, **Страна**, **Местоположение** и требуется ли позиция (**NMEA**: **Требуется**).
3. Нажмите **Выбрать**. Название попадёт в поле **Точка монтирования**.

</Steps>

## 3. Передайте свою позицию (VRS и кастеры с ближайшей точкой) {/* #3-send-your-position-vrs-and-nearest-mountpoint-casters */}

Кастеры VRS и кастеры с ближайшей точкой формируют поправки для вашего местоположения, поэтому им нужна ваша позиция в виде NMEA-предложения GGA.

<Steps>

1. Оставьте **Отправлять GGA вверх по потоку** включённым (по умолчанию), а **Интервал отправки (секунды)** — 10.
2. Оставьте **Источник позиции** на **Текущая позиция от полётного контроллера**.
3. Также введите **Широту**, **Долготу** и **Высоту (м)** в ручной позиции. UAVcast-Pro использует её, пока полётный контроллер не получит фиксацию GPS.

</Steps>

Для одной фиксированной базы GGA не вредит, но его можно отключить.

## 4. Запустите поток {/* #4-start-the-stream */}

Включите **Включить клиент NTRIP**. Через несколько секунд панель статуса должна показать:

1. **Состояние**: **Передача поправок**, с **Ответ кастера** вида `ICY 200 OK`.
2. Счётчик **Передано сообщений RTCM** растёт, а **Последний кадр RTCM** показывает *только что*.
3. **Недавние типы сообщений** с вашими созвездиями, например 1005, 1077, 1087, 1097.
4. Значок фиксации RTK переходит от **3D-фикс** к **RTK Float**, а затем к **RTK Fixed** при открытом небе.

Карточка **Качество GPS** добавляет точность, которую сообщает приёмник, и измеренную **Стабильность позиции (1σ)**, которая не зависит от собственной оценки приёмника. Панель управления показывает состояние в разделе **Поправки RTK**, а тип фиксации — в разделе **GPS**.

## Пресеты {/* #presets */}

```text title="Кастер сообщества (rtk2go.com)"
Caster host   rtk2go.com
Port          2101
TLS           off
Username      you@example.com
Password      (empty)
Mountpoint    nearest one from Browse mountpoints
```

```text title="Коммерческий сервис VRS"
Caster host   provider host name
Port          2101 (sometimes 2102 or 443)
TLS           as the provider says
Username      provider account
Password      provider password
Mountpoint    the provider's VRS mountpoint
GGA upstream  on, 10 s, live position from flight controller
```

## Полезно знать {/* #good-to-know */}

- Поправки идут по тому же каналу MAVLink, что и телеметрия, поэтому связь с полётным контроллером должна быть активна.
- После кратковременного обрыва интернета поправки возобновляются в течение нескольких секунд. Если кастер замолкает, UAVcast-Pro переподключается самостоятельно.
- Точность падает с расстоянием до базовой станции. Выбирайте ближайшую точку монтирования или используйте сервис VRS.

## Устранение неполадок {/* #troubleshooting */}

Застряли на **Подключение...**, получили ответ `401`, нет данных RTCM или нет фиксации RTK: [Поправки RTK не поступают](../troubleshooting/rtk-corrections-not-arriving.mdx). Все настройки этой страницы описаны в [NTRIP / RTK](../uavcast-pro/flight-controller/ntrip-rtk.mdx).
