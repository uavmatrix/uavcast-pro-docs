# Удалённый доступ через Tailscale {/* #remote-access-with-tailscale */}

Tailscale — это VPN на основе WireGuard. Если ваша команда уже им пользуется, это самый быстрый способ связаться с дроном по 4G: дрон и ваш ноутбук подключаются к одной tailnet и обмениваются данными по адресам `100.x.y.z`.

Нет tailnet? VPN Fleet Manager, входящий в вашу лицензию, делает то же самое без учётной записи Tailscale: см. [Полёт за пределами прямой видимости по 4G](./bvlos-4g.mdx) и [Подключение парка дронов](./fleet-onboarding.mdx).

**Вам понадобится:** UAVcast-Pro с доступом в интернет на дроне (Wi-Fi или модем), учётная запись Tailscale и клиент Tailscale на ноутбуке.

## 1. Войдите на дроне в Tailscale {/* #1-log-the-drone-in-to-tailscale */}

<Steps>

1. В UAVcast-Pro откройте **Виртуальная частная сеть**.
2. Установите **Включить VPN** в **Да**, а **Сервисы** — в **Tailscale**.
3. Выберите способ входа:
   - **Веб-вход**: нажмите **Сгенерировать URL для входа**, затем **Аутентифицировать это устройство** и войдите в учётную запись Tailscale на открывшейся странице.
   - **Ключ аутентификации**: создайте ключ аутентификации в консоли администратора Tailscale, вставьте его в поле **Ключ аутентификации**, при необходимости задайте **Имя хоста (Опционально)** и нажмите **Подключиться с помощью ключа**. Используйте этот способ, если настраиваете дроны для других людей или сразу много дронов.
4. Дождитесь статуса **Подключено**. Запишите **IPv4 адрес** (100.x.y.z).

</Steps>

:::tip Отключите истечение ключей для дронов
Ключи устройств Tailscale истекают, и дрон с истёкшим ключом выпадает из tailnet, пока кто-нибудь снова не выполнит вход. Поле **Истекает** показывает, когда это произойдёт. В консоли администратора Tailscale отключите истечение ключей для дронов, которые вы развёртываете.
:::

## 2. Подключите ноутбук к той же tailnet {/* #2-put-the-laptop-on-the-same-tailnet */}

Установите Tailscale на ноутбук и войдите с той же учётной записью или в ту же tailnet. Выполните `tailscale status`: дрон должен быть в списке. Затем:

```bash
ping <drone tailscale ip>
```

Откройте веб-интерфейс дрона по адресу `http://<drone tailscale ip>/`.

## 3. Отправляйте телеметрию и видео на ноутбук {/* #3-send-telemetry-and-video-to-the-laptop */}

<Steps>

1. В UAVcast-Pro перейдите в **Наземные станции** и нажмите **Добавить пункт назначения**.
2. В поле **IP-адрес или хост назначения** введите IPv4-адрес Tailscale **ноутбука** (выполните `tailscale ip -4` на ноутбуке).
3. Включите **Включить телеметрию** и **Включить видео**.
4. Разрешите входящий UDP 14550 и 5600 в брандмауэре ноутбука. Windows часто считает адаптер Tailscale общедоступной сетью.

</Steps>

Откройте QGroundControl или Mission Planner. Телеметрия поступит по UDP 14550, а видео — по UDP 5600.

## 4. Проверьте качество соединения {/* #4-check-the-connection-quality */}

Поле **Ретранслятор** на странице **Виртуальная частная сеть** показывает, идёт ли трафик через ретранслятор Tailscale. Путь через ретранслятор работает, но добавляет задержку. Некоторые сотовые операторы не разрешают прямые соединения, поэтому проверяйте связь у того оператора, с которым будете летать.

## Устранение неполадок {/* #troubleshooting */}

- Не удаётся пропинговать дрон: [VPN подключён, но нет доступа к дрону](../troubleshooting/vpn-cant-reach-drone.mdx)
- Ping работает, телеметрии нет: [Нет телеметрии в наземной станции](../troubleshooting/no-telemetry-in-gcs.mdx)
- Если позже дрон будет сопряжён с Fleet Manager и вы выберете **Replace existing VPN with Fleet Manager network**, он выйдет из вашей tailnet и подключится к сети организации.
