# Fleet Manager {/* #fleet-manager */}

UAVmatrix Fleet Manager — веб-приложение по адресу [fleet-manager.uavmatrix.com](https://fleet-manager.uavmatrix.com) для управления большим количеством дронов из одного места. Любой дрон с UAVcast-Pro можно сопрячь с вашей организацией. После этого вы видите его на живой карте, открываете его терминал, отправляете команды, загружаете миссии и направляете его видео и телеметрию на наземные станции, которые используют ваши пилоты.

## Как всё устроено {/* #how-it-fits-together */}

Fleet Manager никогда не обращается к полётному контроллеру напрямую. Это делает UAVcast-Pro на бортовом компаньоне дрона, который поддерживает одно зашифрованное соединение с Fleet Manager:

1. **Сопряжение.** UAVcast-Pro запрашивает у Fleet Manager код сопряжения. Вы вводите код в Fleet Manager. Затем Fleet Manager передаёт дрону его собственный клиентский сертификат.
2. **Канал управления.** Дрон подключается к брокеру MQTT Fleet Manager по TLS на порту **8883**, аутентифицируясь этим сертификатом. Телеметрия, пульсовые сообщения (heartbeat), команды, терминальные сессии и удалённый доступ к веб-интерфейсу UAVcast-Pro проходят через это соединение. Оно работает через NAT и сотовые сети, потому что дрон всегда подключается наружу.
3. **Канал данных (необязательный).** Видео и MAVLink до наземной станции передаются напрямую между устройствами через виртуальную частную сеть вашей организации — сеть WireGuard, которой управляет Fleet Manager. Без VPN Fleet Manager по-прежнему показывает и контролирует дрон, но не направляет потоки.

## Основные понятия {/* #concepts */}

| Термин | Что это значит в Fleet Manager |
|---|---|
| **Организация** | Ваша компания или команда. Дроны, миссии, сеть VPN и участники принадлежат одной организации. Каждый пользователь может владеть одной организацией и быть участником любого количества других. |
| **UAV** | Дрон (или ровер, катер или другое транспортное средство) с UAVcast-Pro, привязанный одновременно только к одной организации. Fleet Manager распознаёт его по ID устройства, который UAVcast-Pro формирует на основе серийного номера процессора бортового компаньона и загрузочного диска, поэтому идентичность сохраняется после перезагрузок и смены сети. |
| **Сопряжение** | Привязка UAV к организации с помощью 8-значного кода, который показывает UAVcast-Pro. Код действует 5 минут. |
| **Наземная станция (GCS)** | Ноутбук или ПК с QGroundControl, Mission Planner или аналогичным ПО, подключённый к VPN вашей организации, чтобы принимать потоки. |
| **Привязка потока** | Правило «отправлять видео и телеметрию этого UAV на эту наземную станцию». У каждой привязки свои UDP-порты, поэтому одна наземная станция может одновременно принимать сигнал от многих дронов. |
| **Роли** | **Owner**, **Admin** или **Viewer**, задаются для каждой организации. Viewer может только смотреть; Admin и Owner могут сопрягать, управлять и настраивать. См. [Роли и права доступа](./team/roles-and-permissions.mdx). |
| **Лицензии и места** | Каждому сопряжённому UAV нужна активная лицензия UAVcast-Pro, принадлежащая участнику организации. Члены команды мест не занимают. См. [Лицензии](./licenses.mdx). |
| **Статус и оповещения** | Статусы «онлайн», «офлайн», «нет MAVLink» и предупреждения о GPS на карте и в списке дронов, а также системные объявления. См. [Индикаторы статуса и уведомления](./alerts-and-status.mdx). |

## Что нужно {/* #what-you-need */}

Fleet Manager входит в вашу лицензию UAVcast-Pro: отдельной подписки и дополнительных мест не требуется.

- Учётная запись UAVmatrix (та же, что вы используете на [uavmatrix.com](https://uavmatrix.com) для покупки лицензий).
- Как минимум один бортовой компаньон с установленным UAVcast-Pro и активированной лицензией. См. [Установка](../get-started/installation.mdx) и [Активация лицензии](../get-started/license-activation.mdx).
- Доступ дрона в интернет с исходящим HTTPS (443) и открытым TCP **8883**.
