# Настройки, аккаунт и оплата {/* #settings-account-and-billing */}

Откройте **Settings** из боковой панели (**Organization → Settings**) или из меню пользователя. Здесь четыре вкладки: **Profile**, **Organizations**, **Support** и **History**.

## Профиль {/* #profile */}

Ваше имя, email, фотография и пароль принадлежат аккаунту UAVmatrix. **Изменения профиля управляются через UAVMatrix Store**: в разделе **Password & Security** выберите **UAVMatrix Store**, чтобы внести изменения там. Fleet Manager подхватит их автоматически.

## Организации {/* #organizations */}

Переименуйте организацию, измените её описание или (только для Owner) удалите её. См. [Настройка организации](./set-up-organization.mdx#rename-or-delete-the-organization).

## Поддержка {/* #support */}

Ваши обращения в поддержку с их статусом и переключатель **Support Chat Bubble**, который показывает или скрывает плавающую кнопку поддержки. См. [Поддержка и FleetBot](./support.mdx).

## История {/* #history */}

Хранение телеметрии, очистка и удаление истории по каждому дрону — для Owner и Admin. См. [История полётов](./map/flight-history.mdx#how-long-history-is-kept).

## Оплата {/* #billing */}

В Fleet Manager нет страницы оплаты. Лицензии, слоты устройств, заказы и счета находятся в вашем аккаунте на [uavmatrix.com](https://uavmatrix.com). См. [Лицензии и места](./licenses.mdx).

## Удаление аккаунта {/* #delete-your-account */}

**Profile → Danger Zone → Delete Account** удаляет ваш аккаунт Fleet Manager. Для подтверждения введите `DELETE`.

Будет удалено:

- ваш профиль и данные аккаунта в Fleet Manager
- все ваши членства в организациях
- все ваши активные сеансы
- созданные вами миссии и отправленные приглашения

Записи, которые вы сделали в **Recent Activity**, останутся без вашего имени.

:::warning Сначала передайте владение
Нельзя удалить аккаунт, пока вы владеете организацией. Fleet Manager покажет список организаций и предложит [передать владение](./team/index.mdx#transfer-ownership) или сначала удалить их.
:::

Удаление аккаунта Fleet Manager не удаляет ваш аккаунт в магазине UAVmatrix и ваши лицензии. Управляйте ими на [uavmatrix.com](https://uavmatrix.com).
