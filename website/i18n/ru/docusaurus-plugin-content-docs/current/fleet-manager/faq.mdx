# FAQ Fleet Manager {/* #fleet-manager-faq */}

### Что нужно для работы с Fleet Manager? {/* #what-do-i-need-to-use-fleet-manager */}

Учётная запись UAVmatrix и дроны с UAVcast-Pro и активированной лицензией. Лицензия каждого дрона должна принадлежать участнику вашей организации. См. [Лицензии и места](./licenses.mdx).

### Стоит ли Fleet Manager дополнительных денег? {/* #does-fleet-manager-cost-extra */}

Нет. Fleet Manager входит в вашу лицензию UAVcast-Pro. Отдельной подписки нет, а участники команды ничего не платят.

### Сколько дронов можно подключить? {/* #how-many-drones-can-i-manage */}

Сам Fleet Manager не ограничивает количество дронов. Каждому дрону нужна собственная активация лицензии UAVcast-Pro, поэтому число дронов определяется вашими лицензиями и слотами устройств.

### Нужна ли лицензия участникам команды? {/* #do-team-members-need-a-license */}

Нет. Вы можете приглашать сколько угодно Admin и Viewer. См. [Пригласите команду](./team/index.mdx).

### Какие роли существуют? {/* #which-roles-are-there */}

**Owner**, **Admin** и **Viewer**. Роли «Member» нет. См. [Роли и права доступа](./team/roles-and-permissions.mdx).

### Откуда берётся код сопряжения? {/* #where-does-the-pairing-code-come-from */}

Код генерирует дрон. В UAVcast-Pro откройте **Fleet Management → Connect to Fleet Manager**. Появится 8-значный код, действительный 5 минут. Введите его в Fleet Manager в разделе **Fleet → Pair Device**. См. [Добавление первого дрона](./pair-uav.mdx).

### Работает ли Fleet Manager через 4G/LTE? {/* #does-fleet-manager-work-over-4glte */}

Да. Дрон сам устанавливает исходящее соединение с Fleet Manager по TCP 8883, поэтому работает за NAT оператора связи без публичного IP-адреса. Оператор не должен блокировать порт 8883.

### Нужен ли VPN? {/* #do-i-need-the-vpn */}

Только для передачи видео и телеметрии с дронов на наземные станции через Fleet Manager. Карта, телеметрия, команды, миссии, терминал и удалённый доступ к UAVcast-Pro работают и без него. См. [Сеть и VPN](./network/index.mdx).

### Может ли одна наземная станция принимать данные от нескольких дронов? {/* #can-one-ground-station-receive-several-drones */}

Да. Каждая [привязка потока](./network/stream-bindings.mdx) получает собственный блок портов на этой наземной станции с запасом для второй камеры и аудио. Первый дрон использует порты 5600 / 14550.

### Могу ли я продолжать использовать собственную сеть ZeroTier или Tailscale? {/* #can-i-keep-using-my-own-zerotier-or-tailscale-network */}

Да, если вам не нужны привязки потоков Fleet Manager. Можно отказаться от VPN при сопряжении. Если вы его принимаете, дрон, уже находящийся в сети Tailscale, переводится в сеть вашей организации. Дрон в ZeroTier сохраняет свою сеть ZeroTier и подключается к сети организации рядом с ней; ZeroTier покидается только при отмене сопряжения дрона.

### Работает ли он с ArduPilot и PX4? {/* #does-it-work-with-ardupilot-and-px4 */}

Fleet Manager работает с любым полётным контроллером MAVLink, с которым взаимодействует UAVcast-Pro, — ArduPilot или PX4: карта в реальном времени, телеметрия, статус, терминал и привязки потоков одинаковы. Элементы управления полётными режимами используют режимы ArduPilot для Copter, Plane, Rover и Sub, а список команд миссий следует терминологии ArduPilot. Поэтому на PX4 меняйте режимы и планируйте миссии с помощью наземной станции.

### Можно ли управлять дроном только через Fleet Manager? {/* #can-i-fly-a-drone-from-fleet-manager-alone */}

Fleet Manager может менять режимы, взводить, а также запускать, приостанавливать и останавливать миссии. Ручное управление стиками он не предназначен. Всегда держите пилота с наземной станцией или пультом RC в контроле и соблюдайте местные правила.

### Как долго хранится история полётов? {/* #how-long-is-flight-history-kept */}

По умолчанию до 1 года. Owner и Admin могут сократить срок до 7, 14, 30, 60 или 90 дней либо до 6 месяцев. См. [История полётов](./map/flight-history.mdx#how-long-history-is-kept).

### Можно ли экспортировать журналы полётов? {/* #can-i-export-flight-logs */}

Пока нет. Fleet Manager воспроизводит полёты на карте, но не экспортирует файлы и не хранит `.tlog`, DataFlash или видео.

### Отправляет ли Fleet Manager оповещения по электронной почте? {/* #does-fleet-manager-send-alerts-by-email */}

Пока нет. Статус отображается в реальном времени на карте, в списке флота и на страницах дронов. См. [Индикаторы состояния и уведомления](./alerts-and-status.mdx).

### Что происходит, когда дрон теряет связь? {/* #what-happens-when-a-drone-loses-its-connection */}

Если данные не поступают 20 секунд, дрон отображается как **OFFLINE**, а при восстановлении связи переподключается сам. Поведение самого летательного аппарата определяют собственные failsafe полётного контроллера; Fleet Manager при потере связи никаких команд не отдаёт.

### Как перевести дрон в другую организацию? {/* #how-do-i-move-a-drone-to-another-organization */}

Удалите дрон из текущей организации (это удалит его историю там), затем сопрягите его с новой. См. [Повторное сопряжение, удаление или передача дрона](./fleet/remove-or-transfer.mdx).

### Я купил лицензии на другой адрес электронной почты. Что делать? {/* #i-bought-licenses-with-a-different-email-what-now */}

Пригласите этот адрес в организацию или попросите поддержку добавить его как дополнительный адрес лицензий в вашу учётную запись. См. [Лицензии, купленные на другой адрес](./licenses.mdx#licenses-bought-with-another-email).

### Есть ли мобильное приложение? {/* #is-there-a-mobile-app */}

Есть удобный для телефона [облегчённый вид](./lite-view.mdx) в браузере.

### Безопасны ли мои данные? {/* #is-my-data-safe */}

У каждого дрона есть собственный клиентский сертификат TLS, у каждой организации — собственный зашифрованный VPN, а роли проверяются на сервере. См. [Безопасность и конфиденциальность](./security.mdx).
