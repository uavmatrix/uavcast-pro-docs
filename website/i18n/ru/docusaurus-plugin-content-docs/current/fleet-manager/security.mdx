# Безопасность и конфиденциальность {/* #security-and-privacy */}

Эта страница предназначена для людей, которые утверждают использование Fleet Manager: специалистов по информационной безопасности, руководителей ИТ и операционных подразделений.

## Подключение дрона {/* #drone-connection */}

- **Клиентские сертификаты для каждого дрона.** При сопряжении Fleet Manager выдаёт каждому дрону собственный TLS-клиентский сертификат. Дрон использует его для подключения к MQTT-брокеру Fleet Manager по порту **8883**, единственному публичному входу брокера. Общего пароля нет.
- **Каждый дрон может использовать только свои темы.** Идентификатор сертификата — это ID устройства дрона, а брокер разрешает дрону публиковать и получать сообщения только в его собственных темах. Один скомпрометированный дрон не может читать данные другого или отдавать ему команды.
- **Только исходящие соединения.** Дроны подключаются к Fleet Manager сами. Вам не нужно открывать входящие порты на дроне или в его сети.
- **Короткое окно сопряжения.** Коды сопряжения состоят из 8 случайных цифр, действуют 5 минут и используются один раз. Проверка кодов ограничена по частоте (10 проверок и 5 попыток сопряжения на пользователя в минуту). Сертификат дрона и ключ VPN выдаются только до первого подключения дрона и никогда позже чем через 15 минут после истечения срока кода.
- **Обновления сертификатов.** Когда Fleet Manager ужесточает схему сертификатов, более старые дроны помечаются как **Re-pair required**, а не принимаются молча.

## Частный VPN для каждой организации {/* #private-vpn-per-organization */}

- Каждая организация получает собственную сеть на VPN-сервере Fleet Manager (`vpn-connect.uavmatrix.com`), самостоятельно размещённом сервере управления, совместимом с Tailscale. Трафик между устройствами шифруется сквозным образом с помощью WireGuard. Устройства одной организации не видят устройства другой: VPN-сервер применяет отдельное правило доступа для каждой организации. Если Fleet Manager не может подтвердить эту изоляцию, он скрывает ключ аутентификации (*VPN isolation could not be verified, so the auth key is hidden.*) и не выдаёт ключ.
- Для подключения нужен ключ аутентификации, который могут создавать только Owner и Admin. Срок действия ключей — 90 дней. Дроны получают ключ автоматически при сопряжении или при **Push to Drone**, и только с согласия Owner или Admin.
- Удаление устройства в **Network** удаляет его с VPN-сервера.

## Контроль доступа {/* #access-control */}

- Вход выполняется через ваш аккаунт UAVmatrix. Fleet Manager не хранит пароли.
- Три роли в каждой организации (Owner, Admin, Viewer), которые проверяются на сервере для каждого действия. См. [Роли и права доступа](./team/roles-and-permissions.mdx).
- SSH-терминал и удалённый доступ к UAVcast-Pro доступны только Owner и Admin.
- Ссылки-приглашения зашифрованы, используются один раз и истекают через 7 дней.
- UAVmatrix может приостановить аккаунты или организации, нарушающие условия использования. Приостановленные пользователи видят **Account Suspended** или **Organization Suspended** с указанием причины и контактом поддержки.

## Данные, которые хранит Fleet Manager {/* #data-fleet-manager-stores */}

| Данные | Срок хранения |
|---|---|
| Телеметрия (позиция, высота, скорость, курс, батарея, режим, состояние взведения, GPS, состояние служб), раз в секунду | Согласно настройке хранения организации: от 7 дней до 1 года (по умолчанию 1 год). Сжимается через 7 дней. Удаляется при удалении дрона. |
| Названия сохранённых полётов и временные диапазоны | До удаления или до удаления дрона |
| Команды, отправленные дронам, с указанием отправителя | До удаления дрона |
| Журнал действий (кто сопрягал, удалял, приглашал, менял роли) | Сохраняется при удалении дронов или участников |
| Миссии | До удаления или до удаления организации |
| Обращения в поддержку и их скриншоты | Хранятся для поддержки |

Fleet Manager не хранит видео. Видео и MAVLink до наземных станций передаются через VPN между вашими устройствами, и Fleet Manager их не записывает.

Терминал и удалённый прокси UAVcast-Pro проходят через зашифрованное соединение Fleet Manager с дроном; их содержимое не сохраняется.

Трафик VPN идёт напрямую между вашими устройствами, если сети это позволяют. Если не позволяют (например, за строгим NAT или у мобильного оператора), он переходит на публичные релейные серверы Tailscale (DERP). В любом случае трафик остаётся зашифрованным сквозным образом с помощью WireGuard; UAVmatrix не управляет релейными серверами.

## Сторонние сервисы {/* #third-parties */}

- **Карты:** тайлы карты поступают от Esri; слой воздушного пространства — от OpenAIP через Fleet Manager.
- **FleetBot:** сообщения чата отправляются в Anthropic для генерации ответов. Ничего другого из данных вашей организации не отправляется. См. [Поддержка и FleetBot](./support.mdx#ask-fleetbot).
- **Аналитика продукта и отчёты об ошибках:** Fleet Manager использует PostHog для аналитики использования, например, какие страницы открываются и какие кнопки нажимаются, а также для отправки сообщений об ошибках приложения.
