# Fleet {/* #fleet */}

**Fleet** (боковая панель: **Fleet Management → Fleet**) показывает все дроны выбранной организации. Список обновляется в реальном времени, поэтому его можно держать открытым на большом экране рядом с [картой](../map/index.mdx).

## Карточки дронов {/* #uav-cards */}

В заголовке отображается **UAVs (n)**. Каждая карточка содержит:

- **Name** (имя) и значок статуса: **ONLINE**, **OFFLINE** или **PAIRING**.
- **Battery** (батарея) в процентах. Становится жёлтой ниже 50 % и красной ниже 20 %.
- **Last seen** (последний выход на связь) в относительном времени. Карточки офлайн-дронов приглушены.
- **Re-pair required** (требуется повторное сопряжение), если дрон нужно сопрячь ещё раз (см. [Повторное сопряжение дрона](./remove-or-transfer.mdx#re-pair-a-drone)).

Дрон считается офлайн, если в течение **20 секунд** от UAVcast-Pro не поступило ни одного сообщения; UAVcast-Pro отправляет heartbeat каждые 5 секунд.

На каждой карточке две кнопки:

- **Operations** открывает [панель управления](./remote-control.mdx): полётные режимы, взведение и разоружение, миссии.
- **Details** открывает [страницу UAV](./uav-details.mdx): телеметрия в реальном времени, терминал, журналы, системные действия, переименование и удаление.

## Кнопки на странице {/* #buttons-on-the-page */}

- **Pair Device** запускает [мастер сопряжения](../pair-uav.mdx). Только для Owner и Admin.
- **Refresh** перезагружает список.
- **Need more devices?** → **View Plans** открывает магазин UAVmatrix, где вы покупаете дополнительные лицензии UAVcast-Pro. См. [Лицензии](../licenses.mdx).

## Баннер повторного сопряжения {/* #re-pair-banner */}

Если один или несколько дронов используют старый сертификат подключения, в верхней части страницы появляется баннер **n UAV(s) must be re-paired**. Повторно сопрягите каждый дрон из списка один раз: он сохранит имя и историю. См. [Повторное сопряжение дрона](./remove-or-transfer.mdx#re-pair-a-drone).

## Советы для больших флотов {/* #tips-for-large-fleets */}

- **Называйте дроны для карты.** Имена отображаются на подписях карты и в списках привязок. Номер борта или роль («Inspection-07») удобнее имени хоста по умолчанию. Переименовать можно на странице UAV.
- **Назначьте каждому дрону собственный цвет.** Fleet Manager автоматически выбирает цвета из палитры из 24 цветов. Чтобы дроны, которые должна узнавать команда, было видно с первого взгляда, задайте фиксированный цвет на панели управления (**Change map color**).
- **Используйте организации для разделения клиентов.** Дрон принадлежит ровно одной организации. Если вы работаете на нескольких клиентов, каждый из которых должен видеть только свои дроны, создайте для каждого отдельную организацию.
