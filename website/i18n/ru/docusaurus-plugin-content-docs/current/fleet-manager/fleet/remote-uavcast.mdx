# Открытие UAVcast-Pro удалённо {/* #open-uavcast-pro-remotely */}

Вы можете изменять настройки UAVcast-Pro на дроне (камера, модем, наземные станции и т. д.), не находясь в одной сети с дроном. На [странице UAV](./uav-details.mdx) карточка **UAVcast Application** содержит две кнопки:

| Кнопка | Способ подключения | Для чего использовать |
|---|---|---|
| **Open via Proxy** | Через зашифрованное соединение Fleet Manager с дроном. Работает для любого дрона в сети, VPN не нужен. | Изменение настроек и базовое управление. |
| **Open via VPN** | Открывает `http://<адрес VPN дрона>` напрямую. Отображается, только если дрон находится в VPN вашей организации, и ваш компьютер также должен быть подключён к этому VPN. | Всё, включая карту полёта и телеметрию в реальном времени. |

Прокси доступен Owner и Admin. Fleet Manager отказывает в доступе роли Viewer с сообщением **Access denied. Only administrators can access UAVcast remotely.**

## Open via Proxy {/* #open-via-proxy */}

<Steps>

1. На странице UAV нажмите **Open via Proxy**.
2. Прочтите диалог **Remote UAVcast Access via Proxy** и нажмите **Continue**.
3. UAVcast-Pro откроется в новой вкладке на странице **Application**. Войдите под пользователем UAVcast-Pro дрона: прокси не передаёт ваш логин Fleet Manager. (Дрон, на котором ещё нет пользователей UAVcast-Pro, откроется без входа.)

</Steps>

<Screenshot id="fleet-manager/drone-detail--proxy-warning" alt="Диалог Remote UAVcast Access via Proxy с перечнем недоступных функций" caption="Диалог Remote UAVcast Access via Proxy с перечнем недоступных функций WebSocket: телеметрия в реальном времени, статус соединения MAVLink и карта полёта." />

Прокси передаёт обычные запросы страниц, но не постоянные соединения. **WebSocket features unavailable** означает, что через него не работают:

- телеметрия и обновления в реальном времени
- статус соединения MAVLink
- карта полёта

На каждый запрос отводится 30 секунд. На медленном соединении большие страницы могут не загрузиться: появится **Request timed out. UAVcast may be unreachable.** Если дрон офлайн, вы увидите **Drone is offline. UAVcast interface is not available.**

:::warning Будьте осторожны с сетевыми настройками через прокси
Прокси работает через собственное интернет-соединение дрона. Если вы измените настройки модема, приоритет сети или VPN, и дрон потеряет интернет, прокси тоже перестанет работать, и для исправления понадобится локальный доступ.
:::

## Open via VPN {/* #open-via-vpn */}

Подключите ваш компьютер к VPN организации так же, как наземную станцию (см. [Подключение наземной станции](../connect-gcs.mdx)). После этого **Open via VPN** откроет веб-интерфейс дрона напрямую со всеми функциями в реальном времени. Этот способ лучше подходит для всего, что выходит за рамки изменения отдельных настроек.
