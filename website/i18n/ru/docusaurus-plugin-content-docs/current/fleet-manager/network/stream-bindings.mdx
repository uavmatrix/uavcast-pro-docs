# Привязки потоков {/* #stream-bindings */}

Привязка потока указывает дрону отправлять видео и телеметрию на одну наземную станцию через VPN вашей организации. Один дрон может передавать потоки на несколько наземных станций, а одна наземная станция может принимать сигнал от нескольких дронов. Fleet Manager выбирает порты так, чтобы потоки никогда не пересекались.

## Перед началом {/* #before-you-begin */}

- [VPN включена](./index.mdx#enable-vpn), а дрон подключён к ней (тип **UAV** в **Connected Devices**).
- Наземная станция [подключена и настроена как **GCS**](../connect-gcs.mdx).
- Роль **Owner** или **Admin**.
- Дрон **в сети**. Fleet Manager сразу отправляет новые пункты назначения в UAVcast-Pro и ждёт подтверждения.

## Добавление привязки {/* #add-a-binding */}

<Steps>

1. Перейдите в **Network → Stream Bindings** и нажмите **Add Binding**.
2. В **Add Stream Binding** выберите **Drone** и **Ground Station**.
3. Нажмите **Create Binding**.

</Steps>

<Screenshot id="fleet-manager/network--add-binding" alt="Диалог Add Stream Binding с выбором дрона и наземной станции и примечанием об автоматическом назначении портов" caption="Диалог Add Stream Binding с выбранными дроном и наземной станцией и примечанием о том, что порты назначаются автоматически." />

Привязка появится в таблице с включёнными **Video** и **Telemetry** и своими **Ports** (видео / телеметрия). UAVcast-Pro начнёт отправку в течение нескольких секунд.

Если дрон не подтверждает в течение 15 секунд, Fleet Manager отменяет привязку с сообщением **Failed to send configuration to drone - it may be offline**. Проверьте, что дрон в сети, и попробуйте снова.

## Как назначаются порты {/* #how-ports-are-assigned */}

Порты считаются **для каждой наземной станции**. Каждая привязка получает собственный блок UDP-портов на этой наземной станции, поэтому дроны никогда не пересекаются:

- **видеопорт** для камеры 1, за которым идут порты для **камеры 2** (двойной поток) и **звука**, на которые UAVcast-Pro отправляет данные после видеопорта;
- **телеметрический порт** для MAVLink.

Первая привязка на наземной станции использует значения по умолчанию: видео **5600** и телеметрия **14550**. Следующие привязки получают следующий свободный блок.

Несколько важных следствий:

- **Каждая наземная станция начинает со значений по умолчанию.** Один и тот же дрон может иметь разные порты на двух ноутбуках в зависимости от того, что ещё принимает каждый ноутбук.
- **Освободившиеся порты используются повторно.** Удаление привязки освобождает её блок для следующей новой привязки к этому ноутбуку.
- **Порты не следуют за дроном.** Удаление и повторное добавление привязки может дать другие порты. Всегда читайте столбец **Ports** перед настройкой ПО наземной станции.
- Порты назначает Fleet Manager, и изменить их в приложении нельзя.
- Заданный вручную на дроне **Порт видео (Камера 2)** сохраняется при обновлении пунктов назначения из Fleet Manager только начиная с UAVcast-Pro 6.5.3. В более ранних версиях следующее обновление его сбрасывает.

## Настройка ПО наземной станции {/* #set-up-the-ground-station-software */}

Используйте порты из столбца **Ports** привязки. Поток приходит с VPN-адреса дрона.

<Tabs>
<TabItem value="qgc" label="QGroundControl">

- **Телеметрия:** QGroundControl по умолчанию слушает UDP 14550, поэтому первый дрон подключается сам. Для остальных дронов откройте **Application Settings → Comm Links**, добавьте связь типа **UDP** с телеметрическим портом привязки и подключите её.
- **Видео:** в **Application Settings → Video** (в старых версиях — **General**) установите **Source** в **UDP h.264 Video Stream** и укажите видеопорт привязки (**UDP URL** `0.0.0.0:<port>` в актуальных версиях). QGroundControl показывает одно видео за раз; чтобы смотреть несколько дронов, запустите второй экземпляр или используйте видеоплеер для остальных.

</TabItem>
<TabItem value="mp" label="Mission Planner">

- **Телеметрия:** в выпадающем списке подключения в правом верхнем углу выберите **UDP**, нажмите **Connect** и введите телеметрический порт привязки. Для нескольких дронов подключайтесь по одному разу на каждый порт; Mission Planner показывает каждый аппарат по системному ID.
- **Видео:** щёлкните правой кнопкой мыши по HUD, выберите **Video → Set GStreamer Source** и введите конвейер, который слушает видеопорт привязки. Точный конвейер см. в разделе [Mission Planner](../../uavcast-pro/ground-stations/mission-planner.mdx).

</TabItem>
</Tabs>

:::tip Дайте каждому дрону собственный системный ID MAVLink
Когда одна наземная станция принимает несколько дронов, каждый полётный контроллер должен иметь уникальный `SYSID_THISMAV` (ArduPilot) или `MAV_SYS_ID` (PX4). Иначе наземная станция их перепутает.
:::

Подробнее о работе со многими аппаратами с одной станции: [Передача потоков на несколько наземных станций](../../guides/multiple-ground-stations.mdx).

## Пауза или удаление привязки {/* #pause-or-remove-a-binding */}

- Выключите **Video** или **Telemetry** в таблице, чтобы остановить этот поток, не теряя привязки и её портов. Делайте это, пока дрон в сети, чтобы он получил изменение.
- Нажмите значок корзины, чтобы удалить привязку. Порты освободятся для следующей привязки к этой наземной станции.

Используйте поле поиска и фильтр **Video Status** (**All Video**, **Video On**, **Video Off**), чтобы найти привязки в большом парке.

## Привязки на странице UAV {/* #bindings-on-the-uav-page */}

На [странице UAV](../fleet/uav-details.mdx#connected-ground-stations) каждого дрона перечислены его наземные станции в разделе **Connected Ground Stations** с теми же переключателями и кнопками **Pause** / **Resume**. Кнопка **Add GCS** там создаёт привязку так же, как **Add Binding** здесь, с ближайшими свободными портами на этой наземной станции.

## Нет потока? {/* #no-stream-arriving */}

См. [Нет телеметрии в наземной станции](../../troubleshooting/no-telemetry-in-gcs.mdx) и [Нет видео в наземной станции](../../troubleshooting/no-video-in-gcs.mdx). Обычные причины: брандмауэр на ноутбуке блокирует входящий UDP, ПО наземной станции слушает не тот порт или поток отключён в привязке.
