# Лицензии и места {/* #licenses-and-seats */}

Fleet Manager входит в вашу лицензию UAVcast-Pro. У него нет собственной подписки, мест или тарифных планов. Какие дроны можно сопрячь, определяют ваши лицензии UAVcast-Pro из [магазина UAVmatrix](https://uavmatrix.com):

- **Дроны:** каждый сопряжённый дрон работает с UAVcast-Pro с активированной лицензией. Каждая активация использует один из **Device Slots** лицензии в магазине («2 of 5 device slots used»). Нужно больше дронов? Купите больше лицензий или слотов. **Fleet → Need more devices? → View Plans** ведёт в магазин.
- **Члены команды:** бесплатно. Fleet Manager не ограничивает число приглашённых, и участникам не нужна собственная лицензия.

## Что проверяет Fleet Manager при сопряжении {/* #what-fleet-manager-checks-when-you-pair */}

Когда вы вводите код сопряжения, Fleet Manager находит лицензию, активированную на этом дроне, и проверяет, что:

1. лицензия существует, активна, не истекла и не возвращена, и
2. её **email владельца** (учётная запись в магазине, на которой она куплена) принадлежит **участнику организации**, в которую вы сопрягаете дрон, с любой ролью.

Если оба условия выполнены, дрон сопрягается. Fleet Manager проверяет всё снова при каждом повторном сопряжении.

| Сообщение в мастере сопряжения | Значение |
|---|---|
| **License is not owned by any member of this organization** | Лицензия принадлежит учётной записи в магазине, email которой не является участником этой организации. |
| **License has expired** | Срок действия лицензии истёк. |
| **License has been refunded** | Лицензия возвращена (оплата возвращена). |
| **Invalid license key** | Магазин не знает лицензию, которая есть на дроне. Проверьте активацию в UAVcast-Pro. |

Лицензия проверяется и раньше, когда UAVcast-Pro запрашивает код сопряжения. Если вместо кода UAVcast-Pro показывает **Invalid or inactive license**, лицензия истекла, возвращена или не привязана к учётной записи в магазине.

Об ошибках активации на самом дроне см. [Активация лицензии](../get-started/license-activation.mdx) и [Лицензия не активируется](../troubleshooting/license-activation-failed.mdx).

## Кто должен владеть лицензиями {/* #who-should-own-the-licenses */}

Fleet Manager сопоставляет лицензии по email, поэтому продумайте, кто покупает:

- **Проще всего:** Owner организации покупает все лицензии с тем email, под которым входит в Fleet Manager.
- **Несколько покупателей:** учитываются лицензии любого участника, включая Viewer. Коллега, который закупает, может быть Viewer.
- **Дроны клиента:** если лицензии купил клиент, пригласите его email из магазина в свою организацию (достаточно роли Viewer).

## Лицензии, купленные на другой email {/* #licenses-bought-with-another-email */}

Типичный случай: лицензии куплены на `purchasing@company.com`, а пилот входит в Fleet Manager как `anna@company.com`. Сопряжение не удаётся с ошибкой **License is not owned by any member of this organization**.

Есть два способа это исправить:

1. **Пригласите email покупателя** в организацию. Этот аккаунт должен один раз войти, чтобы принять приглашение.
2. **Попросите поддержку UAVmatrix добавить дополнительный email** к учётной записи пользователя Fleet Manager. Тогда лицензии, принадлежащие любому из этих email, при сопряжении засчитываются этому пользователю во всех организациях, в которых он состоит.

Чтобы запросить это, откройте обращение через кнопку поддержки (категория **General Inquiry**) или напишите на support@uavmatrix.com с адреса, под которым вы входите, и перечислите другие email, на которые куплены лицензии. См. [Поддержка](./support.mdx).

Полезно знать:

- Email сопоставляются без учёта регистра.
- Каждый дополнительный email может принадлежать только одному пользователю Fleet Manager.
- Добавлять и удалять эти email может только поддержка UAVmatrix. В ваших настройках они не отображаются.
- Лицензии остаются в исходной учётной записи магазина. Меняется лишь то, кого Fleet Manager считает владельцем при сопряжении.

## Перенос лицензий между дронами {/* #moving-licenses-between-drones */}

Лицензия активируется для каждого устройства в UAVcast-Pro, а не в Fleet Manager. Чтобы перенести её, освободите слот устройства в UAVcast-Pro или в магазине, активируйте лицензию на новом дроне и затем [сопрягите новый дрон](./pair-uav.mdx). См. [Замена бортового компаньона](./fleet/remove-or-transfer.mdx#replace-the-companion-computer).
