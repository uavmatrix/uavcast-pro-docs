# Две камеры: переключение по RC и два потока {/* #two-cameras-rc-switching-and-dual-stream */}

UAVcast-Pro работает с двумя камерами, например с передней FPV-камерой и камерой, направленной вниз, или камерой на подвесе. Их можно использовать двумя способами:

- **Переключение**: один поток, а вы выбираете, какая камера его питает, в веб-интерфейсе или с RC-канала на передатчике. Использует пропускную способность и процессор одного потока.
- **Два потока**: обе камеры передают одновременно, каждая на свой порт UDP, у каждой свои разрешение, FPS и битрейт. Использует вдвое больше пропускной способности и процессора.

Поддерживаемые комбинации: CSI + USB, две USB-камеры или две камеры CSI на платах с двумя разъёмами для камер (Raspberry Pi 5, платы-носители Compute Module).

## Добавление второй камеры {/* #add-the-second-camera */}

<Steps>

1. Перейдите в **Камера → Настройки камеры**. Убедитесь, что в **КАМ 1** есть камера.
2. Нажмите **Добавить Камеру** рядом с КАМ 1 и выберите вторую камеру. Она появится в слоте **КАМ 2**.
3. Нажмите на слот, чтобы сделать эту камеру активной (*Нажмите, чтобы переключиться на Камеру 2*).

</Steps>

В режиме переключения обе камеры используют разрешение и частоту кадров Камеры 1 (*Разрешение и FPS Камеры 1 будут использованы*). Если Камера 2 не поддерживает этот размер, она использует собственное разрешение и масштабируется, если только вы не включите **Сопоставить Разрешение Камеры 1** для камеры, которая его поддерживает.

## Переключение камер с передатчика RC {/* #switch-cameras-from-your-rc-transmitter */}

**Переключение по RC Каналу** появляется, когда заданы две камеры и выключен режим двух потоков.

<Steps>

1. На передатчике назначьте двухпозиционный переключатель свободному каналу, например каналу 7. Проверьте в Mission Planner или в **Карта Полёта → Радио**, что канал переключается примерно между 1000 и 2000 µs.
2. В разделе **Переключение по RC Каналу** включите **Включить переключение камеры по RC каналу**.
3. Выберите **RC Канал**.
4. Переключите тумблер и следите за **Текущий PWM**. Значение ниже 1500 выбирает Камеру 1, выше 1500 — Камеру 2.

</Steps>

<Screenshot id="uavcast-pro/camera--control-panel" alt="Панель управления камерой с заполненным слотом КАМ 1 и пустым слотом Добавить Камеру" caption="Слоты камер: КАМ 1 используется, Добавить Камеру — для второй камеры. Переключение по RC Каналу появляется, когда заняты оба слота и выключен режим двух потоков." />

Пока включено переключение по RC, нажатие на слот камеры ничего не делает: управляет передатчик. Выключите переключение по RC, чтобы выбирать камеры вручную.

| Параметр | По умолчанию | Значения | Примечания |
|---|---|---|---|
| **Включить переключение камеры по RC каналу** | Выкл. | Вкл., выкл. | |
| **RC Канал** | Канал 7 | Канал 1–18 | Считывается из входа RC полётного контроллера. |
| Точка переключения | 1500 µs | фиксированная | PWM < 1500 = Камера 1, PWM > 1500 = Камера 2. |

## Одновременная передача с двух камер (два потока) {/* #stream-both-cameras-at-once-dual-stream */}

<Steps>

1. Когда заданы две камеры, включите **Два потока** на странице «Камера». Значок покажет **Оба в эфире**.
2. В разделе **Настройки для каждой камеры** задайте разрешение, FPS и битрейт для каждой камеры.
3. В разделе [Наземные станции](../ground-stations/index.mdx) у каждого пункта назначения появится **Порт видео (Камера 2)**. Оставьте его пустым, чтобы использовать **Порт видео** + 1 (`5601`), или введите другой порт. Если на одном компьютере несколько пунктов назначения, разнесите их порты видео на 3 (`5600`, `5603` и т. д.), чтобы камера 2 и звук не попали на порт другого пункта назначения.
4. Настройте второй приёмник видео на наземной станции для этого порта.

</Steps>

Камера 1 отправляется на **Порт видео** каждой наземной станции (по умолчанию `5600`), Камера 2 — на **Порт видео (Камера 2)** (по умолчанию `5601`).

QGroundControl показывает один видеопоток за раз. Чтобы смотреть Камеру 2, запустите второй приёмник: например, второй экземпляр QGroundControl на порту 5601, Mission Planner с источником GStreamer на 5601 или сам GStreamer:

```bash
gst-launch-1.0 udpsrc port=5601 caps="application/x-rtp, media=(string)video, clock-rate=(int)90000, encoding-name=(string)H264" ! rtph264depay ! avdec_h264 ! videoconvert ! autovideosink sync=false
```

:::warning Следите за процессором и каналом
Два потока удваивают нагрузку на кодирование и пропускную способность. Следите за **Загрузка системы** (*Процессор почти исчерпан. Снизьте разрешение или битрейт потока либо выключите второй поток.*) и держите суммарный битрейт далеко внутри вашего сотового канала. Частое распределение: 1280x720 с 1500 kbps для основной камеры и 854x480 с 600 kbps для второй.
:::

На Карте Полёта отображается одно окно видео для каждого активного потока. Записи могут включать обе камеры: см. **Записывать камеру 2** в разделе [Записи](./recordings.mdx).

## Устранение неполадок {/* #troubleshooting */}

- **Вторая камера отсутствует в списке**: две камеры CSI требуют платы с двумя портами камер. На Raspberry Pi перезагрузите устройство после установки UAVcast-Pro: установщик увеличивает пул памяти камеры (CMA), чтобы две камеры могли работать одновременно.
- **Изображение камеры 2 растянуто**: в режиме переключения Камера 2 масштабируется до разрешения Камеры 1. Используйте камеры с одинаковым соотношением сторон или включите **Сопоставить Разрешение Камеры 1**.
- **Переключение не работает**: проверьте **Текущий PWM**. *Нет сигнала* означает, что полётный контроллер не передаёт входы RC на этом канале.
