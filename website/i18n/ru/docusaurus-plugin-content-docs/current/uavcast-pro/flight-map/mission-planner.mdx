# Вкладка Планировщик Миссий {/* #mission-planner-tab */}

Вкладка Планировщик Миссий позволяет спланировать простую маршрутную миссию прямо в браузере и отправить её на полётный контроллер через UAVcast-Pro из любой точки, где доступен веб-интерфейс. Миссии сохраняются в том же формате `.waypoints` (QGC WPL 110), который используют Mission Planner и QGroundControl, поэтому их можно переносить между программами. Откройте **Карта Полёта → Планировщик Миссий**.

## Планирование миссии {/* #plan-a-mission */}

<Steps>

1. Щёлкните по карте в том месте, где должна находиться первая маршрутная точка. При первом использовании **Установить Значения По Умолчанию** запросит **Высота По Умолчанию (метры)**, **Радиус Маршрутной Точки (метры)** и **Система Отсчёта Высоты**. Нажмите **Continue**.
2. Продолжайте щёлкать, чтобы добавлять маршрутные точки. Перетащите маркер, чтобы переместить его.
3. Настройте каждую точку в таблице: **Выс. (м)**, **Система** и **Радиус (м)**. Удалить точку можно в столбце **Action**.
4. Проверьте значения **Маршрутные Точки** и **Расстояние** для всего маршрута.

</Steps>

| По умолчанию | Значение | Варианты |
|---|---|---|
| **Высота По Умолчанию (метры)** | `100` | любое |
| **Радиус Маршрутной Точки (метры)** | `30` | любое |
| **Система Отсчёта Высоты** | **Относительная** | **Относительная** (над точкой дома), **Абсолютная** (над уровнем моря), **Рельеф** (над землёй, нужны данные о рельефе на полётном контроллере) |

В таблице системы сокращены до **Rel**, **Abs** и **Ter**. Маршрутные точки отправляются как `MAV_CMD_NAV_WAYPOINT`.

## Отправка на полётный контроллер {/* #upload-to-the-flight-controller */}

<Steps>

1. В разделе **Полётный Контроллер** выберите **Отправить**.
2. Подтвердите **Отправить Миссию**. В диалоге предупреждается, что миссия на полётном контроллере будет заменена.
3. Вы увидите сообщение *Миссия отправлена на полётный контроллер.*

</Steps>

- **Читать** загружает миссию, которая находится на полётном контроллере, в планировщик.
- **Очистить** удаляет маршрутные точки из планировщика.

Чтобы выполнить миссию, используйте **Старт** на вкладке **Действия** Карты Полёта или переключитесь в режим AUTO с передатчика или наземной станции.

## Сохранение и загрузка файлов {/* #save-and-load-files */}

В разделе **Файлы**:

- **Сохранить** скачивает миссию как `mission.waypoints`.
- **Загрузить** открывает файл `.waypoints` или `.txt` в формате QGC WPL, например сохранённый в Mission Planner.

## Ограничения {/* #limits */}

Этот планировщик работает только с обычными маршрутными точками. **Загрузить** сохраняет позицию, высоту, систему и радиус каждой строки, но превращает каждую строку в обычную маршрутную точку: команды взлёта, посадки, loiter и DO (срабатывание камеры, сервопривод) не сохраняются, а команда без позиции становится маршрутной точкой с координатами 0, 0. Для команд взлёта и посадки, DO-команд, сеток съёмки, геозаборов и точек сбора планируйте и отправляйте миссию напрямую в Mission Planner или QGroundControl.
