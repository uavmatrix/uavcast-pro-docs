# Сети {/* #networks */}

На странице **Сети** показаны все сетевые интерфейсы дрона (Ethernet, Wi-Fi, модем, VPN) и интерфейс, который является маршрутом по умолчанию. Здесь же выбирается, какой интерфейс предпочтителен, Wi-Fi или сотовый модем, когда подключены оба. Откройте **Сети** на боковой панели.

## Выбор приоритета сети {/* #choose-the-network-priority */}

Когда подключены Wi-Fi и модем, Linux отправляет трафик через тот интерфейс, у которого меньше метрика маршрута. **Приоритет сети** задаёт эти метрики за вас:

| Вариант | Когда использовать | Эффект |
|---|---|---|
| **Приоритет WiFi (Режим в помещении)** | На стенде или дома, чтобы экономить мобильный трафик. | Метрика Wi-Fi 100, метрика модема 600. |
| **Приоритет модема (Режим на улице)** | Перед каждым полётом по сотовой связи. | Метрика модема 100, метрика Wi-Fi 600. |
| **Автоматически (Системный по умолчанию)** | Вы не хотите, чтобы UAVcast-Pro что-либо менял. | Собственные метрики NetworkManager. |

:::warning Переключитесь на Приоритет модема перед взлётом
Если дрон взлетает с приоритетом Wi-Fi, связь остаётся на Wi-Fi, пока Wi-Fi не потеряется, и только тогда переключается на модем в воздухе. Из-за этого возникает разрыв в телеметрии и видео. Выберите **Приоритет модема (Режим на улице)** на земле.
:::

Изменение применяется к активным подключениям без их перезапуска (*Применение изменений...*).

:::note Какие подключения меняются
Метрика Wi-Fi задаётся для подключения NetworkManager с именем `preconfigured`. Это имя, которое Raspberry Pi Imager присваивает Wi-Fi, введённому при записи образа. Wi-Fi, настроенный иначе, сохраняет собственную метрику, а Ethernet никогда не изменяется.
:::

## Информация об интерфейсах {/* #interface-information */}

В карточках сводки показаны **Активные интерфейсы**, **Шлюз по умолчанию** (и интерфейс, через который он проходит) и **Всего интерфейсов**. В разделе **Сетевые интерфейсы** перечислен каждый интерфейс с **Именем**, **IP-адресом**, **Шлюзом**, **Статусом** (**Активен**, **Неактивен**, **VPN**), **Скоростью**, **Типом** и отметкой, какой из них **По умолчанию**.

Распространённые имена интерфейсов:

| Имя | Что это |
|---|---|
| `eth0`, `end0` | Проводной Ethernet |
| `wlan0` | Wi-Fi |
| `ppp0`, `wwan0` | Традиционный модем |
| `usb0`, `eth1` | Модем HiLink |
| `zt…` | ZeroTier |
| `tailscale0` | Tailscale |
