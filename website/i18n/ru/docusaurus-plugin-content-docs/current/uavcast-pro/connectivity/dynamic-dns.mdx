# Динамический DNS {/* #dynamic-dns */}

Динамический DNS направляет имя хоста, например `mydrone.ddns.net`, на текущий публичный IP-адрес дрона. UAVcast-Pro проверяет публичный IP каждые 5 минут и обновляет вашего провайдера DNS, когда он меняется. Откройте **Динамический DNS** на боковой панели.

:::note В большинстве сотовых сетей вместо этого нужен VPN
Динамический DNS помогает, только если публичный IP-адрес дрона может принимать входящие подключения. Большинство мобильных операторов ставят SIM-карты за NAT оператора, поэтому публичный IP принадлежит оператору, а не дрону. Используйте [VPN](./vpn.mdx), если только ваша SIM-карта не имеет публичного (часто «статического» или «M2M») IP-адреса.
:::

Динамический DNS не меняет адреса, на которые UAVcast-Pro отправляет телеметрию и видео: они всегда идут на IP-адреса из раздела [Наземные станции](../ground-stations/index.mdx). Он нужен для доступа к веб-интерфейсу или SSH дрона извне.

## Настройка {/* #set-it-up */}

<Steps>

1. Создайте имя хоста у вашего провайдера DNS (No-IP, DynDNS или DuckDNS).
2. В UAVcast-Pro перейдите в **Динамический DNS**. Установите **Включить динамический DNS?** в значение **Да**.
3. Выберите **Система DNS**.
4. Введите имя пользователя вашей учётной записи (поле называется **Конфигурация динамического DNS**), **Пароль** и имя хоста в поле **Псевдоним**. Для DuckDNS введите токен в поле имени пользователя, а в поле **Пароль** — любое значение (форма его требует, DuckDNS его игнорирует). Поля сохраняются при переходе к следующему.
5. Нажмите **Подключить**, чтобы запустить обновление. Текущий IP отправляется сразу, затем проверка выполняется каждые 5 минут. **Отключить** останавливает обновление.

</Steps>

## Справочник настроек {/* #settings-reference */}

| Параметр | По умолчанию | Значения | Примечания |
|---|---|---|---|
| **Включить динамический DNS?** | **Нет** | **Да**, **Нет** | |
| **Система DNS** | **No-IP** | **No-IP**, **DynDNS**, **DuckDNS**, **Общий** | |
| **URL DNS** | пусто | URL обновления | Только для **Общий**. URL обновления, совместимый с DynDNS, из документации провайдера. |
| **Конфигурация динамического DNS** (имя пользователя) | пусто | | Имя пользователя вашей учётной записи DNS или токен для DuckDNS. Интерфейс подписывает это поле не совсем точно; это имя пользователя. |
| **Пароль** | пусто | | Пароль вашей учётной записи DNS. Обязателен в форме; для DuckDNS игнорируется. |
| **Псевдоним** | пусто | имя хоста | Имя хоста для обновления, например `mydrone.ddns.net`. |
| Интервал обновления | 5 минут | фиксированный | |

Строка **Динамический DNS** на [Панели управления](../dashboard.mdx) показывает, работает ли обновление. В **Журнале действий** отображается каждое обновление и ответ провайдера.
