# 設定參考 {/* #settings-reference */}

依頁面分類列出 UAVcast-Pro 網頁介面中的每一項設定，標籤與應用程式顯示的完全相同，並附上全新安裝時的預設值。會即時套用設定的頁面，除非另有說明，都會立即生效。功能頁面會詳細說明各區域；本頁則方便查詢。

## 飛行控制器 → 連線 {/* #flight-controller--connection */}

| 設定 | 預設值 | 值與備註 |
|---|---|---|
| **Link enabled** | 開啟 | 開啟或關閉飛行控制器連線。 |
| **Link type** | **USB** | **USB**（飛行控制器本身的 USB 連接埠）或 **UART / Serial**（GPIO 腳位上的 TELEM 連接埠，或 USB 序列轉接線）。 |
| **Port** | **Automatic** | Automatic 會找到飛行控制器，並在裝置編號變更時跟隨。**Custom path…** 可輸入裝置路徑，例如 `/dev/ttyAMA0`。 |
| **Baud rate** | **Automatic** | 必須與飛行控制器上的 `SERIALx_BAUD` 相符。Automatic 會依序嘗試 57600、115200、921600、1500000、460800、230400 與 500000。USB 不使用此設定。 |

按鈕：**Auto-detect**（掃描所有連接埠與傳輸速率，並儲存結果）、**連接**、**Restart link**、**停止**。變更會立即套用，無需重新啟動。

## 飛行控制器 → NTRIP / RTK {/* #flight-controller--ntrip--rtk */}

| 設定 | 預設值 | 值與備註 |
|---|---|---|
| **啟用 NTRIP 用戶端** | 關閉 | |
| **Caster 主機** | 空白 | NTRIP Caster 的主機名稱。 |
| **連接埠** | `2101` | 部分 TLS Caster 使用 2102 或 443。 |
| **掛載點** | 空白 | 可透過 **瀏覽掛載點** 選擇。 |
| **使用 TLS（HTTPS）** | 關閉 | 適用於要求 TLS 的 Caster。 |
| **Username** ／ **Password** | 空白 | rtk2go.com：以電子郵件地址作為使用者名稱，無須密碼。 |
| **上行傳送 GGA** | 開啟 | VRS 與最近掛載點型 Caster 需要此設定。 |
| **傳送間隔（秒）** | `10` | |
| **位置來源** | **來自飛控的即時位置** | 或 **固定的手動位置**（**Latitude**、**Longitude**、**高度（公尺）**），在取得第一次 GPS 定位前也會作為備用。 |

## 飛行控制器 → 注入器 {/* #flight-controller--injectors */}

| 設定 | 預設值 | 值與備註 |
|---|---|---|
| **Input type** | | **HTTP**、**UDP** 或 **Serial**。建立後無法變更。 |
| **MAVLink sysid** | `1` | 與飛行控制器相同。 |
| **MAVLink compid** | `194` | 使用者酬載。 |
| **Name prefix** | 空白 | 最多 8 個 ASCII 字元，會加在每個訊號名稱之前。 |
| **Rate limit (Hz per signal)** | | 每個訊號名稱每秒最多的取樣數。 |
| **Protocol**（UDP、Serial） | | **Key=Value（逐行）** 或 **JSON**（`{name, value}`）。 |
| **Port** ／ **Bind address**（UDP） | | 選擇未使用的連接埠，例如 14600。`0.0.0.0` 表示所有介面，`127.0.0.1` 表示僅限本機。 |
| **Device path** ／ **Baud rate**（Serial） | | 例如 `/dev/ttyUSB0`；傳輸速率必須與傳送端相符。 |

## 地面控制站 {/* #ground-control-stations */}

每個目標位址各有一張卡片。

| 設定 | 新目標位址的預設值 | 值與備註 |
|---|---|---|
| **名稱** | 空白 | 最多 50 個字元。 |
| **目標IP或主機** | 空白 | IPv4 位址。必須先填寫，才能開啟視訊或遙測。 |
| **遙測連接埠** | `14550` | 1–65535。 |
| **視訊連接埠** | `5600` | 1–65535。 |
| **視訊連接埠（攝影機 2）** | 空白（= 視訊連接埠 + 1） | 僅在 **雙路視訊串流** 開啟時顯示。 |
| **啟用終端** | 開啟 | 關閉後，所有傳送至此目標位址的內容都會停止：遙測、視訊與音訊。 |
| **啟用視訊** | **關閉** | |
| **啟用遙測** | **關閉** | |
| **Read Only** | 關閉 | 地面站可接收遙測，但無法變更飛行器上的任何內容。此行為自 UAVcast-Pro 6.5.3 起適用；在較早的版本中，Read Only 不會阻擋參數寫入。 |

## 攝影機 → 攝影機設定 {/* #camera--camera-settings */}

| 設定 | 預設值 | 值與備註 |
|---|---|---|
| **啟用攝影機？** | 是 | |
| **選擇攝影機** | Raspberry Pi 攝影機 | 已偵測到的 CSI 與 USB 攝影機。 |
| **解析度** | 640×480 | 僅提供攝影機支援的尺寸。 |
| **選擇幀率** | **自動** | 由攝影機自動協商。 |
| **位元率：** | `0`（自動） | 0–10000 kbps。 |
| **串流恢復速率** | **自動** | 關鍵影格間隔。自動 = 每秒一個關鍵影格。較快的等級可更快從封包遺失中恢復，但會佔用更多頻寬。 |
| **旋轉：** ／ **翻轉設定** | 0°，不翻轉 | **水平翻轉**、**垂直翻轉**。 |
| **啟用即時預覽？** | 是 | 於本頁及飛行地圖中顯示預覽。 |
| **自訂管道** | 測試管道 | 會覆寫地面控制站的目標位址。請省略 `gst-launch-1.0` 前綴。 |
| **啟用 RC 通道攝影機切換** | 關閉 | |
| **RC 通道** | 7 | PWM < 1500 = 攝影機 1，PWM > 1500 = 攝影機 2。 |
| **匹配攝影機 1 解析度** | 關閉 | 攝影機 2 以攝影機 1 的解析度擷取。 |
| **雙路視訊串流** | 關閉 | 同時串流兩台攝影機。 |
| **音訊** | 關閉 | 預覽中的 Opus 音訊。 |
| **音訊裝置** | **Auto (camera microphone if present)** | 或擷取裝置，或 **Test tone (no microphone needed)**。 |
| **位元率**（音訊） | 64 kbps | |
| **傳送音訊到地面站** | 關閉 | 以 RTP/Opus 傳送至每個視訊目標位址的視訊連接埠 + 2。 |

## 攝影機 → 錄製 → 設定 {/* #camera--recordings--settings */}

| 設定 | 預設值 | 值與備註 |
|---|---|---|
| **儲存位置** | **內部儲存空間** | USB 隨身碟或 SSD，或 **或其他資料夾**。 |
| **保留空間** | 2 GB | 0.5–1000 GB。 |
| **空間不足時刪除最舊的錄製** | 開啟 | 關閉時，磁碟寫滿即停止錄製。 |
| **刪除超過以下天數的錄製** | 0 天 | 0 表示保留，直到需要空間時再刪除。 |
| **解鎖時自動錄製** | 開啟 | |
| **錄製攝影機 1** ／ **錄製攝影機 2** | 開啟 ／ 開啟 | 攝影機 2 僅在雙路視訊串流時可用。 |
| **檔案長度** | 1 分鐘 | 每個檔案 1–30 分鐘。 |
| **錄製遙測** | **解鎖時** | **連線期間始終** 或 **關閉**。 |
