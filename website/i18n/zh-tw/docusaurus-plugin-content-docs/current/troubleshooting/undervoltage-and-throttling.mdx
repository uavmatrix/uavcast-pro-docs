# 欠壓與 CPU 降速 {/* #undervoltage-and-throttling */}

儀表板的**電源供應**列顯示警告、數據機中斷、飛行控制器連線重置，或 Pi 在飛行中重新開機。在無人機上，電源供應器容量不足所造成的怪異故障，比任何軟體設定都還要多。

<Screenshot id="uavcast-pro/dashboard--status-card" alt="儀表板狀態卡，系統區段下的電源供應列顯示穩定" caption="儀表板 → 狀態卡。電源供應列位於系統區段下；此處顯示**穩定**。出現警告時，該文字會被取代，如下表所列。" />

| 電源供應列 | 意義 |
|---|---|
| **穩定** | 自開機以來未發生欠壓或降速 |
| **電壓過低，請使用更強的電源供應器** | 目前的供應電壓低於 Pi 所需 |
| **開機後曾發生電壓下降** | 此情況先前已發生，例如數據機連線時或馬達啟動時 |
| **已降速（過熱或電源不足）** | CPU 為了保護自身免於過熱或電壓不足，而降低執行速度 |

這些讀數來自 Raspberry Pi 韌體，因此僅能在 Raspberry Pi 上取得。

## 檢查 1：為所有負載配置足夠的電源 {/* #check-1 */}

Pi 透過其 USB 連接埠為數據機與 USB 攝影機供電。4G 數據機在連線時以及訊號微弱時，會抽取峰值電流。

<Steps>

1. 使用額定容量遠高於 Pi、數據機、攝影機以及同一供電線路上所有其他負載總電流的 5 V BEC 或穩壓器。Raspberry Pi 官方的電源規格列出了各機型的需求。
2. 切勿從飛行控制器的 TELEM 或 USB 連接埠為 Pi 供電。
3. 若數據機抽取的電流超過 Pi 所能傳遞的電流，請改由穩壓器直接為數據機供電，透過有外接電源的 USB 集線器，或使用另有電源的 USB 線。

</Steps>

## 檢查 2：線材與接頭 {/* #check-2 */}

細或長的線材在負載下會損失電壓。請為電源線使用短而粗的導線，並為數據機使用品質良好的 USB 線。適用於手機充電器的線材，在峰值電流下仍可能造成欠壓。

## 檢查 3：散熱 {/* #check-3 */}

**系統資訊**下的**溫度**顯示 CPU 溫度。在陽光下、密閉機身內執行影片編碼的 Pi 會變得很燙。請加裝散熱片或小型風扇，並為機殼提供通風。Pi 5 在持續編碼時需要主動散熱。

## 檢查 4：修正後確認 {/* #check-4 */}

**開機後曾發生電壓下降**會持續到下次開機為止。請重新開機，在台架上執行一次典型任務（數據機已連線、攝影機串流中），並確認該列維持為**穩定**。

## 仍然看到警告？ {/* #still-seeing-warnings */}

日誌下載內含 `diagnostics.txt`，其中有來自核心的電源與 USB 事件。請[下載日誌](./collect-logs.mdx)，並附上您電源配線的照片，寄送至 **support@uavmatrix.com**。
