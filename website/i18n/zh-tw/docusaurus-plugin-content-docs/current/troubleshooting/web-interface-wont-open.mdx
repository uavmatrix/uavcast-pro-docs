# 網頁介面無法開啟 {/* #web-interface-wont-open */}

安裝程式已完成，但 `http://<device-ip>/` 逾時、連線遭拒，或顯示其他程式的頁面。

<SymptomTable rows={[
  {symptom: '逾時，或頁面始終無法載入', cause: '位址錯誤，或您的電腦位於另一個網路', start: '#check-1'},
  {symptom: '連線遭拒', cause: '網頁服務未執行', start: '#check-2'},
  {symptom: '出現其他網頁，例如 nginx 或 Apache', cause: '其他程式正在使用連接埠 80', start: '#check-3'},
  {symptom: '先前正常，變更設定後停止', cause: '伺服器連接埠已變更', start: '#check-4'},
  {symptom: '頁面可載入，但每個頁面都會跳到應用程式', cause: '尚未啟用授權', start: '#check-5'},
]} />

## 檢查 1：使用正確的位址 {/* #check-1 */}

網頁介面預設使用**連接埠 80**，因此位址就是 `http://<device-ip>/`。

<Steps>

1. 找到裝置 IP。安裝程式會在結束時印出它。您也可以在裝置上執行 `hostname -I`。
2. 在使用預設主機名稱的 Raspberry Pi 上，請嘗試 `http://raspberrypi.local/`。
3. 請使用 `http://`，而非 `https://`。網頁介面不提供 HTTPS。
4. 請確認您的電腦與裝置位於同一個網路，或同一個 VPN。透過 4G 時，您必須使用無人機的 VPN 位址。

</Steps>

## 檢查 2：網頁服務是否正在執行？ {/* #check-2 */}

在裝置上執行：

```bash
sudo systemctl status uavcast-web
```

應顯示 **active (running)**。若沒有，請啟動它並查看停止的原因：

```bash
sudo systemctl restart uavcast-web
journalctl -u uavcast-web --since "1 hour ago"
```

網頁介面也需要背景服務。請以相同方式檢查：`uavcast-factory`、`mavlink-manager`、`uavcast-camera` 與 `redis-server`。完整清單請見[服務與檔案](../reference/services-and-files.mdx)。

## 檢查 3：連接埠 80 已被使用 {/* #check-3 */}

若裝置上安裝了另一個網頁伺服器，它可能佔用了連接埠 80。請找出是哪個程式在監聽：

```bash
sudo ss -ltnp | grep ':80 '
```

請停止並停用另一個伺服器（例如：`sudo systemctl disable --now nginx`），然後重新啟動 `uavcast-web`。

## 檢查 4：伺服器連接埠已變更 {/* #check-4 */}

**應用程式 → 設定 → 伺服器連接埠**會將網頁介面移到其他連接埠，此時位址會變為 `http://<device-ip>:<port>/`。若您忘記了連接埠，請在裝置上讀取：

```bash
grep SERVER_PORT /etc/systemd/system/uavcast-web.service
```

## 檢查 5：每個頁面都跳到應用程式 {/* #check-5 */}

在裝置上啟用授權之前，這是預期的行為。請在**應用程式 → 許可證管理器**中啟用授權。若失敗，請參閱 [UAVcast-Pro 授權無法啟用](./license-activation-failed.mdx)。

## 檢查 6：安裝程式未完成 {/* #check-6 */}

若 `uavcast-web` 不存在（`Unit uavcast-web.service could not be found`），表示安裝提前中止。請參閱 [UAVcast-Pro 安裝失敗](./installation-fails.mdx)。

## 仍然無法解決？ {/* #still-no-luck */}

請將 `systemctl status uavcast-web` 與 `journalctl -u uavcast-web --since yesterday` 的輸出，以及 `/opt/uavcast-pro/installer.log`，寄送至 **support@uavmatrix.com**。
