# 應用程式設定、日誌與備份 {/* #application-settings-logs-and-backups */}

**應用程式**頁面包含 UAVcast-Pro 本身的所有設定：授權、更新、介面設定、日誌下載與設定資料庫。此頁面僅限管理員檢視，也是唯一在裝置取得授權之前即可使用的頁面。請開啟 **Management → 應用程式**。

## 設定 {/* #settings */}

| 設定項目 | 預設值 | 可選值 | 說明 |
|---|---|---|---|
| **功能導覽** | | | 重新開始介面的引導導覽。 |
| **深色主題** | 開啟 | 開啟、關閉 | 依瀏覽器儲存。也可以在頂端列的主題切換按鈕中設定。 |
| **伺服器連接埠** | `80` | 1–65535 | 網頁介面的連接埠。請參閱下方說明。 |
| **語言** | 瀏覽器語言，否則為英文 | English, Español, 简体中文, 繁體中文, Italiano, Nederlands, Polski, Português, Русский, Türkçe | 也可以在側邊欄底部的使用者選單中設定。 |

### 變更網頁介面連接埠 {/* #change-the-web-interface-port */}

<Steps>

1. 在 **伺服器連接埠** 中輸入新的連接埠。
2. 點擊 **提交並重啟伺服器**。對話框會顯示 **新URL**，例如 `http://192.168.1.50:8080`。
3. 等待數秒後，開啟新的 URL。

</Steps>

舊位址的書籤與連結將無法使用。變更連接埠後，會顯示警告 *伺服器連接埠已從預設的 80 號連接埠變更。* 從 UAVcast-Pro 6.5.3 起，更新時會保留此連接埠設定；較早的版本會將其重設為 80。

## 日誌 {/* #logging */}

UAVcast-Pro 會分別記錄每一項服務的日誌。發生問題時，請下載日誌並傳送給技術支援。

<Steps>

1. 開啟 **偵錯模式**以取得更多細節，然後重現問題。
2. 在 **選擇要下載的日誌** 中，保留 **所有日誌**，或選擇單一服務。
3. 在 **選擇時間範圍** 中，選擇涵蓋問題發生時段的範圍（從 **最近10分鐘** 到 **所有時間**）。
4. 點擊 **下載**。您會取得一個 zip 檔案。
5. 將檔案寄送至 support@uavmatrix.com，並附上簡短的問題描述。完成後請關閉 **偵錯模式**。

</Steps>

下載的檔案包含 `diagnostics.txt` 快照（設定、序列埠、電源與 USB 事件），有助於技術支援更快找出問題。

| 日誌 | 涵蓋範圍 |
|---|---|
| **Mavlink Manager**、**Mavlink Publisher** | 飛行控制器連線，以及路由至地面站 |
| **Camera Server**、**Camera Detector** | 視訊管道、攝影機偵測 |
| **Modem Manager**、**Modem Detector** | 數據機連線、APN 嘗試 |
| **VPN Manager** | ZeroTier 與 Tailscale |
| **NTRIP Client** | RTK 校正 |
| **DNS Manager** | 動態 DNS 更新 |
| **License Manager** | 啟動，以及每 4 小時一次的授權檢查 |
| **Application Updater**、**Application Installer** | 更新與安裝 |
| **Backend API Server** | 內部 API |

**清除所有日誌**會刪除所有日誌檔案，且無法復原。若您希望在重現問題前取得乾淨的日誌，請先執行此操作。在無人機上，日誌位於 `/opt/uavcast-pro/logs`。

每個頁面也都有 **操作日誌** 主控台，會顯示該頁面對應服務的即時日誌。

## 資料庫 {/* #database */}

所有設定（地面站、飛行控制器、攝影機、數據機、VPN、NTRIP、使用者、儀表板、注入器及授權資料）都儲存在同一個 SQLite 資料庫中，位於 `/opt/uavcast-pro/uavcast.db`。

| 操作 | 功能 |
|---|---|
| **備份資料庫** | 將資料庫下載為 `uavcast_backup.db`。 |
| **恢復資料庫** | 上傳 `.db` 備份檔，並取代目前的設定（包括使用者）。 |
| **重設資料庫** | 將地面站、飛行控制器、攝影機、VPN 與動態 DNS 設定重設為預設值。使用者、授權、數據機、NTRIP、錄製設定、儀表板、注入器以及 Fleet Manager 配對會保留。此操作無法復原。 |

變更前可使用備份來保留已知良好的設定，或用於以相同方式設定第二架無人機。還原後請重新開機，讓所有服務以還原後的設定啟動。

:::note 在不同硬體上還原
資料庫中的授權資料與產生它的裝置綁定。在其他 Raspberry Pi 或 SD 卡上還原備份後，請在新裝置上啟用授權。還原也會匯入備份中的使用者與密碼。
:::
