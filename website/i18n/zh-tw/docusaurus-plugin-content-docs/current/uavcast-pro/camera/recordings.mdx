# 錄製與飛行回放 {/* #recordings-and-flight-review */}

UAVcast-Pro 會在無人機本身錄製每次飛行：攝影機視訊與 MAVLink 遙測記錄（`.tlog`）。錄製會使用已編碼完成的串流，因此不會增加 CPU 負擔，也不會中斷傳送至地面站的即時視訊。由於檔案寫入於無人機上，即使行動網路連線中斷，您仍能取得全品質的視訊。錄製會在解鎖時自動開始，或從飛行地圖手動開始。需要 v6.5.1 或更新版本。

請開啟 **攝影機 → 錄製**。此頁面有兩個分頁：**錄製庫** 與 **設定**。

<Screenshot id="uavcast-pro/camera--recordings" alt="錄製庫，包含儲存空間列與兩筆飛行紀錄，顯示時長以及攝影機 1 與遙測標籤" caption="攝影機 → 錄製 → 錄製庫，顯示兩筆飛行紀錄。" />

## 解鎖時自動錄製 {/* #record-automatically-when-armed */}

此功能預設為開啟。馬達解鎖時開始錄製，上鎖時停止。若飛行中連線中斷，錄製會繼續進行。

依賴此功能之前，請注意：

- 請在飛行地圖或 **設定** 中，檢查 **錄製儲存空間** 的可用空間。
- 錄製不需要開啟 **啟用即時預覽？**。開啟錄製時，即使預覽已關閉，攝影機仍會在內建媒體伺服器中保留一份串流副本。

## 手動錄製 {/* #record-by-hand */}

飛行地圖的頂端列中有 **錄製** 群組：**攝影機 1**（雙路串流時還會有 **攝影機 2**）用於啟動與停止視訊，**遙測** 用於啟動與停止遙測記錄。紅點表示正在錄製的項目。唯讀使用者無法開始錄製。

## 儲存設定 {/* #storage-settings */}

請開啟 **攝影機 → 錄製 → 設定**。

| 設定 | 預設值 | 可選值 | 說明 |
|---|---|---|---|
| **儲存位置** | **內部儲存空間** | 內部儲存空間、偵測到的 USB 隨身碟或 SSD、**或其他資料夾** | 插入磁碟後，選擇 **重新尋找磁碟** 即可看到該磁碟。內部儲存空間位於 `/opt/uavcast-pro/recordings/video`。 |
| **保留空間** | `2` GB | 0.5–1000 GB | 錄製不會讓磁碟用量超過此值。系統本身也需要保留空間。 |
| **空間不足時刪除最舊的錄製** | 開啟 | 開啟、關閉 | 類似行車記錄器：錄製不會因空間不足而停止。關閉時，則改為停止錄製。 |
| **刪除超過以下天數的錄製** | `0` 天 | 0–3650 天 | `0` 表示保留錄製，直到需要空間時才刪除。 |
| **解鎖時自動錄製** | 開啟 | 開啟、關閉 | |
| **錄製攝影機 1** | 開啟 | 開啟、關閉 | 適用於自動錄製。 |
| **錄製攝影機 2** | 開啟 | 開啟、關閉 | 僅在開啟雙路視訊串流時適用。 |
| **檔案長度** | `1` 分鐘 | 1–30 分鐘 | 視訊會依此長度分段儲存。片段越短，斷電時遺失的內容越少。 |
| **錄製遙測** | **解鎖時** | **解鎖時**、**連線期間始終**、**關閉** | 與視訊並列顯示的 `.tlog`。**連線期間始終** 也會在地面上記錄，並在每次解鎖、上鎖及每小時建立新檔案。 |

<Screenshot id="uavcast-pro/camera--recordings-settings" alt="錄製設定，已選擇內部儲存空間，保留空間為 2 GB，並開啟空間不足時刪除最舊的錄製與解鎖時自動錄製" caption="已選擇內部儲存空間，並啟用解鎖時自動錄製。" />

:::tip 錄製至 USB SSD
對於連續視訊錄製，USB 3 SSD 比 microSD 卡更快、更耐用。插入後選擇 **重新尋找磁碟**，再於 **儲存位置** 下選擇它。
:::

## 檔案與格式 {/* #files-and-formats */}

- 視訊會寫成分段的 fragmented MP4，即使飛行中斷電，已寫入的部分仍可播放。下載的檔案為 MP4。
- 遙測為標準的 MAVLink `.tlog`，可在 Mission Planner、MAVExplorer、UAV Log Viewer 及[飛行分析](../flight-map/flight-analytics.mdx)中讀取。
- 錄製庫中，只要檔案之間的間隔不超過 15 秒，就會視為同一段錄製。

## 回顧飛行過程 {/* #review-a-flight */}

在錄製項目上選擇 **播放**，即可開啟 **飛行回放**：視訊、地圖軌跡、駕駛艙視角與飛行資料都會顯示在同一個時間軸上。

- 時間軸會標示 **已解鎖**、**已上鎖**，以及飛行模式的變更。
- 提供 **倒退 10 秒**、**播放**／**暫停**、**前進 10 秒**，以及 **播放速度**（0.5× 至 4×）。
- 有兩台攝影機時，**變更視訊版面** 可在 **子母畫面** 與 **並排** 之間切換；**放大此攝影機** 則可交換兩者。
- 資料面板會顯示目前時間點的 **高度**、**速度**、**電池**、**衛星** 與 **模式**。
- **下載** 可將片段儲存為 MP4。

<Screenshot id="uavcast-pro/camera--flight-review" alt="飛行回放播放器，包含視訊區域、地圖軌跡、駕駛艙視角，以及附播放控制的時間軸" caption="飛行回放：視訊、地圖、駕駛艙與遙測資料位於同一個時間軸上。" />

若播放器顯示 *此錄製沒有遙測記錄*，表示錄製時未記錄遙測（預設只在解鎖期間記錄）。

## 刪除錄製 {/* #delete-recordings */}

在錄製項目上點擊 **刪除**。若該錄製包含遙測記錄，您可以選擇 **僅刪除影片** 或 **刪除影片和遙測**。刪除為永久性操作。仍在錄製中的項目必須先停止。
