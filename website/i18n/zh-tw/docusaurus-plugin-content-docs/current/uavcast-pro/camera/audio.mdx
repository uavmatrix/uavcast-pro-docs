# 音訊 {/* #audio */}

UAVcast-Pro 可以加入 USB 麥克風或 USB 攝影機內建麥克風的聲音。音訊會以 Opus 編碼，CPU 與頻寬用量都很低。音訊一律會在即時預覽中播放，您也可以將其以獨立的 RTP 串流傳送至地面站。請在 **攝影機 → 攝影機設定** 中的 **音訊** 卡片找到此功能。

## 開啟音訊 {/* #turn-on-audio */}

<Steps>

1. 插入 USB 麥克風，或使用內建麥克風的網路攝影機。
2. 在 **攝影機 → 攝影機設定** 中，開啟 **音訊**。
3. 將 **音訊裝置** 保留為 **自動（如有攝影機麥克風）**，或選擇特定裝置。若要在沒有麥克風的情況下測試音訊路徑，請使用 **測試音（無需麥克風）**。
4. 觀察狀態指示燈。若顯示 **音訊直播中** 且音量指示條會移動，表示已擷取到聲音。
5. 在 **即時預覽** 中取消播放器的靜音。瀏覽器預設會以靜音方式開始預覽。

</Steps>

<Screenshot id="uavcast-pro/camera--audio" alt="攝影機頁面的音訊卡片，音訊開關為關閉，狀態顯示為音訊關閉" caption="攝影機 → 音訊，目前為關閉狀態。開啟後即可選擇麥克風與位元率。" />

麥克風故障時不會中斷視訊。指示燈會改為顯示 **音訊錯誤** 與原因。

## 將音訊傳送至地面站 {/* #send-audio-to-ground-stations */}

開啟 **傳送音訊到地面站**。UAVcast-Pro 接著會將獨立的 RTP/Opus 串流，傳送給每個接收視訊的地面站，連接埠為該目標的 **視訊連接埠 + 2**。使用預設視訊連接埠時，即為 `5602`。若兩個目標位於同一台電腦上，其視訊連接埠至少需相隔 3，例如 `5600` 與 `5603`。

QGroundControl 與 Mission Planner 會忽略音訊。請使用 GStreamer 播放：

```bash title="在地面站上"
gst-launch-1.0 udpsrc port=5602 caps="application/x-rtp, media=(string)audio, clock-rate=(int)48000, encoding-name=(string)OPUS, payload=(int)97" ! rtpopusdepay ! opusdec ! audioconvert ! autoaudiosink
```

此串流為 48 kHz 的 Opus，RTP 酬載類型（payload type）為 97。VLC 可以透過描述上述參數的 SDP 檔案播放此串流。

## 設定參考 {/* #settings-reference */}

| 設定 | 預設值 | 可選值 | 說明 |
|---|---|---|---|
| **音訊** | 關閉 | 開啟、關閉 | 變更任何音訊設定都會重新啟動攝影機服務。 |
| **音訊裝置** | **自動（如有攝影機麥克風）** | 自動、已偵測到的擷取裝置、**測試音（無需麥克風）** | 已儲存但已拔除的裝置會顯示為 *（未連接）*。 |
| **位元率** | `64 kbps` | 24、32、48、64、96、128 kbps | 32–64 kbps 足以涵蓋語音與引擎噪音。 |
| **傳送音訊到地面站** | 關閉 | 開啟、關閉 | 以 RTP/Opus 傳送至每個已啟用視訊之目標的視訊連接埠 + 2。 |

## 故障排除 {/* #troubleshooting */}

- *找不到音訊擷取裝置*：請插入 USB 麥克風，或內建麥克風的攝影機。在無人機上，執行 `arecord -l` 可列出擷取裝置。
- **無訊號**：裝置已開啟但沒有聲音。請檢查麥克風的靜音開關，或嘗試 **測試音**。
- 預覽中有音訊，但地面站沒有：請確認 **傳送音訊到地面站** 已開啟、該目標已開啟 **啟用視訊**，且接收端正在監聽視訊連接埠 + 2。
