# 行動數據機（4G/LTE） {/* #cellular-modem-4glte */}

4G/LTE 數據機可讓無人機在任何有行動網路覆蓋的地方連上網路，使遙測與視訊能夠傳送到超出 Wi-Fi 範圍的地面站。UAVcast-Pro 支援 **HiLink** 數據機（可自行連線），以及 **傳統型（PPP）** 數據機（UAVcast-Pro 透過 ModemManager 連線）。對於傳統型數據機，它會自動找到 APN、在開機時連線，並在斷線後重新連線。請在側邊欄中開啟 **數據機**。

## 我的數據機是哪一種？ {/* #which-type-is-my-modem */}

| | HiLink | 傳統型（PPP） |
|---|---|---|
| 顯示方式 | 網路卡（`usb0` 或 `eth1`）。數據機會運行自己的路由器與網頁，通常位於 `192.168.8.1`。 | 由 ModemManager 管理的數據機裝置。連線通常顯示為 `ppp0` 或 `wwan0`。 |
| 由誰連線 | 數據機本身。 | UAVcast-Pro，透過 ModemManager 與 NetworkManager。 |
| UAVcast-Pro 中的設定 | 無。如有需要，請在數據機自己的網頁中設定 APN。 | APN（選用）、使用者名稱、密碼、PIN。 |
| 範例 | Huawei E3372h、E8372 | Huawei E3372s、Quectel EC25 / EG25、Sierra Wireless |

不確定時，請插入數據機，並在無人機上執行 `mmcli -L`。若 ModemManager 有列出該數據機，請選擇 **傳統型（PPP）**。若沒有列出，但 **網路** 中出現新的網路介面，則為 HiLink。

## 設定傳統型數據機 {/* #set-up-a-traditional-modem */}

<Steps>

1. 插入資料用 SIM 卡，並將數據機接到伴隨電腦上。
2. 前往 **數據機**。將 **啟用數據機** 設為 **是**，並將 **數據機類型** 設為 **傳統型（PPP）**。
3. 將 **存取點名稱 (可選)** 留空，UAVcast-Pro 會自動偵測。
4. 若您的 SIM 卡需要 PIN，請在 **PIN碼 (可選)** 中輸入。
5. 等待 30 至 90 秒。連線後，**數據機資訊** 會顯示電信業者、技術，以及 **IPv4 資訊**。

</Steps>

已插入的數據機會自動連線。若您選擇 **斷開連接**，它會保持斷線狀態，直到您再次連線為止，即使重新開機後也一樣。

### 自動 APN 的運作方式 {/* #how-the-automatic-apn-works */}

當 APN 欄位留空時，UAVcast-Pro 會依下列順序嘗試：

1. 此 SIM 卡的電信業者上次成功使用的 APN，
2. 網路的預設 APN（空白 APN），
3. 數據機附著至 LTE 時所使用的 APN，
4. 行動寬頻供應商資料庫中，該電信業者的網際網路 APN。

第一個取得網際網路位址的 APN 會被儲存，作為該電信業者的設定。若您更換為其他電信業者的 SIM 卡，則會重新偵測。若您的電信業者需要特殊 APN（私有 APN、M2M 或企業 SIM 卡），請手動輸入。只有使用者設定的 APN 會被嘗試。

## 設定 HiLink 數據機 {/* #set-up-a-hilink-modem */}

<Steps>

1. 插入數據機，並等待其指示燈顯示穩定的連線。
2. 在 **數據機** 頁面，將 **啟用數據機** 設為 **是**，並將 **數據機類型** 設為 **HiLink**。
3. 檢查 **Hilink數據機資訊**：您應會看到 **介面** 與 **IP 位址**。

</Steps>

HiLink 數據機會自行連線、選擇網路並重新連線，因此沒有連線按鈕。若要變更 APN、PIN 或網路模式，請在數據機自己的網頁中進行（可從無人機的網路連到該網頁，通常為 `http://192.168.8.1`）。

## 設定參考 {/* #settings-reference */}

| 設定 | 預設值 | 可選值 | 說明 |
|---|---|---|---|
| **啟用數據機** | **是** | **是**、**否** | |
| **數據機類型** | **傳統型（PPP）** | **HiLink**、**傳統型（PPP）** | |
| **存取點名稱 (可選)** | 留空（**自動**） | 您的電信業者提供的 APN | 僅適用於傳統型數據機。 |
| **使用者名稱 (可選)** / **密碼 (可選)** | 留空 | | 僅適用於傳統型數據機。多數電信業者都不需要。 |
| **PIN碼 (可選)** | 留空 | SIM PIN | 僅適用於傳統型數據機。若 SIM 卡沒有 PIN，請留空。 |

## 數據機資訊 {/* #modem-information */}

對於傳統型數據機，**數據機資訊** 會顯示 **訊號品質**、**技術**（LTE、UMTS 等）、**需要解鎖**、**狀態**、**製造商**、**IMEI**、網路（**電信業者**、**代碼**、**註冊**）、**IPv4 資訊**（**IP 位址**、**閘道**、**DNS**、**MTU**），以及 **連線屬性**（**APN**、**IP 類型**、**漫遊**）。

儀表板上的 **Cellular** 列會顯示相同的訊號摘要。

## 在行動網路上飛行前 {/* #before-flying-over-cellular */}

- 在[網路](./networks.mdx)頁面中，選擇 **數據機優先（戶外模式）**，使起飛時即使 Wi-Fi 仍在範圍內，流量也會保留在數據機上。
- 使用 [VPN](./vpn.mdx)：行動電信業者不會給無人機一個地面站能連到的位址。
- 在飛行控制器上開啟 **地面站故障保護**（GCS failsafe）。
- 在飛行高度檢查訊號：覆蓋範圍是針對地面規劃的，爬升時訊號會改變。

## 疑難排解 {/* #troubleshooting */}

| 症狀 | 檢查項目 |
|---|---|
| *未連接數據機* | 未偵測到數據機。請檢查 USB 連接與數據機的電源指示燈。若數據機連線時 Pi 會重新啟動，請使用有外接電源的集線器。 |
| **需要解鎖** 顯示 *已鎖定* | 輸入 SIM PIN，或在手機中停用 PIN。 |
| 已註冊但沒有 IP 位址 | APN 錯誤。請輸入電信業者的 APN，而不是使用自動。 |
| 連線後在負載下中斷 | 通常是電源問題。請檢查儀表板上的 **電源** 列。 |

**操作日誌** 會顯示每次 APN 嘗試及其失敗原因。更多協助請參閱[數據機已連線但無法上網](../../troubleshooting/modem-no-internet.mdx)。
