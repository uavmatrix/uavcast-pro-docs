# 網路 {/* #networks */}

網路頁面會顯示無人機上的所有網路介面（乙太網路、Wi-Fi、數據機、VPN），以及哪一個是預設路由。當 Wi-Fi 與數據機同時連線時，您也可以在此選擇優先使用 Wi-Fi 或行動數據機。請在側邊欄中開啟 **網路**。

## 選擇網路優先順序 {/* #choose-the-network-priority */}

當 Wi-Fi 與數據機都已連線時，Linux 會透過路由度量值（route metric）最低的連線傳送流量。**網路優先順序** 會替您設定這些度量值：

| 選項 | 適用情況 | 效果 |
|---|---|---|
| **WiFi優先（室內模式）** | 在工作台或家中，為了節省行動數據用量。 | Wi-Fi 度量值 100，數據機度量值 600。 |
| **數據機優先（戶外模式）** | 每次透過行動網路飛行之前。 | 數據機度量值 100，Wi-Fi 度量值 600。 |
| **自動（系統預設）** | 您不希望 UAVcast-Pro 變更任何設定。 | NetworkManager 自身的度量值。 |

:::warning 起飛前切換至數據機優先
若無人機以 Wi-Fi 優先起飛，連線會維持在 Wi-Fi 上，直到 Wi-Fi 中斷後才會在空中切換到數據機。這會造成遙測與視訊中斷。請在地面上選擇 **數據機優先（戶外模式）**。
:::

變更會套用到目前的連線，無需重新啟動（*正在套用變更...*）。

:::note 會變更哪些連線
Wi-Fi 度量值會設定在名為 `preconfigured` 的 NetworkManager 連線上，這是 Raspberry Pi Imager 在燒錄時為您輸入的 Wi-Fi 所指定的名稱。以其他方式設定的 Wi-Fi 會保留自己的度量值，而乙太網路則永遠不會被變更。
:::

## 介面資訊 {/* #interface-information */}

摘要卡片會顯示 **活動介面**、**預設閘道**（以及其所經過的介面），以及 **介面總數**。**網路介面** 會列出每個介面的 **名稱**、**IP 位址**、**閘道**、**狀態**（**活動**、**非活動**、**VPN**）、**速度**、**類型**，以及哪一個是 **預設**。

常見的介面名稱：

| 名稱 | 說明 |
|---|---|
| `eth0`、`end0` | 有線乙太網路 |
| `wlan0` | Wi-Fi |
| `ppp0`、`wwan0` | 傳統型數據機 |
| `usb0`、`eth1` | HiLink 數據機 |
| `zt…` | ZeroTier |
| `tailscale0` | Tailscale |
