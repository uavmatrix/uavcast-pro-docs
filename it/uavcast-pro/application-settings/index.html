Impostazioni dell'applicazione, log e backup

La pagina Applicazione contiene tutto ciò che riguarda UAVcast-Pro stesso: la licenza, gli aggiornamenti, le impostazioni dell'interfaccia, il download dei log e il database delle impostazioni. È visibile solo agli amministratori ed è l'unica pagina che funziona prima che il dispositivo abbia una licenza attiva. Apri Gestione → Applicazione.

Cambiare la porta dell'interfaccia web​

  1. Inserisci la nuova porta in Porta Server.
  2. Seleziona Invia e riavvia server. Una finestra mostra il Nuovo URL, ad esempio http://192.168.1.50:8080.
  3. Attendi qualche secondo e apri il nuovo URL.

I segnalibri e i link al vecchio indirizzo smettono di funzionare. Una porta modificata mostra l'avviso The server port has been changed from the default port 80. A partire da UAVcast-Pro 6.5.3 la porta viene mantenuta quando aggiorni; le versioni precedenti la reimpostano a 80.

Registrazione Log​

UAVcast-Pro registra separatamente i log di ogni servizio. Scaricali quando qualcosa va storto e inviali all'assistenza.

  1. Attiva la Modalità Debug per avere più dettagli. Riproduci il problema.
  2. In Seleziona log da scaricare, lascia Tutti i Log oppure scegline uno.
  3. In Seleziona intervallo di tempo, scegli un intervallo che copra il problema (da Ultimi 10 minuti a Tutto il Tempo).
  4. Seleziona Scarica. Otterrai un file zip.
  5. Invia il file via email a support@uavmatrix.com con una breve descrizione di quanto è successo. Disattiva di nuovo la Modalità Debug al termine.

Il download include uno snapshot diagnostics.txt (impostazioni, porte seriali, eventi di alimentazione e USB) che accelera l'assistenza.

Elimina Tutti i Log cancella tutti i file di log. Non può essere annullato; eseguilo prima di riprodurre un problema se vuoi un log pulito. Sul drone, i log si trovano in /opt/uavcast-pro/logs.

Ogni pagina ha inoltre una console Registro Azioni che mostra il log in tempo reale del servizio di quella pagina.

Database​

Tutte le impostazioni (stazioni di controllo a terra, controllore di volo, telecamera, modem, VPN, NTRIP, utenti, dashboard, iniettori, dati di licenza) risiedono in un unico database SQLite, /opt/uavcast-pro/uavcast.db.

AzioneCosa fa
Backup DatabaseScarica il database come uavcast_backup.db.
Ripristina DatabaseCarica un backup .db e sostituisce le impostazioni attuali, utenti inclusi.
Reset DatabaseRipristina ai valori predefiniti le impostazioni di stazioni di controllo a terra, controllore di volo, telecamera, VPN e DNS dinamico. Utenti, licenza, modem, NTRIP, impostazioni di registrazione, dashboard, iniettori e l'abbinamento con Fleet Manager vengono mantenuti. Non può essere annullato.

Usa i backup per conservare una configurazione funzionante prima di apportare modifiche, oppure per configurare allo stesso modo un secondo drone. Riavvia dopo un ripristino, così ogni servizio parte con le impostazioni ripristinate.

Ripristino su hardware diverso

I dati di licenza nel database sono legati al dispositivo da cui provengono. Dopo aver ripristinato un backup su un altro Pi o su un'altra scheda SD, attiva la licenza sul nuovo dispositivo. Il ripristino importa anche utenti e password dal backup.
