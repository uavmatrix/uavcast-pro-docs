Referencia de ajustes

Todos los ajustes de la interfaz web de UAVcast-Pro, agrupados por página, con la etiqueta exactamente como la muestra la aplicación y el valor predeterminado en una instalación nueva. Las páginas que cambian ajustes en vivo los aplican de inmediato, salvo que se indique lo contrario. Las páginas de funciones explican cada área en detalle; esta página sirve para consultar datos.

Controlador de Vuelo → Conexión​

AjustePredeterminadoValores y notas
Enlace habilitadoActivadoActiva o desactiva el enlace con el controlador de vuelo.
Tipo de enlaceUSBUSB (el puerto USB propio del controlador de vuelo) o UART / Serie (puerto TELEM en los pines GPIO o en un cable USB-serie).
PuertoAutomáticoAutomático encuentra el controlador de vuelo y lo sigue si cambia el número de dispositivo. Ruta personalizada… acepta un dispositivo como /dev/ttyAMA0.
Tasa de baudiosAutomáticaDebe coincidir con SERIALx_BAUD del controlador de vuelo. Automática prueba 57600, 115200, 921600, 1500000, 460800, 230400 y 500000. No se usa con USB.

Botones: Detección automática (busca en todos los puertos y velocidades, y guarda el resultado), Conectar, Reiniciar enlace, Detener. Los cambios se aplican de inmediato, sin reiniciar.

Controlador de Vuelo → Inyectores​

AjustePredeterminadoValores y notas
Tipo de entradaHTTP, UDP o Serie. No se puede cambiar después de crear el inyector.
sysid MAVLink1Igual que el controlador de vuelo.
compid MAVLink194Carga útil de usuario.
Prefijo de nombrevacíoHasta 8 caracteres ASCII, antepuestos a cada nombre de señal.
Límite de tasa (Hz por señal)Máximo de muestras por segundo para cada nombre de señal.
Protocolo (UDP, Serie)Clave=Valor (líneas) o JSON ({name, value}).
Puerto / Dirección de escucha (UDP)Elige un puerto libre, por ejemplo 14600. 0.0.0.0 = todas las interfaces, 127.0.0.1 = solo local.
Ruta del dispositivo / Baudios (Serie)Por ejemplo /dev/ttyUSB0; la tasa de baudios debe coincidir con la del emisor.

Una tarjeta por destino.

IP o Host de DestinovacíoUna dirección IPv4. Es obligatoria antes de poder activar el video o la telemetría.
Puerto de Telemetría145501–65535.
Puerto de Video56001–65535.
Puerto de Video (Cámara 2)vacío (= Puerto de Video + 1)Solo se muestra cuando Dual stream está activado.
Habilitar EndpointActivadoDesactivado detiene todo hacia este destino: telemetría, video y audio.
Habilitar VideoDesactivado
Habilitar TelemetríaDesactivado
Read OnlyDesactivadoLa estación de control en tierra recibe telemetría, pero no puede cambiar nada en el vehículo. Esto se aplica a partir de UAVcast-Pro 6.5.3; en versiones anteriores, Read Only no bloquea la escritura de parámetros.
