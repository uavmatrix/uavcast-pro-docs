Tutorial · Raspberry Pi
Inicio rápido

De una tarjeta SD en blanco a video en vivo y telemetría en tu estación de control.

  1. Graba un SO de 64 bits
  2. Ejecuta el instalador
  3. Conecta el controlador de vuelo
  4. Agrega tu estación de control
Referencia
Requisitos de hardware

Computadoras de a bordo, controladores de vuelo, cámaras y módems. Revisa esto antes de comprar piezas.

  • Raspberry Pi, NVIDIA Jetson, Orange Pi
  • Cualquier computadora Linux arm64 o amd64
  • Cualquier controlador de vuelo MAVLink (ArduPilot, PX4)
  • Módems LTE USB y HiLink
Licencias
Activa tu licencia

Activa una clave en un dispositivo, muévela a nuevo hardware y revisa cómo funcionan los espacios de dispositivos.

  1. Compra una clave en la tienda de UAVmatrix
  2. Abre Aplicación › Gestor de Licencias
  3. Ingresa la clave con conexión a internet

¿Algo no funciona?

Todas las soluciones
  • No hay video en QGroundControl ni en Mission Planner
  • No hay heartbeat de MAVLink desde el controlador de vuelo
  • No hay telemetría en la estación de control
  • La clave de licencia no se activa
  • El módem se conecta pero no tiene internet
  • No se abre la interfaz web
